## 2. 官方要求與本報告範圍

官方《TTQS 查核佐證文件資料表－訓練機構版》第 1 頁列示的佐證文字為「目標市場需求調查。」本報告聚焦於調查結果如何被整理成可追溯的需求分析，並明列資料母數、計算口徑、分析結果、限制與建議。

本報告的分析範圍包括：

- 將有效回覆與無效回覆分開，說明分析分母。
- 彙整需求排序、緊急度、信心、學習偏好、障礙及預期改善方向。
- 標示只有一份有效合成答卷的限制，不把答卷內排序寫成市場普遍排名。
- 提供可供協會採用的真實資料替換及後續追蹤方法。

本報告不承擔問卷設計、接觸邀請、同意取得、逐筆執行紀錄或課程核准。官方 PDF 頁面列出的是佐證文字；I01-E02 是本案對應需求識別，不應誤寫成官方 PDF 印出的方框流水號。

## 3. 示範目標市場與分析問題

**示範目標市場假設：** 以參與協會志工服務的人員作為初步觀察群體。這是依合成答卷中的「志工類別」設定的分析情境，尚未經真實名冊、服務範圍或市場調查確認。報告不設定真實地區、人口數、服務量或市場規模。

**分析問題：** 在這份合成小樣本中，答卷者依序提到哪些能力需求？其自評緊急度、信心與參訓偏好為何？現有資料足以支持哪些有限判讀，還需要哪些真實資料才能進入課程規劃？

**不納入的推論：** 本案沒有可驗證的目標市場總人數、抽樣框完整度、真實回收母體、外部市場資料、競爭者比較或服務需求趨勢。因此不估算市場規模、需求成長、付費意願、課程市場占比或預期訓練成效。

### 7.2 緊急度、信心與探索性差值

- 緊急度總分：4 分；有效作答數：1；平均緊急度＝4 ÷ 1＝4.0／5。
- 高緊急度：該答卷分數為 4，符合「4 或 5」的計算條件；比例＝1 ÷ 1＝100.0%。這是本合成樣本的算術結果，不可外推。

- 探索性對照＝緊急度 4.0 − 信心 2.0＝2.0 分。兩題測量的概念不同，且沒有量表效度資料；此差值只提示後續可詢問「急於改善但信心較低」的原因，不是正式能力落差分數。

## 10. 分析結論與建議

### 10.1 分析結論

這份 SAMPLE／SYNTHETIC 案例可完整展示有效樣本判定後的分析方法：一份有效答卷中，服務流程與紀錄列為首位，緊急度自評為 4／5，信心自評為 2／5，並有面對面、週末上午及教材可讀性等個人偏好。由於有效樣本只有一份，結果只能描述該筆合成資料。現有資料不足以判斷目標市場規模、需求普遍程度、課程定價、開課可行性或訓練成效。

### 10.2 建議採取的處理

1. 將本次結果保留為分析流程示例，不發布成協會調查成果，不作開課或支出決議依據。
2. 先以協會可合法使用的對象清冊界定真實目標群體、納入條件與分群方式；保存名冊版本與去識別化方式，不在分析報告揭露個資。
3. 使用 0003 問卷的核定題目與量尺收集真實回覆；依 0004 的執行紀錄保存邀請、同意、回收、排除及重複處理證據。若題目或量尺變更，標明版本並避免直接混算不同版本。
4. 回收結束後先核對唯一回覆數、有效數與各題有效分母，再按本報告定義重算需求排序、平均分及高需求比例；各分群樣本不足時只列筆數，不作比較性結論。
5. 將三個示範主題作為待真實資料驗證的候選方向。只有在真實需求、時段／交通、教材可近性、資源可行性均有相應證據後，才把分析提供給有權責的主管或會議審議。任何實際決議應另由正式會議或核定紀錄證明。
