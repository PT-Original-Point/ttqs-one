## 1. 摘要、用途與決策問題

### 1.1 用途
本文件提供一份可執行的訓後成果追蹤調查工具與彙總分析報告設計，直接回應官方要求「訓後調查表」。它定義合格受訪母群、邀請與追蹤控制、問卷題目、量尺、指標公式、合成示範資料與改善行動。所有示範資料均為 `SAMPLE / SYNTHETIC`，必須完成替換登錄後，才能主張 `REAL`。

### 1.2 主要讀者
- 訓練管理人員
- 決策者
- 內部品質審查人員
- 訓練改善責任人員

### 1.3 決策問題
1. 受訓者是否認為訓練內容相關、清楚且可應用？
2. 受訓者如何自評知識、技能、信心與工作應用？
3. 哪些訓練元素應保留、修正或停止？
4. 哪些支持或障礙影響學習應用？
5. 根據結果應採取哪些改善行動、由誰負責、期限為何、如何追蹤？

### 1.4 使用時點與限制
- 於指定訓練活動結束且約定追蹤期間屆滿後使用。
- 於下一輪訓練、課程修訂或預算決策前使用。
- 僅用於彙總改善決策。
- 不得用於個人人事決策、證照決策、雇主驗證或外部稽核結論。

### 1.5 首頁 30 秒說明
本文件是訓後成果追蹤調查與彙總分析報告。它定義合格受訪母群、邀請與追蹤控制、問卷題目、量尺、指標公式、合成示範資料計畫與改善行動。本文件中的所有示範資料均為 `SAMPLE / SYNTHETIC`，必須先完成替換登錄，才能主張 `REAL`。

## 4. 指標定義、分母與計算方法

### 4.1 工具段落

| 段落 | 目的 |
|---|---|
| A. 受訪者背景 | 描述受訪群體，不識別個人 |
| B. 訓練相關性 | 衡量知覺相關性與清楚度 |
| C. 學習成果 | 衡量受訓者對知識、技能與信心的訓後自評 |
| D. 應用與遷移 | 衡量工作應用與知覺組織效益 |
| E. 支持與障礙 | 衡量訓後支持與障礙 |
| F. 整體價值 | 衡量整體價值與推薦意願 |
| G. 開放文字 | 蒐集具體例子與改善建議 |

| 題號 | 段落 | 題目文字 | 必答 | 分析用途 |
|---|---|---|---|---|
| Q05 | B | 訓練內容與我的工作相關。 | 是 | 相關性平均分與正向率 |

| Q07 | B | 訓練足夠實務，可應用於工作。 | 是 | 可應用性平均分與正向率 |
| Q08 | C | 目前，我認為自己具備運用訓練主題相關知識處理工作情境的能力。 | 是 | 知識自評平均分與正向率 |
| Q09 | C | 目前，我認為自己具備運用訓練所學技能處理工作情境的能力。 | 是 | 技能自評平均分與正向率 |
| Q10 | C | 我有信心在工作情境中運用訓練所學。 | 是 | 信心自評平均分與正向率 |
| Q11 | D | 我自評曾在工作情境中應用訓練所學。 | 是 | 工作應用自評平均分與正向率 |
| Q12 | D | 學習應用對我的工作或組織有益。 | 是 | 效益平均分與正向率 |
| Q13 | E | 我獲得足夠支持以應用學習。 | 是 | 支持平均分與正向率 |

### 4.5 量尺、編碼與定義

| 代碼 | 標籤 | 定義 |
|---|---|---|
| 1 | 非常不同意 | 幾乎不認同此敘述 |
| 2 | 不同意 | 多半不認同此敘述 |
| 3 | 普通 | 既不同意也不反對 |
| 4 | 同意 | 大致認同此敘述 |
| 5 | 非常同意 | 完全認同此敘述 |
| 9 | `N/A` | 不適用；排除於題目分母並另行計數 |
| 空白 | 缺漏 | 未回答；排除於題目分母並另行計數 |
| 無效 | 超出範圍 | 代碼不在 `1-5` 或 `N/A` 範圍；排除並記錄 |

正向回應定義為代碼 `4` 或 `5`。`N/A` 不是正向回應，且不計入題目分母。

### 4.6 指標公式

| 指標 | 公式 | 備註 |
|---|---|---|
| 回收率 | `D2 / D1 × 100%` | `D1` 為符合核准資格且已實際送達的邀請數；若 `D1 = 0`，報 `N/A` |
| 題目平均分 | `有效題目分數總和 / 有效題目回覆數` | 題目分數為 `1-5` |
| 正向率 | `4-5 分人數 / 有效題目回覆數 * 100` | 有效題目回覆數必須大於 0 |
| 缺漏率 | `缺漏或 N/A 數 / 有效回覆數 * 100` | 依題目報告 |
| 完成率 | `11 個評分題全答的有效回覆數 / 有效回覆數 * 100` | 選用但建議報告 |
| 分群平均分 | `分群有效題目分數總和 / 分群有效題目回覆數` | 需依核准隱私規則聚合 |
| 分群正向率 | `分群 4-5 分人數 / 分群有效題目回覆數 * 100` | 需依核准隱私規則聚合 |

### 4.7 四捨五入與缺漏規則
