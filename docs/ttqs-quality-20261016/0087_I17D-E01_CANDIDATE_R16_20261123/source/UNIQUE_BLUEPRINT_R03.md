## 1. 用途、讀者、決策與使用時點
### 1.1 用途
產出一份可執行的訓後成果追蹤調查工具與彙總分析報告，直接回應官方要求 `訓後調查表。`。文件必須呈現實際題目、追蹤方式，以及示範資料計畫。

### 1.2 主要讀者
- 訓練管理人員
- 決策者
- 內部品質審查人員
- 訓練改善責任人員

### 1.3 決策問題
1. 受訓者是否認為訓練內容相關、清楚且可應用？
2. 受訓者如何自評知識、技能、信心與工作應用？
3. 哪些訓練元素應保留、修正或停止？
4. 哪些支持或障礙影響學習應用？
5. 根據結果應採取哪些改善行動、由誰負責、期限為何、如何追蹤？

### 1.4 使用時點與限制
- 於指定訓練活動結束且約定追蹤期間屆滿後使用。
- 於下一輪訓練、課程修訂或預算決策前使用。
- 僅用於彙總改善決策。
- 不得用於個人人事決策、證照決策、雇主驗證或外部稽核結論。

### 1.5 首頁 30 秒說明
本文件是訓後成果追蹤調查與彙總分析報告。它定義合格受訪母群、邀請與追蹤控制、問卷題目、量尺、指標公式、示範資料計畫與改善行動。本藍圖中的所有示範資料均為 `SAMPLE / SYNTHETIC`，必須先完成替換登錄，才能主張 `REAL`。

## 11. 訓後成果分析計畫
### 11.1 必要描述性輸出
- 依波次與梯次計算回收率。
- 題目層級的 `n`、總和、平均分、正向數、正向率與缺漏數。
- 在允許的格子大小下，依角色、工作領域與交付模式進行分群比較。
- 開放題主題摘要與例句。
- 若存在至少兩波可比較資料，進行趨勢比較。
- 重要性或提及頻率與表現分數的優先矩陣。

### 11.2 分群比較規則
分群比較僅為描述性。由於來源未指定推論統計方法，本藍圖預設不包含顯著性檢定、信賴區間或因果比較。任何推論分析需另行核准統計分析計畫與足夠樣本數。

### 11.3 趨勢規則
趨勢比較僅在以下條件全部成立時允許：
1. 使用相同問卷版本或核准的等效版本。
2. 母群可比較。
3. 兩波皆報告回收率。
4. 比較標示為描述性。

若任一條件缺失，趨勢結果為 `UNKNOWN`，不得估算。

## 12. 公式、分母、四捨五入與缺漏

|---|---|---|
| 回收率 | `D2 / D1 × 100%` | `D1` 為符合核准資格且已實際送達的邀請數；若 `D1 = 0`，報 `N/A` |
| 題目平均分 | `有效題目分數總和 / 有效題目回覆數` | 題目分數為 `1-5` |
| 正向率 | `4-5 分人數 / 有效題目回覆數 * 100` | 有效題目回覆數必須大於 0 |
| 缺漏率 | `缺漏或 N/A 數 / 有效回覆數 * 100` | 依題目報告 |
| 完成率 | `11 個評分題全答的有效回覆數 / 有效回覆數 * 100` | 選用但建議報告 |
| 分群平均分 | `分群有效題目分數總和 / 分群有效題目回覆數` | 需依核准隱私規則聚合 |
| 分群正向率 | `分群 4-5 分人數 / 分群有效題目回覆數 * 100` | 需依核准隱私規則聚合 |

### 12.2 四捨五入與報告
- 百分比：1 位小數。
- 平均分：2 位小數。
- 計數：整數。
- 若分母為 0，報告 `分母為 0 時報 `N/A``，不得報告 `0`、空白或 `100`。
- 每個百分比與平均分必須報告 `n`。
- 分群結果必須依核准隱私規則聚合；若無核准規則，標示 `UNKNOWN`，不得自行設定預設閾值。

### 12.3 缺漏與遲交規則
1. 評分題空白：計為缺漏；排除於題目平均分與正向率分母。
2. `N/A`：排除於題目分母；另行計數。
3. 無效代碼：排除於題目分母；記錄於清理記錄。
4. 重複回覆：依核准的去重規則處理並記錄；規則未核准前，處理方式標示 `UNKNOWN`。
5. 遲交回覆：僅納入分析鎖定前且於核准遲交期間內收到者；其餘排除並計數。
6. 部分回覆：若 11 個評分題中至少回答 8 題，視為有效；報告完成狀態。
7. 未記錄同意或拒絕同意的回覆為無效，排除於 `D2`。
8. 各題報告缺漏數、有效 `n` 與 `N/A` 數；可靠度判準標示 `UNKNOWN / 待核准`，不得自行設定缺漏百分比閾值。

以上分母與缺漏規則為本藍圖提出的方法提案；來源未授權的分母細節在正式使用前需治理確認。
