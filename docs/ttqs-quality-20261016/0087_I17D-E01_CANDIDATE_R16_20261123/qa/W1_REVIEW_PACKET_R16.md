## 12. 公式、分母、四捨五入與缺漏
### 12.1 公式
| 指標 | 公式 | 備註 |
|---|---|---|
| 回收率 | `D2 / D1 × 100%` | `D1` 為符合核准資格且已實際送達的邀請數；若 `D1 = 0`，報 `N/A` |
| 題目平均分 | `有效題目分數總和 / 有效題目回覆數` | 題目分數為 `1-5` |
| 正向率 | `4-5 分人數 / 有效題目回覆數 * 100` | 有效題目回覆數必須大於 0 |
| 缺漏率 | `缺漏或 N/A 數 / 有效回覆數 * 100` | 依題目報告 |
| 完成率 | `11 個評分題全答的有效回覆數 / 有效回覆數 * 100` | 選用但建議報告 |
| 分群平均分 | `分群有效題目分數總和 / 分群有效題目回覆數` | 需依核准隱私規則聚合 |
| 分群正向率 | `分群 4-5 分人數 / 分群有效題目回覆數 * 100` | 需依核准隱私規則聚合 |

### 12.2 四捨五入與報告
- 百分比：1 位小數。
- 平均分：2 位小數。
- 計數：整數。
- 若分母為 0，報告 `分母為 0 時報 `N/A``，不得報告 `0`、空白或 `100`。
- 每個百分比與平均分必須報告 `n`。
- 分群結果必須依核准隱私規則聚合；若無核准規則，標示 `UNKNOWN`，不得自行設定預設閾值。

### 12.3 缺漏與遲交規則
1. 評分題空白：計為缺漏；排除於題目平均分與正向率分母。
2. `N/A`：排除於題目分母；另行計數。
3. 無效代碼：排除於題目分母；記錄於清理記錄。
4. 重複回覆：依核准的去重規則處理並記錄；規則未核准前，處理方式標示 `UNKNOWN`。
5. 遲交回覆：僅納入分析鎖定前且於核准遲交期間內收到者；其餘排除並計數。
6. 部分回覆：若 11 個評分題中至少回答 8 題，視為有效；報告完成狀態。
7. 未記錄同意或拒絕同意的回覆為無效，排除於 `D2`。
8. 各題報告缺漏數、有效 `n` 與 `N/A` 數；可靠度判準標示 `UNKNOWN / 待核准`，不得自行設定缺漏百分比閾值。

以上分母與缺漏規則為本藍圖提出的方法提案；來源未授權的分母細節在正式使用前需治理確認。
