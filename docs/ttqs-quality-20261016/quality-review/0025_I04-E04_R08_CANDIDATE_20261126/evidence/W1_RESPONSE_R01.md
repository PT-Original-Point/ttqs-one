## 1. 目的

1.1 建立一套**可重複、可交接、可抽查**的訓練評估與實施程序，使不同承辦人、不同班次、不同年度執行同一標準，結果具可比性。

1.2 明定**訓練實施的依據**：在任何班次正式開課前，必須逐項確認需求、計畫、法規／合約適用性、學員資格、師資教材、場地設備、評量工具、紀錄與授權等前置條件；條件未成立者不得開課。

1.3 明定**訓練結果的評估**方法：以可重算的公式、明確的分母、固定的施測時點與判定門檻，將出席、學習、實作與反應層面資料轉為單一可稽的綜合判定。

1.4 明定**標準化機制**：統一步驟編號、表單編號、判定分支、例外升級路徑與紀錄保存要求，使程序偏離可被偵測、可被矯正。

1.5 確保所有合成示範資料與真實資料之界線清楚，不得以本文件之示範值宣稱為機構辦訓實績。

## 3. 名詞定義

| 名詞 | 本程序中的定義 | 備註 |
|---|---|---|
| 班次（Class Instance） | 一次具固定日期、場地、講師、學員名單與課程時數的訓練執行單位 | 同一課程不同日期即不同班次 |
| 計畫人時（Planned Person-Hours） | 錄取人數 × 每人應受訓時數 | 本程序出席率之分母 |
| 實得人時（Actual Person-Hours） | Σ（每位學員實際出席時數）；未出席者以 0 計 | 分母與分子必須同基準 |
| 註冊學員（Registered Cohort） | 已完成錄取程序並列入名單者，含事後缺席者 | 不得事後剔除缺席者以美化比率 |
| 全程出席 | 實際出席時數等於該班次應受訓時數 | 中離、遲到、早退均不計全程 |
| 中離 | 出席時數 > 0 但 < 應受訓時數 | 依實際時數計入實得人時 |
| 前置依據檢核 | 開課前對 B1–B10 之逐項確認，結果為 PASS／HOLD／N/A（附理由） | HOLD 即不得開課 |
| 綜合判定 | 依 §7.2 決策樹得出之單一結論（C-1～C-4） | 不得以平均掩蓋單項未達標 |
| 控制缺口 | 因兼任、人力或系統限制而無法執行之預定控制 | 須登錄 F-04-02-07，不得以「視為已執行」處理 |
| SAMPLE | 合成示範值，非機構實績、非官方規定 | 須經 §14 替換方可 REAL 化 |
| N/A | 經判定不適用，且已記載判定理由與判定角色 | 不得等同「未檢查」 |

## 4. 角色、權責與分離控制

### 4.1 角色代碼（不指涉真人）

| 代碼 | 角色 | 主要職責 | 授權層級 |
|---|---|---|---|
| P-01 | 訓練承辦人 | 立案、彙整依據、執行、施測、計算、撰寫報告草稿 | 執行與彙整，**無核准權** |
| P-02 | 訓練主管／覆核者 | 審核依據完整性、計算正確性、判定合理性；簽核報告 | 覆核與核定（除對外正式發行） |
| P-03 | 講師 | 授課、命題與評分（依既定評分規準）、出席確認 | 評分執行 |
| P-04 | 學員單位主管 | 提名學員、確認受訓需求、支持課後應用 | 提名與支持 |
| P-05 | 品質管理代表 | 抽核紀錄、監督控制缺口、彙整監測指標 | 監督與抽核 |
| P-06 | 機構負責人 | 正式版本核准、對外公告、涉及對外效力之簽署 | 最終核准（Human Gate） |

> 以上為**功能角色**，不代表機構實有六名人員。實際兼任情形依 §4.3 處理並登錄控制缺口。

### 4.2 RACI 與代理

- R＝負責執行；A＝當責核准；C＝被諮詢；I＝被通知。
- **代理規則（SAMPLE）**：P-02 不在時，由其書面指定之代理層級執行覆核；代理不得為同一班次之 P-01。
- **兼任規則**：若 P-01 與 P-02 為同一人，屬分離控制失效，須登錄控制缺口並改由高一層級或外部人員執行覆核；不得以自我覆核結案。

| 立案與依據彙整 | R | C | I | C | I | I |
| 前置依據檢核 | R | **A** | C | I | C | I |
| 課程與評量執行 | R | I | **R** | I | I | I |
| 評分與資料彙整 | R | C | **R** | I | I | I |

| 評估報告簽核 | R | **A** | I | I | C | I |

### 4.3 分離控制矩陣（Builder ≠ Reviewer）

| 控制 | 要求 | 若無法達成 |
|---|---|---|
| 計算與覆核分離 | 執行計算者 ≠ 簽核報告者 | 登錄控制缺口 GAP-01；由 P-05 或高一層級執行獨立重算 |
| 命題與審題分離 | 命題者 ≠ 審題定版者 | 登錄 GAP-02；採既有題庫並由 P-02 逐題核對 |

| 出席登錄與資料彙整分離 | 簽到表核對者 ≠ 成績登打者（如人力允許） | 登錄 GAP-04；採雙人核對或抽樣回核 |
| 正式核准 | 對外效力與正式發行僅 P-06 | 不得由 P-01／P-02 代行；此為 Human Gate |

## 8. 評量工具與可重算的判定方法

### 8.1 評量工具（四層次對應；工具版本為 SAMPLE）

| 層次 | 工具 | 施測時點 | 產出 | 對應門檻 |
|---|---|---|---|---|
| 反應 | 課後滿意度問卷（6 題、5 點量尺） | 課程結束當日 | 各題平均、總平均、回收率 | TH-6、TH-7 |
| 學習 | 前測（10 題、滿分 100）、後測（同構、滿分 100） | 開課時、結訓前 | 平均、增益、通過率 | TH-2、TH-3 |
| 行為／技能 | 實作演練評分規準（4 項×5 分＝20 分） | 課程中 | 平均、通過率 | TH-4、TH-5 |
| 成果 | 課後 30 天追蹤調查（自評應用程度） | T+30 | 回收率、平均 | 參考指標，不作門檻 |

> 工具題數、量尺與規準均為 **SAMPLE 設計假設**；實際題庫與版本以 B6／B8 定版紀錄為準。工具與課程目標之對應關係必須在 B8 逐題確認。

### 8.2 公式、分母與精度規則

1. **精度規則**：所有計算過程保留 **6 位小數**；僅在展示時四捨五入至 **2 位小數**。報告中同時呈現「未四捨五入值」與「展示值」，使第三人可重算。
2. **分母標示規則**：每一比率欄位名稱必須內含分母定義，例如「人時出席率（分母：計畫人時）」、「後測通過率（分母：後測有效份數）」。
3. **缺席計 0 規則**：計算註冊學員基準之出席率時，未出席者一律以 **0 小時**計入分子，且不得自分母剔除。
4. **雙基準並列規則**：若另呈現「僅計出席者」之比率，必須獨立欄位、獨立標題，不得與註冊學員基準混用或相互替代。
5. **比率一致性檢查**：出席率＋缺勤率必須等於 100.00%（允許 ±0.01% 顯示誤差）；不一致即表示分母錯誤。

公式：

- 計畫人時 = 註冊學員數 × 每人應受訓時數
- 實得人時 = Σ（每位學員實際出席時數），未出席者計 0
- 人時出席率 = 實得人時 ÷ 計畫人時
- 缺勤率 = 1 − 人時出席率
- 僅出席者人時率 = 實得人時 ÷（報到人數 × 每人時數）
- 平均分 = Σ分數 ÷ 有效份數
- 增益 = 後測平均 − 前測平均；相對增益 = 增益 ÷ 前測平均
- 通過率 = 達標人數 ÷ 有效份數
- 問卷總平均 = Σ各題平均 ÷ 題數

3. **不得宣稱之事項**：不得宣稱本機構已依本程序辦理任何班次、已達任何比率、已獲任何核准或已符合任何法規。
4. **個資界線**：真實學員姓名、聯絡方式、成績屬個人資料，僅保存在機構核可之位置；對外文件應以學員代碼呈現。問卷與成績不得任意複製至非核可載體。
5. **權限界線**：本文件之撰寫、覆核、核准為三個不同權限；撰寫者不得自任核准者。對外正式發行僅 P-06 有權。
6. **計算可追溯**：任何 REAL 數值進入報告時，必須同時保留原始資料位置與計算工作表，否則該數值視為未驗證。
