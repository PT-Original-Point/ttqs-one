1.2 三種常見的過度推論 
• 把「有獎狀」寫成「訓練績效顯著」：獎狀只證明某次競賽的結果，不證明學習前後的能力變化，也不證明目標客戶的評價。 
• 把「同一個人」寫成「同一門課的功勞」：學員可能課前已有基礎、另外參加其他培訓、或競賽難度較低。沒有訓練紀錄與時間序，只能說「有關聯」，不
能說「因為這門課所以得獎」。 
• 把「協會沒有人提供」寫成「協會沒有得獎」：目前狀態是資料未取得，不是績效為零。UNKNOWN 不能被改寫成 0。 
1.3 與 2 分、4 分的關係 
• 2 分談的是目標客戶及學員認為訓練有達成能力提升效果；這需要回饋或評價資料，不是單靠獎項。 
• 3 分、4 分涉及績效改善與顯著具體績效；獲獎可以是佐證之一，但仍要能說明「誰受訓、受什麼訓、學到什麼、表現在哪裡、如何確認」。 
• 本文件只協助把「獲獎證據」與「訓練關聯」整理到可被查核的程度，不做評分，也不宣稱會得幾分。 
1.4 證據等級不是自動加分 
即使拿到官方結果頁，也要看它是否列出可對應的得獎者、是否為同一屆／同一組別、是否為正式獎項。若官方頁面基於個資只列隊名或部分姓名，必須另外取
得主辦單位確認，或由學員提供可對照的證明；不能只看「看起來很像」就通過。
