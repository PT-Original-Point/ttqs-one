## E. 唯一 SAMPLE/SYNTHETIC 批次與核算口徑

公式與對帳：

- `篩選數 = 不合資格 + 合資格邀請 = 1 + 4 = 5`。
- `合資格邀請 = 唯一回覆 + 拒絕 + 無回覆 = 2 + 1 + 1 = 4`。
- `唯一回覆 = 有效 + 無效 = 1 + 1 = 2`。
