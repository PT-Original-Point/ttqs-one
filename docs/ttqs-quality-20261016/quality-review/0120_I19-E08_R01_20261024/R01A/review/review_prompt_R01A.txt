## 計算規則與資料品質

- `完訓率 = 符合完訓條件人數 / 入班人數`。
- `配對完整率 = 前後測皆有效人數 / 入班 cohort 人數`。
- `前測平均 = 配對者前測總分 / paired n`；`後測平均 = 配對者後測總分 / paired n`。
- `配對平均差 = Σ(每人後測−前測) / paired n`，不得以全班不同分母計算兩期平均後再稱為配對差。
- `門檻通過率 = 達門檻人數 / 有效該次評量人數`；`回覆率 = 有效回覆人數 / 邀請人數`；都須標出基數與四捨五入位數。
- 缺測值不當作 0；分母 0 時輸出 `NOT_CALCULABLE`；不得排除缺測但不列清冊。
- 描述性變化不代表訓練造成改善；同期間其他影響、量尺版本、前測效應、非隨機缺測都需在限制中交代。
