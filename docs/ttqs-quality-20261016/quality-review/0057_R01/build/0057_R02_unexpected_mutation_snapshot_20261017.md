| `D` | 有效回覆數 | `C` 中完成**主波 T+90 有效問卷**者（唯一人；其他波次不計入 `D`） | `D ⊆ C` |
| `E` | 實際應用數 | `D` 中於主波判定「已實際應用」者（判定見 4.4；每人一次） | `E ⊆ D` |
| `F` | 符合能力門檻人數 | `B` 中課後評量達門檻者 | `F ⊆ B ⊆ A` |
| `G` | 具非自述佐證之應用數 | `E` 中歸屬 Tier-A 或 Tier-B 者（互斥歸屬，見 4.5） | `G ⊆ E ⊆ D ⊆ C ⊆ A` |

**嵌套硬規定**：`G ≤ E ≤ D ≤ C ≤ A` 與 `F ≤ B ≤ A` 必須逐期成立；任何一格違反即退件。

### 4.4 唯一判定規則（R02 修復：消除 E 的自述矛盾）

- **`E`（實際應用）主判定波 = T+90**，每名回覆者只判一次，二擇一即成立：
  1. **自述路徑**：主波 T+90 問卷達「行為達標」（`Q1 ≥ 1 次` 且 `Q2 ≥ 4` 且 `Q3 ≥ 4`）；或
  2. **非自述路徑**：截至主波（第 84–90 天窗內）已存在 Tier-A 紀錄佐證或 Tier-B 觀察達標（總分 ≥ 9/12），**即使該員主波未自述達標**亦計入 `E`。
- **`G`（非自述佐證）**：`E` 中**僅**歸屬 Tier-A 或 Tier-B 者；純自述（Tier-C）**不**計入 `G`。
- **描述性波次**：T+30、T+60、T+180 的回覆與結果**只做描述性揭露**（T4-C），**不得**用來新增或重複計入 `D`、`E`、`G`；期間三的 T+180 與期後組的各波在截點時為「未到期」，**不得填值**。
- **率（每率均寫明分子/分母，且須與 T2/T4 逐列重算一致；每率僅一個主判定時點）**

| # | 率 | 分子/分母 | 主判定時點 |
|---|---|---|---|
| 1 | 評量完成率 | `B / A` | T0（結訓後 7 日內） |
| 2 | 可追蹤率 | `C / A` | T0+7 |
| 3 | 追蹤回覆率 | `D / C` | **主波 T+90**（第 84–90 天） |
| 4 | 實際應用率 | `E / D` | **主波 T+90 判定**（4.4 兩路徑） |
| 5 | 能力達標率 | `F / B` | T0 課後評量 |
| 6 | 非自述佐證占率 | `G / E` | 截至**主波 T+90** 之 Tier 歸屬 |

### 4.5 Tier 互斥歸屬與證據筆數（R02 修復：人數與筆數分離）

- **Tier 定義（皆為「非自述佐證」= non-self-report corroboration，單位是人）**
  - **Tier-A（非問卷自述之當期紀錄佐證）**：服務接觸紀錄簿、系統登錄等**當期產生、可由他人查核**的紀錄。
  - **Tier-B（他人觀察量尺達標）**：T+60 觀察量尺總分 ≥ 9/12。
  - **Tier-C（僅自述）**：只有主波自述達標、無 Tier-A／Tier-B。
- **互斥歸屬順序（防同一人被算兩次）**：具 Tier-A → 歸 **Tier-A**；否則具 Tier-B → 歸 **Tier-B**；否則 → 歸 **Tier-C**。每人只歸一層，`G = Tier-A + Tier-B`（唯一人相加）。
- **「非自述」≠「第三方獨立」（硬規定）**：Tier-A／Tier-B 只表示**非問卷自述**的佐證；觀察者若與受觀察者同站值班，須標「非完全獨立」。本示範**不得**宣稱任何未隸屬第三方的獨立性、鑑證或公正性。
- **證據筆數另計（T4-B）**：紀錄筆數、觀察表份數是**記錄數**，僅供佐證量感，**不得**與人數混算，**不得**進入任何率的分子或分母。

### 4.6 分母與缺失處理規則（硬規定）

- 非回覆者（失聯／拒訪）**留在 C**，不從分母剔除；只在分子（`D`）計入主波有效回覆。
- 主波未回覆者**即使回覆過 T+30 或 T+60**，仍**不計入 `D`**；其歷史回覆只在 T4-C 作描述性揭露。
- 「不適用（N/A）」答案**逐題剔除於該題分母**，並單獨回報題級分母。
- 跨期口徑必須一致：各期以**自身 cohort 分母**計率；**禁止**把三期原始人數直接相加當「等長趨勢」。合計列若呈現，必須標「三期合計（口徑不一致，僅供總覽、不觸發任何判定）」，且**任何門檻／規則都不得用合計率觸發**（見第 9 節）。
