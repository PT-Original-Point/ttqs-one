**主波次（primary follow-up wave）＝ `T+90`**。所有「追蹤相關率」（追蹤涵蓋率、主要應用率、非自述佐證占率）**只以 `T+90` 主波次認定**。

- `T+30`、`T+60`、`T+180` 之回覆**僅為描述性/耐久性補充**，**不**決定 `E`、`G`，且**同一人不得跨波次重複計入任何比率分子**（每人於每一率最多計一次）。
- **單位＝人（person）× cohort**：所有率之分子、分母均以「人」為單位，不以「筆」為單位；「筆數」僅出現於第 7.4 節所稱之**獨立佐證筆數**欄，且明確標示為筆、不進率。

### 5.5 佐證分層與互斥指派（defect 2）

- **Tier-A（非自述、內部紀錄）**：具服務接觸紀錄或系統紀錄佐證者。**非**獨立第三方；僅為「內部非自述佐證」。
- **Tier-B（非自述、內部觀察）**：具督導／同儕觀察量尺達標紀錄者。**非**獨立第三方；觀察者可能與受觀察者同站，屬「非完全獨立」，須註記偏誤風險。
- **Tier-C（僅自述）**：僅有問卷自述達標、無 A 或 B 佐證。
- **互斥指派（硬規定）**：每位 `E` 中之應用者**只歸一層**，優先序 **Tier-A ＞ Tier-B ＞ Tier-C**。故每 cohort 有 `Tier-A人數 + Tier-B人數 + Tier-C人數 = E`，且 `G = Tier-A人數 + Tier-B人數`。
- **獨立佐證筆數（可保留，但分欄）**：另設「Tier-A 佐證紀錄筆數」欄，為**筆數**、非人數；**不得**與人數相加或混算。Tier-B 亦得另計觀察筆數（選用）。

### 5.6 分母與缺失處理規則（硬規定）

- 非回覆/失聯（`UNREACHABLE`）、明確拒訪（`DECLINED`）**留在 `C`**，不從分母剔除；只在分子（`D`）計入有主波次追蹤資料者。
- 「不適用（N/A）」答案**逐題剔除於該題分母**，並單獨回報題級分母。
- 跨期口徑必須一致：`P1`/`P2` 為完整年度、`P3` 為 3 個月有界完成 cohort、`P3-Q2` 不列入分母；任何跨期比較須以「各 cohort 自身分母」計率，**禁止**把原始人數直接相加當等長趨勢。如提供合併數列，須標「合併（口徑不一致、成熟度不同，僅供描述性總覽；**不得作為決策依據**）》」。

## 10. 發現、限制與決策邏輯

### 10.1 Findings（示範資料之敘述性發現；defect 4、7）

- **F1 能力達成（描述性跨期）**：達標率 `80.6% → 86.7% → 89.3%`；`P3` 為 3 個月有界完成 cohort，僅供描述。
- **F2 主要應用未同步**：主波次應用率 `62.5% → 68.8% → 61.1%`，三期皆低於 70%。
- **F3 非自述佐證偏低**：非自述佐證占率 `40.0% → 45.5% → 45.5%`，過半應用僅有自述。
- **F4 追蹤涵蓋波動**：`75.0% → 80.0% → 72.0%`；`P3` 低於 75%。
- **F5 群組差異明顯（僅 P3 用於決策）**：`P3` 陪伴組 `75.0%` vs 無陪伴組 `50.0%`（差距 25.0 百分點）；合併描述性為 `78.8%` vs `53.7%`。屬群組描述，非因果。

> 以上發現均以合成示範資料陳述，**不**主張協會實際達成績效。

### 10.2 Limitations（必須明列）

1. **樣本極小**：各期受訓數 30–48，任何比率波動大；**不得**作因果或顯著性宣稱。
2. **自選偏差**：回覆者與陪伴者可能本即較投入。
3. **佐證層級不均**：多數為自述；觀察常由同站督導進行，屬**內部佐證、非完全獨立**，非第三方獨立。
4. **期間與成熟度不一**：`P3` 為 3 個月有界完成 cohort；`P2` 之 `T+180` 貼近截點；`P3` 之 `T+180` 未到期（`NOT YET DUE`）；`P3-Q2` 未列入分母。
5. **無對照組**：無法將應用歸因於本課程；應用率上升亦不得宣稱「課程造成」。
6. **合成性質**：所有數據為 SAMPLE，**不代表協會實績**，亦**不是 TTQS 分數**。
