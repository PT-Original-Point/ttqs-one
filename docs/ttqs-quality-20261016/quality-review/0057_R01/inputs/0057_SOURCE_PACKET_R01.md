## 3. 本文件應證明什麼

0057 是以資料與例證為中心的**近年訓練成果移轉及達成檢討報告**。讀者應能從正文回答：

1. 觀察哪些訓練／學習目標、工作或志工服務行為及成果；定義與官方要求如何相連。
2. 每期／年度資料的母群、分母、有效追蹤數、缺失與非回覆處理方式是什麼。
3. 學到的能力在何時、何種工作情境被使用；有何可查示範資料，哪些只是自陳。
4. 分期結果有何差異；哪些結果只能描述、不能據此宣稱因果或真實協會績效。
5. 檢討得出什麼結論、改進或 HOLD；由何種擬議角色在何時追蹤，何時重新檢查效果。

建議用一個完整、明確標記 `SAMPLE / SYNTHETIC` 的志工訓練案例示範可操作的資料鏈。協會現有班次、受訓者、服務、任務、管理角色及實際成果目前均未由本來源包證實；不得寫成原始點協會實際辦訓或已發生成果。若沒有經核驗的 REAL 資料，整體結論必須寫成合成示範的檢討結果，REAL 成效保持 `UNKNOWN / PENDING_REAL_SOURCE`。

## 5. Blueprint / Writer 的必備內容方向

以下是來源包要求，不是填空式成品大綱。Blueprint 必須自行具體化專屬章節、欄位、量尺、示例數據、計算與退件條件：

- 近年期別比較，包含資料截點、納入排除及同口徑限制；2026 如採部分年度必須明示。
- 可重算的合成 cohort 表：受訓人數、完成評量人數、可追蹤母數、有效回覆數、實際應用數及符合能力門檻人數；每個率都清楚寫分子、分母與缺失資料規則。
- 至少一條完整 `SYNTHETIC case_id` 證據鏈：學習目標／能力、訓練後基準、追蹤時間、工作情境、具體應用觀察、佐證索引、限制、檢討結論與後續改進；不得將自陳等同獨立佐證。
- 可直接使用的追蹤題項或觀察量尺，包含題目、答案尺度、觀察時點、判讀規則、未回覆／不適用處理及簡單結果示範。
- 一個明確的趨勢／分群分析和圖表；不得把合成資料描述成協會績效或 TTQS 官方分數，也不得宣稱課程造成無法歸因的結果。
- 具體發現、資料限制、決策／HOLD、改善工作項目、擬議責任角色、期限及再追蹤指標。
- `SYNTHETIC_REPLACEMENT_REGISTER`：對每一筆示範日期、人數、比例、案例、測量值、觀察、決策及佐證位置登錄 `fact_id`、`case_id`、段落／表格 locator、設值理由、真實替換來源、核驗角色與升格狀態。
- 明確拒收／HOLD：無真實來源而標 REAL；分母不清、未回覆未交代、跨期口徑不一致；自陳冒充佐證；樣本太小卻作因果推論；虛構協會核准／簽名／課程／學員／雇主成果；把合成指標當官方分數；或內容可替代 0058/0059 相鄰要求。
