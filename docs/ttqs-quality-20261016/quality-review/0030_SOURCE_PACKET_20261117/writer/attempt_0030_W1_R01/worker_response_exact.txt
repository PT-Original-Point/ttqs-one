<h1>工作經驗的相關受訓證明｜證據索引與取得規程</h1>
<div class="synthetic-banner">SAMPLE/SYNTHETIC — 本文件為候選版本（CANDIDATE），包含合成範例僅示範流程，不主張真實人員、雇主、資歷或成就。</div>

<p><strong>文件編號：</strong>0030</p>
<p><strong>需求識別：</strong>I06-E01</p>
<p><strong>版本狀態：</strong>CANDIDATE — 候選文件，僅供規格審查，不等同正式文件、真實原件或 REAL 替換。</p>
<p><strong>適用對象：</strong>協會作業人員，用於工作經驗／受訓證明之證據索引、取得、查核與保管流程導向。</p>

<h2>使用說明</h2>
<p><strong>何時使用：</strong>於 I06-E01 需求啟動時，或評核前進行索引建構與查核程序檢視。本文件適用於 I06-E01 之 157 格 Blueprint row 029 文類邊界。</p>
<p><strong>如何執行：</strong>依次參照本文件結構：「封面及狀態」「目的與範圍」「證據索引」「原件取得流程」「查核及結論規則」「異常處理」「SAMPLE/SYNTHETIC 流程案例」「REAL 替換登錄」。每個步驟均有明確輸入與輸出說明。</p>
<p><strong>預期輸出：</strong>完整的證據索引登錄（每項唯一 SYN-0030-* 識別碼）、取得狀態記錄、查核結果判斷（NO CLAIM / NOT VERIFIED 適用於 SAMPLE/SYNTHETIC 案例）、SAMPLE/SYNTHETIC 案例展示、異常處理記錄。</p>
<p><strong>狀態標記：</strong>CANDIDATE 級候選文件；SAMPLE/SYNTHETIC 案例標示合成性質，不得作為 REAL 資料使用或宣稱具備真實資歷、認可或成就。</p>

<ul>

<h1>目的與範圍</h1>

<p>本文件建立供訓練機構實際維護、供評核者抽查的「工作經驗／受訓證明索引與原件取得及查核流程」。使用者應能定位每件真實佐證的原始來源及頁碼，追蹤原件取得與來源核驗，並判斷資料是否與指定訓練角色／職務相關。</p>

<p>本文件本身不是證書、出勤證明、履歷、雇主證明、職能評估報告或機構能力說明；不得自行宣稱任何人曾任職、曾受訓或已符合職能。</p>

<h2>範圍界定</h2>
<ul>
    <li><strong>適用需求：</strong>僅 I06-E01。鄰近需求 0029（I05-E03）、0031（I06-E02）、0032（I06-E03）內容被明確排除，僅依官方checkbox行 029 為準。</li>
    <li><strong>文類邊界：</strong>157 格 Blueprint row 029「受訓與工作經驗：真實證明索引及取得規程，不偽造」所定義之文類。</li>
    <li><strong>crosswalk 對應：</strong>I06-E01│deliverable_count=1│deliverable_ids=0030│document_titles=工作經驗的相關受訓證明_可直接使用成品。</li>
    <li><strong>官方定位：</strong>TTQS 評核指標及常見參考佐證資料表，PDF 第 2 頁／印刷頁碼 2；指標 6「訓練機構的行政管理能力及訓練主管相關職能」；官方勾選文字：□ 工作經驗的相關受訓證明。</li>
</ul>

<h2>文件類型說明</h2>
<p>本文件屬「證據索引與取得規程」文類，而非成品 DOCX、證書或第三方證明。其目的是規範索引欄位、取得步驟、查核流程與異常處理，而非提供任何實際人員資料或能力結論。</p>

<h1>原件取得流程</h1>

<ol>
    <li><strong>確認需求：</strong>驗證 I06-E01 與 157 格 Blueprint row 029 之對應關係，確認官方勾選文字「工作經驗的相關受訓證明」。</li>
    <li><strong>確認資料保管者及合法授權：</strong>識別文件持有單位，確認合法授權文件或授權聲明。若無法確認授權，本欄位明列 UNKNOWN，並說明需授權文件方能進行。</li>
    <li><strong>實際索取並保存送出證據：</strong>向來源機構或雇主提出索取；收件登錄、核對完整性及定位。若原件未送達，記錄 NOT_RECEIVED 並說明追索條件。</li>
    <li><strong>收件登錄、核對完整性及定位：</strong>錄入證據索引，比對原始頁碼或定位（對應官方 PDF 第 2 頁、印刷頁碼 2）。若影本不完整，記錄不完全並說明補足條件。</li>
    <li><strong>以獨立且可追溯方式核對出具者和文件狀態：</strong>聯絡出具者、驗證文件狀態。若出具者無法聯絡或文件狀態不明，各自記錄 UNKNOWN、原因及允許的下一步；不得猜補。</li>
    <li><strong>比對對象、日期、內容及角色關聯：</strong>比對工作經驗描述、訓練課程、日期期間與指定角色之關聯。關聯性不足者，說明限制與不適用理由。</li>
    <li><strong>記錄查核結論、限制和覆核者：</strong>區分「文件被提及」「收到副本」「收到原件」「出具者核實」「內容相關」「職能已評估」。不把一種狀態合併成「已證明」；不由參訓紀錄直接推論任職、職能或績效。</li>
    <li><strong>依已證實的政策管理原件：</strong>依政策管理原件歸檔，註記保管位置及存取限制。</li>
</ol>

<p class="note">各步驟如遇未取得、出具者無法聯絡、內容不一致、影本不完整、授權未知、保存依據未知等情形，各自記錄 UNKNOWN、原因及取得條件。見下節「異常處理」。</p>
</div>

<!-- Page 5: Verification and Conclusion Rules -->
<div style="page-break-after: always;">
<h1>查核及結論規則</h1>

<p>區分以下狀態，並分別記錄：</p>

<ul>
    <li><strong>文件被提及：</strong>文件被參考或提及，但未收到實體或副本。</li>
    <li><strong>收到副本：</strong>已收到文件影本，但未收到原件。</li>
    <li><strong>收到原件：</strong>已收到原始文件。</li>
    <li><strong>出具者核實：</strong>出具者已確認文件真實性。</li>
    <li><strong>內容相關：</strong>文件內容與指定訓練角色或工作主張具備關聯。</li>
    <li><strong>職能已評估：</strong>已有職能評估報告或相關結論。</li>
</ul>

<p>關鋒原則：</p>
<ol>
    <li>不把一種狀態合併成「已證明」。</li>
    <li>不由參訓紀錄直接推論任職、職能或績效。</li>
    <li>每一主張（曾任職、曾參訓、出勤、結業）各自對應各自的證據，不得互相代替。</li>
</ol>

<p class="note">查核結果呈現時，SAMPLE/SYNTHETIC 案例決策為「NO CLAIM / NOT VERIFIED」；不得計為已具備證明或能力。</p>
</div>

<!-- Page 6: Exception Handling -->
<div style="page-break-after: always;">
<h1>異常處理</h1>

<p>下列情形各自記錄 UNKNOWN、原因及允許的下一步，不得猜補：</p>

<ul>
    <li><strong>未取得原件：</strong>記錄 UNKNOWN、原因（如：未提出索引、索取失敗、來源機構未回覆）及取得條件（如：需合法授權、需正式信函、需聯絡資訊）。</li>
    <li><strong>出具者無法聯絡：</strong>記錄 UNKNOWN、原因（聯絡方式過舊、機構已歇業）及允許的下一步（更新聯絡資訊、查詢相關協會）。</li>
    <li><strong>內容不一致：</strong>記錄 UNKNOWN、不一致處點及允許的下一步（覆核原始來源、補充說明）。</li>
    <li><strong>影本不完整：</strong>記錄 UNKNOWN、缺失處點及允許的下一步（索取原件、補充缺漏）。</li>
    <li><strong>授權未知：</strong>記錄 UNKNOWN、需求的授權依據及允許的下一步（取得授權文件）。</li>
    <li><strong>保存依據未知：</strong>記錄 UNKNOWN、保存期限的法律或政策依據及允許的下一步（查詢組織政策、法律諮詢）。</li>
</ul>

<p>每種情形皆不得填寫 0、推定事實或完成；必須明列 UNKNOWN 並說明需要何種 genuine source 支撐方能升級。</p>
</div>
