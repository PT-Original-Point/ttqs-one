## 第一節 施測目的與決策用途

### 1.1 工具目的與界線

本候選問卷供具直接工作觀察機會的雇主、主管或督導者描述受訓人員在特定任務中的所學運用情形。它收集的是受訪者在指定觀察期間的回報，並非獨立查證過的工作紀錄。

本工具評估工作情境中的技能使用、作業行為及可觀察的產出變化。它不是學員滿意度問卷、雇主感謝函、個人能力認證，也不能單獨證明訓練造成績效改變。工作表現可能同時受任務分派、設備、工作量、督導支持及其他環境因素影響。缺少訓前基線或直接觀察時，應選擇相應的98／99選項，不得推估改善。

### 1.2 回報可如何使用

問卷結果只能作為後續查證與討論的線索。下列均為候選工具提出的可選研討方向，不是官方門檻、協會現行規則或自動生效的決議：

1. 若多份合格回覆指出相同任務障礙，可核對課程單元、設備及實際工作要求是否相符，再評估是否調整教學內容或演練。
2. 若受訓人員表示有能力但缺少設備、任務機會或工作授權，可先釐清職場情境；未取得適當授權及受訪者同意前，不對雇主或第三方聯絡。
3. 若回覆呈現特定技能需求，可與課程文件、其他需求資料及可查核紀錄交叉檢視，再討論補充教材、工作指引或進階訓練。
4. 不以單一答卷、平均分數或本表的示範數據單獨作成停班、改聘、懲處、考績或對外成效宣稱。決策權責與程序未核實前，結論標為待確認。

## 第二節 對象、納入排除條件與倫理說明

### 2.1 填答對象資格定義
填答者應為雇主、雇主代表或直接工作指導者；職稱或任務指派本身不足以符合資格，仍須在明確觀察期間內親自觀察問卷「受訓人員代碼」所指的同一名受訓人員本人，執行至少一項與課程相關的工作任務。

### 2.2 納入與排除條件
為確保回饋資料具備第一手實務觀察基礎，避免臆測或非業務相關人員評估，所有回收之問卷均需依據下列客觀準據進行資格審查：

```
【受訪資格判定流程】
收件 ──> [審查 Q0：是否於觀察期間親自觀察受訓人員代碼所指的同一人執行相關工作任務？]
            │
             ├─ 1. 是 ───────────────> 進入後續題目
             ├─ 2. 否（受訪者本人明確勾選，不論原因） ─> 終止填答；列資格不符排除
             └─ 3. 無法確認／空白 ─────> 暫停待核（HOLD）＋補件，不得推定為「否」或排除
```

* **納入條件（必須全部符合）**：
  1. 受訪者於明確觀察期間內，親自觀察問卷「受訓人員代碼」所指的同一名受訓人員本人執行至少一項與課程相關的工作任務；只看其他同仁、只看完成品或只聽第三人轉述，不等同親自觀察執行。
  2. 受訪者能以第一手觀察說明該任務；不設定最低工作日數，也不要求受訪者必須指派或簽核該任務。
  3. 受訪者已閱讀施測前確認的用途說明，並在C1/C2同意欄選擇同意；未同意者停止。
* **資格排除、HOLD與補件（狀態不可互相替代）**：
  1. **唯一的立即資格排除條件**：只有受訪者本人明確勾選Q0「2. 否」才列候選資格不符排除，無論原因碼選擇或留白。文字摘要口徑為：只有受訪者明確勾選Q0=2才列候選資格不符排除。原因碼僅供描述，不限制明確Q0=2判定；原因碼03沿用表單文字「觀察到的工作與課程無關」。工作人員不得依職稱、排班或成果物代填或更改Q0。
  2. **只看成果物或無法確認**：未親自觀察同一受訓人員執行任務者應由本人選Q0=3或留白；表單列HOLD，僅邀請該受訪者本人澄清，不得由工作人員推定Q0=1或2。
  3. **身份或必要資料不完整**：受訓人員代碼缺漏／不符、受訪者代碼、填答日期、觀察期間缺漏，或欄位互相矛盾時列HOLD。受訪者代碼、填答日期或觀察期間缺漏時依核准方式啟動補件程序；核實前不逕行排除或納入。Q0選「3. 無法確認」或空白者維持暫停待核（HOLD），不得推定為否。工作人員核對指定對象及欄位完整性；資格答案只能由受訪者本人補答。

### 2.3 倫理規範、資料保護與施測前必要條件

本候選工具提出以下資料保護與使用原則。本次施測未取得可核實的現行保存政策、回收管道或用途授權文件；這是證據狀態 UNKNOWN，不代表協會沒有相關規範。

1. **發放前確認**：由有權人員確認調查用途、受訪者說明文字、回收方式、可讀取資料的人員、保存期限及刪除方式。任一項尚未確認，狀態標為 HOLD，先不發放、不收集資料。
2. **減少可識別資料**：本表單設計不要求姓名、身分證號、個人電話、住址或個人電子郵件。使用的代碼可能與其他資料連結，應稱為「代碼化資料」，不可稱為匿名資料。
3. **後續聯絡**：本問卷不收聯絡方式。只有施測前已明確告知、受訪者同意，且有經核准並與答卷分開管理的聯絡方式，才可另行聯繫；條件未確認時不追蹤。
4. **用途邊界**：本工具建議用於檢視課程與工作情境的銜接，不單獨用作學員懲處、考績或訓練成效保證。此為候選工具的建議條件，不代表協會已有該政策；實際用途須先由有權人員確認並向受訪者說明。若無法做到，暫停施測。

## 第三節 構面定義及題目對照

本問卷以工作情境中的直接觀察為核心，包含受訪者同意欄、1道資格閘門、10道回饋題及必要的代碼／日期欄位。各項是本工具的設計，並非官方新增評分細項。

* **構面 A：任務使用與獨立程度（Q1、Q2）**：記錄所學是否用於相關工作任務及所需支援程度。
* **構面 B：行為與整體工作變化（Q3、Q5）**：只有存在可比較的訓前觀察基線時，才判斷變化。
* **構面 C：工作品質比較與回答依據（Q4、Q8）**：Q4先指定單一且同口徑的品質指標；Q8僅記受訪者自述的觀察或資料類型，不表示原件已核實。
* **構面 D：課程實用性與觀察信心（Q6、Q7、Q9、Q10）**：回饋有用內容、主要脫節類型及對應單元、觀察信心與獨立後續接洽意願。

> **【算術示範說明】**  
> 本小節之數據為極小樣本（發放 2 份、回收 2 份）之算術步驟演練，**純供展示計算公式與編碼排除規則，樣本數極低，嚴禁作為推論母體或評價辦訓成效之依據**。

##### 1. 回收率與有效分析占比計算：
* 截止時所有實際收到的表單計入N_returned，並以互斥狀態核對：N_returned=N_valid+N_excluded+N_stopped+N_hold。
* N_valid：同意與資格已核實、身份及必要欄位相符且沒有未解HOLD的答卷；個別題目仍可缺答。N_excluded：受訪者本人明確Q0=2。N_stopped：C1/C2不同意或依核准程序停止處理的已收表單。N_hold：截止時仍待本人澄清或待核的已收表單。
* N_corecomplete是N_valid中Q1–Q5真正空白少於2題的子集，用於五題完整摘要，不是互斥狀態的另一加項；98、99等明確非數值碼不算空白但不進平均。
* 示範發放邀請數（N_sent）=2份【SAMPLE/SYNTHETIC】；示範回收總數（N_returned）=2份【SAMPLE/SYNTHETIC】。
* N_valid=1（SYN-RESP-01）；N_excluded=1（SYN-RESP-02）；N_stopped=0；N_hold=0；N_corecomplete=1。核對2=1+1+0+0，且N_corecomplete屬N_valid。
