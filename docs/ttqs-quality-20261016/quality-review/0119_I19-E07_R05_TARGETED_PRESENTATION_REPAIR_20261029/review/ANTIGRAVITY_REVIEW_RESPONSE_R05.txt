### 4. 合成數值、公式、期程、解釋與數學一致性
- **定位**：第三單元 3.3 節、第四單元 [TABLE 3]、第七單元 7.1 節。
- **數學驗算核對**：
  - **目標市場**：
    - 基線期（2025Q1）：$n=8, N=20 \implies P = \frac{8}{20} \times 100\% = 40.0\%$（回覆/納入率 $20/20 = 100.0\%$）。
    - 比較期（2025Q3）：$n=12, N=25 \implies P = \frac{12}{25} \times 100\% = 48.0\%$（回覆/納入率 $25/25 = 100.0\%$）。
    - 差異量：$\Delta P = 48.0\% - 40.0\% = +8.0\text{ 個百分點 } (+8.0\text{ pp})$。
  - **顧客價值**：
    - 基線期（2025-01班）：發放 20，有效 $N=16 \implies$ 回覆率 $16/20 = 80.0\%$；分子 $n=10 \implies P = \frac{10}{16} \times 100\% = 62.5\%$。
    - 比較期（2025-03班）：發放 25，有效 $N=20 \implies$ 回覆率 $20/25 = 80.0\%$；分子 $n=15 \implies P = \frac{15}{20} \times 100\% = 75.0\%$。
    - 差異量：$\Delta P = 75.0\% - 62.5\% = +12.5\text{ 個百分點 } (+12.5\text{ pp})$。
  - **小樣本敏感度解析**：第七單元 7.1 節指出「單一受試者（1 人）之答案變更即會造成 4.0 至 6.3 個百分點之劇烈波動」（$1/25 = 4.0\%$, $1/16 = 6.25\% \approx 6.3\%$），驗算完全吻合。
  - 全文數值、符號、四捨五入（小數點後第一位）與百分點差算式無任何矛盾。
