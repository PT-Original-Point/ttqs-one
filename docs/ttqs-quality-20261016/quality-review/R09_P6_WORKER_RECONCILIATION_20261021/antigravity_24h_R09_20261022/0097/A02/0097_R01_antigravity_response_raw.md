### 第一章 施測目的、決策用途與倫理界限

#### 1.1 施測目的與評估意圖
在非營利組織與志工培訓之實務運作中，訓練成效往往難以僅憑一次性結業測驗或課後滿意度分數衡量。本項問卷調查工具之目的，在於建立客觀、可操作且能兼顧「內部反思」與「外部觀察」之雙軌評估機制，直接驗證：
1. **學員自評能力轉變**：受訓學員能否在結訓後，明確指出自己在關鍵服務情境下的處理能力相較於課前有具體提升。
2. **目標客戶／觀察者實質感受**：受服務之社區長者、合作單位督導或目標對象代表，是否觀察到學員於活動企劃、溝通協調與突發安全應變等面向之行為表現進步。
3. **訓練要素歸因**：探討能力提升之轉變在何種程度上可歸因於本會提供之課程教學、實務演練或督導回饋，排除外部隨機因素之干擾。

#### 1.2 決策用途與管理回饋迴路
本工具所產出之分析數據，其最終目的並非僅為應付評核，而是實質銜接本會小型培訓團隊之持續改善決策：
- **教學設計改善**：若特定構面之後測分數未達標，或學員與客戶反饋在該構面未見改善，則該單元之教材、教學演練時數或講師授課方式必須列入修訂。
- **志願服務派遣把關**：評估結果若顯示學員在「安全應變與通報記錄」構面尚未達獨立運作成熟度（分數未達 3 分以上），行政團隊得安排資深志工實施一對一伴跑或補救訓練，方可正式排班。
- **年度開班資源配置**：結合客戶觀察者之質性建言，精準調整年度訓練計畫中情境演練課程之權重。

#### 1.3 評估對象與分層抽樣界定
本調查將評估母體嚴格劃分為互不重疊之兩大群體，嚴禁混為一談：
1. **學員層（Learners）**：實際完成全期訓練之受訓志工或學員。
2. **目標客戶／合作單位觀察者層（Clients / Observers）**：包含受服務機構之承辦窗口、在地社區合作幹部、受訓者之資深督導，或於情境模擬演練中扮演需求對象並進行實體互動之代表。

#### 1.4 倫理原則、知情同意與自願參與
為落實人權保障與學術調查倫理，本調查落實以下原則：
- **知情同意優先**：每份表單首題均設為「知情同意確認」。填答者若未勾選同意，系統或紙本作業即刻終止，答卷列為「無效答卷」，不納入後續統計。
- **填答自願與退出權**：明確告知填答者本問卷不影響個人考核、結業資格或志工職務權益，填答者於繳交前均有權中止填寫。
- **基本資料最小化**：除確認填答者角色類別（學員或觀察者）及追蹤代碼外，不收集個人身分證字號、私人生日、精確住址等無關隱私個資。

#### 1.5 匿名編碼與資料保護安全規範
鑑於本會為精簡型組織架構，採用最嚴謹而易於執行之「去識別化追蹤代碼（De-identified Tracking Code）」機制：

### 第二章 能力構面定義與行為錨定評分量尺（BARS）

#### 2.1 三大核心能力構面定義
為避免傳統問卷流於主觀抽象，本工具聚焦於社區服務與演練中最關鍵之三項實務行為構面（Dimensions）：
- **構面 A：辨識服務需求並寫出可觀察目標**
  指學員面對受服務對象（如社區長者、弱勢學童或照顧者）時，能否透過傾聽與觀察，精準提煉其核心需求，並將其轉化為具體、可測量、可觀察之服務活動目標。
- **構面 B：將目標轉成活動步驟與資源配置**
  指學員能否將既定之服務目標，拆解為邏輯清晰之執行時程、分工步驟，並妥善配置志工人力、教具物資與場地動線等實體資源。
- **構面 C：依風險情境調整流程並說明通報與記錄**
  指在活動執行現場面臨突發狀況（如人員身體不適、情緒激動、天候異動或設備故障）時，學員能否依標準作業流程動態調整步驟，並正確落實緊急通報機制與填寫事故／處置紀錄。

#### 2.2 五等級行為錨定評分量尺（BARS 1–5 分）
本量表揚棄模糊之「非常滿意／非常同意」用詞，採用客觀可驗證之行為錨定描述（Behaviorally Anchored Rating Scales），供學員自評與客戶觀察對齊標準：

| 評分級別 | 標籤名稱 | 行為錨定標準定義與可觀察特徵 |
| :---: | :---: | :--- |
| **1 分** | **無法說明／完成** | 面對該任務時完全無法掌握要領，無法說明處置步驟，亦無法在引導下完成任務。 |
| **2 分** | **需逐步提示** | 具備基礎概念，但無法獨立進行；必須在督導、講師或同儕給予逐步口頭提示或手把手示範下始能完成。 |
| **3 分** | **依核對表完成常見情境** | 能夠在標準情境下，對照檢核表、操作手冊或作業指引，獨立且正確地完成常態性工作步驟。 |
| **4 分** | **可獨立完成常見情境** | 無需查閱手冊或提示，即可在常見之實務情境中獨立完成任務，流程流暢且符合規範。 |
| **5 分** | **可處理變化並說明判斷** | 面對罕見、複合或突發之變化情境時，能冷靜判斷關鍵問題，靈活調整處置作法，並清晰向利害關係人說明其專業判斷之理由與依據。 |

#### 2.3 「未觀察／無法判斷（N/O）」非數值代碼之處理嚴格限制
在實務施測中，目標客戶或觀察者常因未全程參與特定演練階段，或學員自評時有無法判斷之情形。本規範特設專用代碼：
- **專屬代碼**：`N/O`（Not Observed / Cannot Judge，未觀察／無法判斷）。
- **嚴格計算禁忌**：**`N/O` 絕對不可登錄為數值 0，亦不得任意填補平均數或參與加總計算！** 遇 `N/O` 答卷時，在該題項之統計計算中，應將該員自「該題配對分母」中完全剔除，僅以實際具備評分之有效樣本數計算。
- **留白（Blank）之本質差異**：空白未填答屬於「漏答／缺答（Missing Data）」，代表填答者遺漏或拒絕作答；`N/O` 則為填答者行使明確之「無法判斷」選項。二者在資料編碼上必須嚴格分立（留白編碼為 `BLANK` 或 `NA`），絕不可混為一談。

#### 2.4 學員「回溯前測（Retrospective Pre-test）」之設計原理與限制說明
傳統成效評估若在課前與課後分別發放前測與後測，常因學員於課前「不知自己所不知」，給予自身過高評價；結訓後因眼界開闊、認知標準提升，反而導致後測自評分數低於課前，此即教育測驗學上著名之「反應轉移偏誤（Response Shift Bias）」。
- **回溯前測設計**：本問卷於訓練結束時，讓學員同時站在結訓後的統一認知標準下，回顧評估「自己在受訓前（課前）」之實際能力水準，並評定「完成受訓後（課後）」之能力水準。
- **方法學限制與偏差防範**：回溯前測之主要限制在於「記憶偏誤（Recall Bias）」以及「自我美化傾向（Social Desirability Bias）」。因此，學員自評數據絕對不能作為唯一決策依據，必須與目標客戶／合作單位觀察者之客觀評估相互參照、交叉驗證。

#### 2.5 目標客戶／合作單位觀察者配對作答資格篩選機制
外部觀察者之評估若要具備有效性，其前提為該觀察者「必須確實具備課前基準觀察與課後演練觀察之實質經驗」。
- **資格過濾題**：觀察者問卷第三題設有強制跳題機制。若觀察者勾選「否，我未具備受訓前之互動或觀察基準」，則系統或紙本指引其**完全跳過**後續三個構面之「課前／課後配對評分題」，直接進入課後整體觀察、質性反饋與建議章節。
- 此舉嚴禁無基準之外部人士憑空猜測課前分數，確保配對樣本之純淨度與方法學嚴謹性。

### 第四章 施測作業標準程序（SOP）與資料治理

為確保精簡編制下調查作業之嚴謹度與可重複執行性，本會規範標準施測與資料處理作業程序如下：

```
施測母體與名冊建立 ──> 發放與獨立收繳 ──> 有效性審查與編碼 ──> 統計分析與異常標記 ──> 決策回饋與改善
  (落實去識別化代碼)      (紙本密封/獨立表單)     (排除同意空白/漏答)     (嚴禁將 N/O 計為 0)     (教案修訂/補救訓練)
```

#### 4.1 施測母體界定與名冊準備
- 訓練承辦人員應於開課前，依核定之參訓學員名冊與合作單位出席名冊，編列「去識別化追蹤代碼對照清冊」。
- 學員與目標客戶名冊分開造冊，嚴禁混雜。每一代碼僅對應一位特定人員。

#### 4.2 發放時點、途徑與填答時間
- **學員問卷**：於情境演練結束、講師完成整體回饋點評後立即發放。現場保留 8 至 12 分鐘專用填答時間，填妥後由學員自行投入「不透光之問卷密封回收箱」，講師與督導均行迴避，以防填答壓力。
- **目標客戶／觀察者問卷**：於演練結束後由行政承辦人員當面致送或於 48 小時內寄發獨立填答連結，由觀察員於 3 日內完成回傳。

#### 4.3 承辦、覆核與輔助角色之建議職責分配
本會內部採行建議性雙人覆核分工（實際簽署須依本會正式組織章程與授權指派辦理）：
1. **訓練行政承辦人（建議職責）**：負責代碼配發、問卷印製發放、回收清點、將原始數據錄入 CSV 工作表，並執行無效卷之初步篩選與標記。
2. **訓練主管／業務覆核人（建議職責）**：覆核 CSV 錄入數值是否與原始答卷一致，審查無效問卷剔除標準，檢核公式運算結果，並依據分析結果擬具訓練改善決策方案。

#### 4.4 原始答卷收繳、重複作答與無效問卷剔除規則
為確保統計品質，嚴格遵守以下篩選規則：
1. **知情同意未勾選者一律剔除**：若 Q1 或 CQ1 勾選不同意或留白未勾，該答卷立即列為「無效答卷（Invalid）」，不得進行任何分數錄入。
2. **配對項目未具備任一完整配對者剔除**：答卷若在構面 A、B、C 之三個配對項目中，全部出現留白漏答或單邊漏答，導致無任何一題可進行「前／後比較」者，整份列為無效答卷。
3. **重複回覆處理**：若同一代碼出現兩次回覆，以「第 1 份完整有效之回覆」為準，第 2 份標記為「重複件（Duplicate）」存檔備查，不計入分母。
4. **有效答卷（Valid Form）嚴格定義**：必須同時滿足「角色類別正確」、「知情同意清楚勾選同意」，且「A、B、C 三大構面中至少具備一項完整前後配對分數」之表單。

#### 4.5 試測（Pilot Testing）修訂機制與施測暫停／退件條件
- **試測機制**：本工具於新班次正式全面推行前，應先由 2 至 3 位資深學員與 1 位友好合作夥伴進行題目易讀性試測，確保語意無歧義後始得大量印製。
- **施測暫停與退件條件**：
  - 若發放過程中發現問卷印刷瑕疵（如缺頁、量尺漏印），應立即暫停回收並全面重新發放。
  - 若特定班次之有效回收率低於 60%，或無效問卷比例超過 30%，該批次調查報告應予退件，不得逕行產出結案結論，承辦人須檢討施測說明程序並提請重新調查或補測。

#### 4.6 資料保管、存取權限與保存年限核定指引
- 原始紙本問卷及已去識別化之電子檔案，應列冊歸檔。
- 其保存年限、銷毀程序與調閱授權，「須依協會正式核定之檔案管理政策設定」。在未正式頒布專門規章前，應以專卷加密妥善保存至少 3 年，以備後續教學品質稽核之需。

#### 5.5 各構面均值、前後差值與配對變化重算展示

本會針對學員自評與客戶觀察分別建立獨立計算矩陣，**嚴禁將兩群體分數混合平均**。所有分母、分子與四捨五入計算過程逐一校對如下：

##### 5.5.1 受訓學員層（有效樣本 $N=8$ 人，共 24 個前後配對項目）
1. **構面 A（辨識服務需求並寫出可觀察目標）**：
   - 課前總分：$2+3+2+3+2+3+2+3 = 20$ 分；課前平均 = $20 / 8 = 2.50$ 分。
   - 課後總分：$4+4+3+4+3+4+3+2 = 27$ 分；課後平均 = $27 / 8 = 3.375 \rightarrow 3.38$ 分。
   - 均值差值：$3.375 - 2.50 = +0.875 \rightarrow +0.88$ 分。
2. **構面 B（將目標轉成活動步驟與資源配置）**：
   - 課前總分：$2+2+3+3+2+2+3+2 = 19$ 分；課前平均 = $19 / 8 = 2.375 \rightarrow 2.38$ 分。
   - 課後總分：$4+3+3+4+2+3+4+3 = 26$ 分；課後平均 = $26 / 8 = 3.25$ 分。
   - 均值差值：$3.25 - 2.375 = +0.875 \rightarrow +0.88$ 分。
3. **構面 C（依風險情境調整流程並說明通報與記錄）**：
   - 課前總分：$3+2+2+2+2+3+3+2 = 19$ 分；課前平均 = $19 / 8 = 2.375 \rightarrow 2.38$ 分。
   - 課後總分：$4+4+3+3+3+4+4+3 = 28$ 分；課後平均 = $28 / 8 = 3.50$ 分。
   - 均值差值：$3.50 - 2.375 = +1.125 \rightarrow +1.13$ 分。
4. **學員 24 個配對項目總體彙總**：
   - 課前 24 項總分：$20 + 19 + 19 = 58$ 分；課前總平均 = $58 / 24 = 2.41667 \rightarrow 2.42$ 分。
   - 課後 24 項總分：$27 + 26 + 28 = 81$ 分；課後總平均 = $81 / 24 = 3.375 \rightarrow 3.38$ 分。
   - 配對總平均差值：$81/24 - 58/24 = 23 / 24 = +0.95833 \rightarrow +0.96$ 分。
5. **學員配對項目變化趨勢分布（共 24 對）**：
   - **能力提升（上升）**：共 21 項，佔比 = $21 / 24 = 0.8750 \rightarrow 87.50\%$。
     （逐項明細：L01 的 A/B/C 全升(3)；L02 全升(3)；L03 的 A/C 升(2)；L04 全升(3)；L05 的 A/C 升(2)；L06 全升(3)；L07 全升(3)；L08 的 B/C 升(2)。$3+3+2+3+2+3+3+2 = 21$ 項）。
   - **能力維持不變（持平）**：共 2 項，佔比 = $2 / 24 = 0.08333 \rightarrow 8.33\%$。
     （逐項明細：L03 構面 B 課前 3 $\rightarrow$ 課後 3 (1項)；L05 構面 B 課前 2 $\rightarrow$ 課後 2 (1項)）。
   - **能力自評反降（下降）**：共 1 項，佔比 = $1 / 24 = 0.04167 \rightarrow 4.17\%$。
     （逐項明細：L08 構面 A 課前 3 $\rightarrow$ 課後 2 (1項)）。
   - 總和檢核：$21 + 2 + 1 = 24$ 項；$87.50\% + 8.33\% + 4.17\% = 100.00\%$。
6. **學員課程貢獻度均值**：

   - 平均值 = $26 / 8 = 3.25$ 分（滿分 4 分，介於「主要關聯」與「關鍵決定性」之間）。

#### 5.7 小樣本分析限制與方法學邊界說明
本示範分析奠基於小規模試行樣本（學員有效 8 人、客戶有效 4 人），本會特此闡明統計方法學上之限制：
- **禁止過度推論**：本樣本數過小，不進行、亦不能進行 t 檢定或迴歸模型等推論統計（Inferential Statistics），所有差值與百分比僅為「描述性統計（Descriptive Statistics）」，嚴禁宣稱為全體志工母體之因果必然性。
- **指標獨立判讀**：學員自評平均（+0.96）與客戶觀察平均（+0.83）各自代表主觀學習獲益與外部行為驗證，雙方分數絕不合併計算單一總平均，以保持雙軌視角之獨立性。

### 第六章 評估結果轉化為訓練管理決策

評估數據若未導向行政行動，則失去調查意義。依據上述示範數據之計算結果，本會擬定以下三項標準決策與處置方針：

#### 6.1 決策矩陣與指標門檻（成效達標判定 vs 改善作為）
本會設定之內部訓練成效監控標準如下：
1. **整體成效達標門檻**：學員與客戶端之構面均值差值均應 $\ge +0.50$ 分，且配對提升比例應 $\ge 70\%$。
   - *本案判定*：學員差值 +0.96（提升率 87.50%）、客戶差值 +0.83（提升率 75.00%），顯示本次演練在整體層面「達到預期能力提升門檻」。
2. **單一構面落後預警門檻**：若特定構面之外部觀察後測均值 $< 3.00$ 分，或均值差值 $< +0.60$ 分，觸發「教案強化程序」。
   - *本案判定*：客戶端對「構面 C（風險應變與通報）」之課後平均僅 2.75 分，均值差僅 +0.50 分。顯示外部人士認為志工對於非預期突發事件之應變處理仍顯生疏。
