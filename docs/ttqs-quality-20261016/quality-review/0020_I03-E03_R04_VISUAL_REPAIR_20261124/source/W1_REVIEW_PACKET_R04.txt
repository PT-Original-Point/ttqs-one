陸、核對、計算與一致性判定
一、關鍵績效指標（KPI）量化計算定義字典
1. KPI-01 專業技術檢定合格率（Professional Skill Certification Rate）
• 對應訓練類型：TYPE-A 專業核心職能類
• 促進機制意涵：透過精密技術實作與模組考核，提升學員實務操作精準度，直接促進產業專業人才即戰力比率。
• 指標計算公式：
KPI-01 =（達 SAMPLE 術科評量門檻之人數 ÷ D01（符合該指標之結訓學員））× 100%
• 計量單位與四捨五入：百分比（%），計算結果四捨五入至小數點後第一位。
• 分子定義：本示例為術科成績達 80／100 分的人數（SYN-0020-TH01；僅 SAMPLE，非通用或機構核定標準）。
• 分母定義：該班次符合機構核定受訓出勤門檻之結訓學員總人數；本例為 D01=30（SAMPLE，假設等於 N_total），實際出勤門檻與名冊須依機構核定資料核實；對應 SYN-0020-DEN01。
• N/A 條件：若該班次無實作檢定考核機制（純理論講授），本指標不適用，應改列為一般課堂評量指標。
2. KPI-02 專案實作成果評核達標率（Project Implementation Rate）
• 對應訓練類型：TYPE-B 管理與組織領導類
• 促進機制意涵：訓練學員具備專案排程控管、團隊溝通與風險管理能力，以實務專題改善報告作為結案評量，促進受訓企業流程優化指標。
• 指標計算公式：
KPI-02 =（本示例專題成績達 80／100 分的人數 ÷ D02（完成專案評核者））× 100%（SAMPLE 門檻 SYN-0020-TH02）
• 計量單位與四捨五入：百分比（%），取至小數點後第一位。
• 分子定義：本示例為專題評分達 80／100 分的人數（SYN-0020-TH02；僅 SAMPLE，非通用或機構核定標準）。
• 分母定義：提出專題作品並完成評核之學員總人數；本例為 D02=25（SAMPLE，假設全部參訓者均完成評核），實際值依評核名冊核實；對應 SYN-0020-DEN02。
• N/A 條件：個人自願退選專題審查或未全程參與組別討論者，列為異常註記，不計入合格分子。
3. KPI-03 數位工具實務應用滿意度（Digital Application Satisfaction Rate）
• 對應訓練類型：TYPE-C 數位轉型與實務應用類
• 促進機制意涵：針對數位軟體操作、雲端協同與資安防護應用，透過即測即評與實務操作問卷，評估學員對數位工具回崗應用之滿意比率。
• 指標計算公式：
KPI-03 =（「具體有助於工作應用」題目評分達 4／5 分的人數 ÷ D03（依核定規則判定之有效問卷份數））× 100%（滿分 SYN-0020-SC01；門檻 SYN-0020-TH03，均僅 SAMPLE）
• 計量單位與四捨五入：百分比（%），取至小數點後第一位。
• 分子定義：本示例以 5 分量表中評分達 4 分的人數計算（SYN-0020-SC01、SYN-0020-TH03；僅 SAMPLE，非通用標準）。
• 分母定義：依機構核定的有效問卷判準，計入可核實回收的問卷份數；本例 D03=45（SAMPLE，假設45份均符合有效規則），實際值依問卷與核定規則核實；對應 SYN-0020-DEN03。本工作稿不把未核定的剔除門檻視為通用規則。
• N/A 條件：有效性判準未取得機構核定文件前標示 UNKNOWN；不得自行採用漏答比例或同選項作為正式排除規則。
4. KPI-04 法定證照測驗通過率（Statutory License Passing Rate）
• 對應訓練類型：TYPE-D 法規遵循與安全認證類
• 促進機制意涵：以適用課程的正式測驗結果及可核實取證資料觀察學員達標情形；本指標本身不等於法規遵循結論，也不據此宣稱事故結果。
• 指標計算公式：
KPI-04 =（依適用正式成績判定通過的人數 ÷ D04（符合應試資格且有正式報名／應試紀錄者））× 100%
• 計量單位與四捨五入：百分比（%），取至小數點後第一位。
• 分子定義：依適用主管機關或正式測驗／證照核發單位所公布的當期合格判定，且有可核實結果紀錄的人數；實際適用標準及來源在取得前均為 UNKNOWN，本稿不預設分數或證書。
• 分母定義：依適用規則符合應試條件且有正式報名或應試紀錄的人數；本例 D04=20（SAMPLE，假設全部參訓者均符合資格並有紀錄），實際資格及來源在取得前為 UNKNOWN；對應 SYN-0020-DEN04。
• N/A 條件：受訓期間因個人因素缺課遭退訓而無法應考者，排除於應考分母外，但須於退訓清冊登錄（缺課時數門檻依主管機關規定，本稿不預設）。
二、示範數據逐步驗算（Reproducible Recomputation）
本節展示表二合成案例之逐步算例，證明運算過程透明可重算（所有數值均為 SAMPLE，目標值對應 SYN-0020-TG01~TG04）：
【算例一：SYN-0020-001 機電整合實務班】
• 輸入參數：班次參訓母數 N_total = 30 人；KPI分母 D01 = 30 名符合指標之結訓學員（SAMPLE 假設，SYN-0020-DEN01）；合格人數 N_pass = 28 人；目標門檻 = 90.0%（SYN-0020-TG01，SAMPLE）。
• 計算過程：
實績值 =（28 ÷ 30）× 100% = 93.3333...% → 四捨五入 → 93.3%
• 差異比較：Δ = 93.3% − 90.0% = +3.3%。
• 判定：實績值 ≥ 目標值，符合 TYPE-A 促進專業核心能力之預期成效（SAMPLE）。
【算例二：SYN-0020-002 專案管理實務班】
• 輸入參數：班次參訓母數 N_total = 25 人；KPI分母 D02 = 25 名完成專案評核學員（SAMPLE 假設，SYN-0020-DEN02）；達標人數 N_pass = 23 人；目標門檻 = 85.0%（SYN-0020-TG02，SAMPLE）。
• 計算過程：
實績值 =（23 ÷ 25）× 100% = 92.0000% → 取至小數點一位 → 92.0%
• 差異比較：Δ = 92.0% − 85.0% = +7.0%。
• 判定：實績值 ≥ 目標值，符合 TYPE-B 促進專案治理績效之預期成效（SAMPLE）。
【算例三：SYN-0020-003 數位辦公資安班】
• 輸入參數：班次參訓母數 N_total = 45 人；KPI分母 D03 = 45 份依核定規則判定有效之問卷（SAMPLE 假設，SYN-0020-DEN03）；滿意人數 N_pass = 42 人；目標門檻 = 90.0%（SYN-0020-TG03，SAMPLE）。
• 計算過程：
實績值 =（42 ÷ 45）× 100% = 93.3333...% → 四捨五入 → 93.3%
• 差異比較：Δ = 93.3% − 90.0% = +3.3%。
• 判定：實績值 ≥ 目標值，符合 TYPE-C 促進數位工具應用轉型之預期成效（SAMPLE）。
【算例四：SYN-0020-004 職安主管認證班】
• 輸入參數：班次參訓母數 N_total = 20 人；KPI分母 D04 = 20 名符合應試資格且有正式紀錄者（SAMPLE 假設，SYN-0020-DEN04）；取證人數 N_pass = 19 人；目標門檻 = 95.0%（SYN-0020-TG04，SAMPLE）。
• 計算過程：

• 判定：實績值達到設定標準，符合 TYPE-D 促進法定合規之嚴格標準（SAMPLE）。
