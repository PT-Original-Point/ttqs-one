## 4. 行政說明與流程

### 4.1 發放對象與寄送時機

- **對象**：已結業且同意受追蹤者。問卷本身含「無機會（N/O）」選項，故**無機會者不被排除，而是被如實記錄**。
- **寄送時機**：以 A3 為第 0 日，於 A3 後滿所選天數的當日寄送；核對條件為 A5−A3＝A4。示範：2026-08-15 後滿 **INT-30（30 天）**，於 **2026-09-14 寄送**，**2026-09-21 截止**。

### 4.2 追蹤間隔選項與記錄（對應需求清冊所列 30／60／90／180 天及「其他」）

| 代碼 | 選項 | 建議選用時機（設計建議，非政策） |
| --- | --- | --- |
| `INT-30` | 30 天 | 高頻、日常性行為之短期一致性（本示範採用） |
| `INT-60` | 60 天 | 中頻行為、需一段時間累積案例 |
| `INT-90` | 90 天 | 一般工作週期、多數服務型行為 |
| `INT-180` | 180 天 | 低頻、季節性或需跨期才出現之情境 |
| `INT-OTHER` | 其他（自填天數） | 需附選用理由 |

- **一致化要求**：同一課程、同一波次應採**同一** `interval_days`；如不同，須逐份記錄理由。
- **必填欄位**：`interval_days`（整數天數）、`send_date`、`due_date`、`reminder_dates`（可多筆）、`return_status`。
- **`return_status` 允許值**：`NOT_RETURNED`／`RETURNED_INCOMPLETE`／`VALID`／`INVALID(排除理由)`。**不得**以空白代替狀態。

> **日期檢核**：以 A3（課程結束日）至 A5（實際寄送日）之日數差核對 A4 所選間隔；差距超過 2 天始標記「間隔異常」。A6（填答日）晚於 A5 屬正常，**不得**誤判為間隔異常；惟 A6 逾 A5 之截止日（`due_date`）時另標 `LATE`，且**不得**改寫 A4 之追蹤間隔。
> 示範檢核：A3 2026-08-15 → A5 2026-09-14 恰為 30 天，符合 `INT-30`；A6 2026-09-15 在 `due_date` 2026-09-21 之內，標記正常。

### 4.3 提醒、回收與狀態登錄

| 節點 | 動作 | 登錄欄位 |
| --- | --- | --- |
| 寄送日 | 發送問卷 | `send_date` |
| 寄送後 +3 日 | 第一次提醒（示範：2026-09-17） | `reminder_dates` |
| 寄送後 +6 日 | 第二次提醒（示範：2026-09-20，截止日前） | `reminder_dates` |
| 截止日（示範為寄送後 +7 日） | 截止收件、統計回收 | `due_date` |
| 每份回收 | 登錄 `return_status` | `return_status` |

- **未回收（`NOT_RETURNED`）**：**不得**計為 0、**不得**計為有效。
- **已回收未完成（`RETURNED_INCOMPLETE`）**：依第 5.3 節完整性規則判為 `INVALID`，或退回請其補齊。
- 提醒**不改變**分母定義。

**逐人追蹤登錄（作業者使用；一人一筆）**：案件／匿名代碼＿＿＿＿；同意及範圍＿＿＿＿；追蹤間隔＿＿天；寄送日＿＿＿＿；截止日＿＿＿＿；提醒一＿＿＿＿；提醒二＿＿＿＿；填答／回收日＿＿＿＿；狀態（`NOT_RETURNED`／`RETURNED_INCOMPLETE`／`VALID`／`INVALID`）＿＿＿＿；退回原因及補件日＿＿＿＿。未回收者仍保留狀態，不補造回覆。

| 值 | 定義 |
| --- | --- |
| `4` | 每週 3 次以上（高頻） |
| `3` | 經常（每週 1–2 次） |
| `2` | 偶爾（每月 1–3 次） |
| `1` | 很少（每月 <1 次） |
