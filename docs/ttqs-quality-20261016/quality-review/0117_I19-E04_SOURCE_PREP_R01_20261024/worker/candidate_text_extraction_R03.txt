學員考照通過率追蹤及分析表
文件 0117｜官方需求 I19-E04｜Blueprint 內部索引 128｜候選版 R03
1. 文件識別、目的與狀態
1.1 文件管制欄（封面/控制區塊）
全表之學員、分數、考試代碼、日期、門檻、結果及增減值皆為 SAMPLE/SYNTHETIC 示範，不是協會實際績效、因果、顯著性或任何正式接受結論。真實通過率、真實增加、真實證據狀態一律 UNKNOWN／HOLD。
1.2 目的
本表為可直接使用之操作性考照／證照成果追蹤與分析工具，供小型協會之訓練管理員與複核人：
1. 凍結符合資格之學員樣本群（cohort），固定分母；
2. 分別登錄每位資格學員之首次應試（first sit）與補考（retake）日期、分數與結果；
3. 在設定的 90 天窗口內追蹤「最終通過（eventual pass）」；
4. 對帳原始證據、標記缺件、缺考與未知結果；
5. 計算四項指標、記錄複核、決策、行動與再檢日期。
1.3 明確不適用事項
本表不是：就業追蹤調查（見 0116/I19-E03）、滿意度表、學員心得或知識分享證據（見 0115/I19-E02）、證照本身、或「協會考照通過率確有提升」之宣稱。其標題被隱藏時，其內容應仍可辨識為考照／證照後續追蹤工具。
2. 官方對應與使用說明（讀者）
讀者與用法：
訓練管理員（承辦）：負責凍結樣本群、登錄應試紀錄、收集與查證發證機構結果、更新本表。
獨立複核人：不參與登錄；負責重算指標、核對分母對帳、抽核原始證據、簽署複審與公開用語。
注意：官方條目指向的問題是「口稱通過率有增加，但未有具體紀錄及評量」。本表的用途正是把「口稱」轉為可查證之紀錄、分母與評量，而非證明增加已經發生。
3. 適用範圍、定義與指標字典
3.1 範圍
適用：協會自辦或委辦訓練班次結訓後，學員報考指定證照／考試之結果追蹤期間。
計算對象：經樣本群凍結確認資格之學員（ELIGIBLE），不做任何事後挑選。
換班、跨期、同名不同人：一律回到凍結表處理，不得事後增刪。

3.3 指標字典（四级指標：分子、分母、公式、納入/排除規則）
對帳恆等式（複核必查）：
首次有效應試人數 = 首次 PASS + 首次 FAIL + 首次 UNKNOWN。
合格樣本群人數 = 首次有效應試人數 + NO_ATTEMPT 人數（凍結後不得變動）。
最終通過人數 = 首次 PASS 人數 + 補考由 FAIL 轉 PASS 之人數（每人計 1 次）。
補考紀錄只進 M3/M4 的分子轉換，永不直接加進任何分母。
3.4 舍位規則
各比率以未舍位值計算差值，最後以一位小數、四捨五入呈現；若舍位差與未舍位差不同，以未舍位差舍位為準並加註。
