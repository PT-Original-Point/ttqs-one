## 第二章 衡量目的、核心指標界定與邊界排他性原則

### 2.1 衡量目的

本評量系統旨在協助本會（非營利社團法人志工團體）在推動非醫療性之「原始點觀念教育與自我照護推廣」時，能夠客觀驗證所研發或發布之學習資源是否：
* 真實契合目標對象現階段最迫切的自學需求（市場端需求匹配）；
* 使學習者在實際接觸資源後，能獨立且正確地獲取核心知識要點並辨識知識界限（顧客端實質效用）。

### 2.2 雙軌核心指標操作型定義

為避免主觀認定，本規範建立兩組獨立之二元二分（Binary: 0 或 1）測量變數，其定義如下表：

| 指標名稱 | 代碼 | 操作型定義與判定規則 | 計分方式 | 嚴格禁止事項 |
| :--- | :---: | :--- | :---: | :--- |
| **目標市場主題契合度**<br>（Market-Topic Fit） | `M_FIT` | 受測者於指定調查問卷中，自多項日常照護議題中，將本會推廣之特定核心範例主題指認為「個人目前優先且迫切需要之學習項目」。符合者計為 1，其餘或未填者計為 0。 | 二元變數<br>（0 或 1） | 嚴禁以「我覺得協會很棒」等主觀好感替代實質主題需求勾選。 |
| **顧客價值任務達成率**<br>（Customer-Value Task Success Rate） | `C_VAL` | 受測者在取得指定學習手冊/影音教材後，能在 5 分鐘內獨立完成標準三步驟檢索任務（定位章節、複述要點、指認界限）。三步驟全數通過者計為 1，任一步驟失敗計為 0。 | 二元變數<br>（0 或 1） | 嚴禁將「三步驟達成」膨脹為主觀滿意度或宣稱具備臨床醫療成效。 |

### 2.3 核心觀念排他性邊界（什麼不是市場與顧客價值）

在 TTQS 查核體系中，評核委員極度重視各指標之邊界劃分。志工行政人員在填寫與判定時，必須嚴格遵守以下排他性原則：

```
┌────────────────────────────────────────────────────────────────────────┐
│                   指標 19（I19-E01）本質邊界確認圖                      │
└────────────────────────────────────────────────────────────────────────┘
  [外部市場需求契合 (M_FIT)]  ─┐
                               ├─► 本文件核心範圍（I19-E01 目標市場與價值改善）
  [教材實用檢索能力 (C_VAL)]  ─┘
  ────────────────────────────────────────────────────────────────────────
  [學員課後滿意度調查]        ──► 屬於 Level 1 反應評量（不可替代外部市場價值）
  [課後學術紙筆測驗成績]      ──► 屬於 Level 2 學習評量（不可單獨等同實用價值）
  [協會歷年會員總人數變化]    ──► 屬於 0113 / I18-E22 會員人數追蹤（無關單一方案價值）
  [內部知識庫系統運作紀錄]    ──► 屬於 0115 / I19-E02 知識分享流程（非市場外部回饋）
  [協會整體能量自我評估表]    ──► 屬於 0100/0101 / I18-E08 組織能力評估
  [官網首頁瀏覽量/點擊次數]   ──► 屬於 0109 / I18-E17 資訊系統使用頻率（無需求轉移）
```

> [!CRITICAL]
> **絕對防混淆警告**：滿意度（「老師講得很精彩」、「場地很舒服」）純屬服務感受，絕不等於市場定位成功；本評量表不採納任何單純滿意度分數作為市場價值佐證。

## 第三章 標準化資料收集流程與母體抽樣作業程序

為確保未來進入真實施測階段（REAL SOURCE COLLECTION）時，數據具備高度可信度與可稽核性，特訂定標準收集程序。

### 3.1 目標受眾與抽樣母體設定

* **目標市場區隔定義（Target Segment）**：設籍或居住於屏東地區、年滿 20 歲、對日常自主健康生活保健具學習意願、且在過去 3 個月內未曾擔任本會內部核心行政幹部之一般民眾或學員。
* **抽樣名冊（Sampling Frame）**：本會推廣課程公開報名清冊或社區非臨床宣導講座登記名單。
* **樣本規模最低要求**：示範樣本數為 10 位（配對受測者代碼 `SYN-P01` 至 `SYN-P10`）；未來進入正式實施時，各梯次有效配對樣本數不得少於 10 份，以維持最低可查核性。

### 3.2 納入與排除標準（Inclusion / Exclusion Criteria）

```
受測個案接觸
  │
  ├─► [年齡未滿 20 歲 / 非目標生活圈 / 本會全職核心幹部] ──► 排除（註記：資格不符）
  │
  ├─► [無法配合前後期（T0 與 T14）追蹤者] ────────────────► 排除（註記：無法配對）
  │
  └─► [符合基本資格並簽署資料分析同意書]
        │
        ├─► 基期（T0）前測施測（問卷調查 + 任務實作檢測）
        │     │
        │     └─► 發生中途退出、作答不全或拒絕實作 ─────► 轉入 HOLD 暫存狀態
        │
        ├─► 間隔期（14 天推廣自學或資源優化介入）
        │
        └─► 後期（T14）後測施測（相同標準工具複測）
              │
              └─► 複核完成 ─────────────────────────────► 列入 VALID 最終有效樣本
```

### 3.3 施測時點與週期規範

1. **基期施測（T0 Baseline）**：於受測者首次接觸特定學習專案、或教材改版前夕進行。同一受測者在同一時點完成「主題契合度問卷」及「三步驟實作任務觀察」。
2. **介入與使用觀察期**：標準間隔為 14 天（記為 T14）。受測者於日常生活中運用本會提供之公版非臨床指引或影音專題。
3. **後期施測（T14 Follow-up）**：於介入後第 14 天，由相同標準規準對同一受測者進行後測，以取得嚴格配對資料（Paired Observations）。

### 3.4 職責分工與權責角色（無虛構個人姓名）

* **施測執行志工（Authorized Test Administrator）**：負責發放問卷、計時並客觀記錄三步驟實作行為，簽名需使用正式登記之「志工職務代碼」。
* **數據複核志工（Quality Reviewer）**：負責比對前後期個案編號一致性、重新核算分母與百分比、執行 HOLD 審查。
* **專案核定主管（Association Approver）**：負責於正式實施後核定決策處置；目前本候選稿中標註為 `REAL UNKNOWN / PENDING_REAL_SOURCE`。

本會作為基層志工團體，在資料收集與管理上，必須落實資料最小化原則，杜絕任何侵犯個人隱私或洩漏機敏資料之風險。

### 11.1 個人資料最小化與去識別化（Data Minimization & De-identification）

1. **去識別編碼原則**：所有進入評量之原始紀錄，全面採用去識別代碼（如 `P-001`、`P-002`），禁止直接在分析表上書寫學員姓名、身分證字號、電話、電子郵件或住址。
2. **編碼對照表獨立保管**：真實身分與代碼之對照索引表，應獨立列印為實體紙本，由指定管理志工加密存放於協會實體公文櫃，嚴禁上傳雲端或置於公開資料夾。
3. **健康與病歷隱私禁令**：本調查專注於「自學教材之文字檢索與觀念理解」，嚴禁在調查表中收集受測者之個人病歷、診斷證明、用藥史、身體隱私部位照片或任何臨床醫療資訊。

### 11.2 權限控管與保存年限原則

* **存取權限**：僅限負責 TTQS 評量作業之專案志工及複核人員具備查閱原始問卷之權限。
* **保存與銷毀年限**：本候選稿**不捏造**未經授權之法定年限（如任意宣稱保存 5 年或 10 年）。真實保存期限應由本會理監事會依正式公文與內部個資規章核定之 `PENDING_REAL_POLICY` 為準；期滿後依規範進行銷毀碎紙並填寫銷毀紀錄。

### 11.3 外部評核公開揭露遮蔽控制（Public Disclosure Suppression）

向外部委員展示評核佐證時，應實施以下保護措施：
* 所有展示樣張一律進行遮蔽（Masking），隱匿受測者筆跡特徵及可能辨識身分之環境特徵。
* 評核委員現場查閱時，僅提供去識別化之清冊與統計圖表；如需查核原始紙本，應於協會辦公室現場隨行陪同閱覽，嚴禁拍照外流。
