## 第 1 章　目的、適用範圍與名詞

### 1.1 目的

建立訓練相關活動的內部稽核與外部稽核之作業程序，使每一次稽核都有：可追溯的範圍與準則、可核對的證據、可重算的判斷、可交接的紀錄，以及在發現不符合時的矯正與結案路徑。

### 1.2 適用範圍

- 對象：本機構辦理之訓練課程、訓練紀錄、講師與學員管理、教材與場地、訓練成效與矯正處理等作業。
- 期間：年度例行稽核、週期性稽核、專案稽核，以及外部稽核／第三方查核之受理與回覆。
- 對象不含：財務簽證、法律遵循之專屬查核（另依其專業程序），本件僅在訓練相關範圍內與之銜接。

### 1.3 名詞定義

| 名詞 | 定義 |
| --- | --- |
| 內部稽核 | 由本機構內部、對被稽核活動無直接責任之人員，依既定準則查核訓練活動並留痕。 |
| 外部稽核 | 由本機構以外之機關、認證／查核單位或受託第三方，依其程序對本機構進行之查核。 |
| 稽核準則 | 判斷符合與否所依據之文件、法規、標準或程序（須可指出版本與出處）。 |
| 母體（population） | 稽核範圍內可被抽樣的全部紀錄或項目總數。 |
| 樣本 | 自母體中依規則選出、實際受測的項目。 |
| 證據 | 足以支持符合或不符合結論之文件、紀錄、訪談或觀察，須註明來源與取得時間。 |
| 發現（finding） | 由證據支持、經事實確認之不符合或觀察事項。 |
| 判斷閘門（decision gate） | 進入下一步驟前必須通過的判定點；未通過即 HOLD、REJECT、升級或重開（見第 6 章）。 |
| HOLD | 因資料不足、未確認或待原件，暫停該步驟並保留現況，不得逕行結論。 |
| REJECT | 因來源不可辨識、遭竄改或超出範圍，退回該項，不予採用。 |
| 升級 | 將未能在期限內或超逾權限處理之事項，向上層權責角色呈報。 |
| 重開 | 結案後發現矯正無效或同一不符合再次出現時，重新開啟該發現之處理。 |

### 1.4 排除事項

本文件不包含：真實稽核結果之公布、獎懲決定、對外法律承諾、第三方原件之代製，以及未經本機構核可之保存年限。凡上述項目，本文件僅提供索引、欄位與取得路徑。

## 第 2 章　內部稽核與外部稽核之區別

| 面向 | 內部稽核 | 外部稽核 |
| --- | --- | --- |
| 發起者 | 本機構（管理代表核定） | 外部機關或第三方 |
| 主導者 | 本機構指派之稽核員 | 外部稽核員 |
| 準則來源 | 本機構程序、官方要求、標準 | 外部機關之要求與其準則 |
| 通知義務 | 內部發通知給受稽核單位 | 受理外部通知，確認範圍與時程 |
| 本文件角色 | 完整執行（第 5 章） | 受理、陪同、提供證據、回應（第 8 章） |
| 紀錄歸屬 | 稽核紀錄組（內部） | 受理紀錄＋外部正式報告原件索引 |

關鍵區別：內部稽核由本機構控制全程；外部稽核由外部主導，本機構的職責是「受理、配合、回應、留痕」，不得代替外部主體製作其正式文件或結論。受理（intake）僅是本機構依第 8 章登錄並準備，本身不是一次已完成之外部稽核；兩者不得混為一談。

#### 5.1.1 建議風險評分方法（SAMPLE/PROPOSED—NOT APPROVED；尚待本機構核定）

本方法僅為規劃與範圍選樣用之**建議草案**，供 F-072-01 填寫；**不得視為已核定之制度**，所有分數、級距、帶狀（banding）與門檻均須經本機構核定後方可正式採用。

- **風險分數**＝可能性（likelihood）1–3 × 影響（impact）1–3，得分範圍 1–9。
- **可能性（likelihood）1–3 之定義**：
  - 1＝低：現有控制可合理防止，過去週期無相關不符合。
  - 2＝中：偶有缺失或控制未完全落實，可能有個別不符合。
  - 3＝高：控制不足或反覆缺失，極可能發生不符合。
- **影響（impact）1–3 之定義**：
  - 1＝低：僅影響個別紀錄之格式，不影響訓練有效性。
  - 2＝中：影響紀錄完整性或部分訓練流程，可於期限內矯正。
  - 3＝高：影響訓練有效性、紀錄可信度或違反強制要求，或具立即性風險。
- **建議帶狀（banding；各帶狀均須核定）**：
  - 低風險：分數 1–3。
  - 中風險：分數 4–6。
  - 高風險：分數 7–9。
- **立即性風險排除條款**：凡涉及人員安全或證據完整性之立即性風險，一律**立即升級**，且**不得以平均分數或帶狀帶過（cannot be averaged away）**；此類風險不因總分偏低而降級。
- **選樣與範圍之運用**：高風險項目原則上納入稽核範圍並採較嚴抽樣（如全查或加大樣本）；中、低風險得採分層或隨機抽樣。選樣決策與核定須一併載明於 F-072-01。

## 第 6 章　判斷規則、例外矩陣、分級與升級

### 6.1 主判斷樹

1. 準則與母體清單是否齊備？　否 → HOLD，補件；是 → 續。
2. 稽核員有無利益衝突或能力未獲佐證？　是 → 迴避／改派（HOLD 至改派完成）；否 → 續。
3. 證據是否可辨識來源且可核對？　否 → REJECT 該證據；是 → 續。
4. 測試結果是否有不符合？　否 → 記符合，續；是 → 開立發現並依 6.4 分級。
5. 事實是否經受稽核單位確認？　否 → HOLD，待確認；是 → 發布報告。
6. 回應是否含有效矯正與期限？　否 → 退回補正；是 → 追蹤。
7. 矯正是否驗證有效？　是 → 結案提案（送 MGMT-REP 核定）；否 → 重開。

### 6.2 例外矩陣

| 例外情境 | 風險 | 處置 | 升級時限（SAMPLE/PROPOSED—NOT APPROVED） |

### 6.3 REJECT／HOLD／升級／重開 判準

- **REJECT**：來源不可辨、內容已遭修改且不可還原、超出稽核範圍。
- **HOLD**：資料待補、事實未確認、獨立性未解決、能力未獲佐證、原件未取得。
- **升級**：逾期、超權限、發生立即性風險、發現具爭議、外部要求補件未決。
- **重開**：結案後發現矯正無效，或同一不符合再次出現；重開須重新進入事實確認（5.6）並記錄重開理由。

| --- | --- |

| 一般 | 程序未落實但未造成訓練失效，且可於期限內矯正。 |
| 觀察 | 未構成不符合，但有改善空間。 |

## 第 8 章　外部稽核受理與回覆流程

本章區分「受理（intake）」與「一次實際外部稽核」。受理只是本機構內部登錄、確認與準備；**受理本身不是外部稽核，也不產生任何外部結論或第三方原件。**

### 8.1 受理與實際外稽之區別

| 面向 | 受理（intake） | 實際外部稽核 |
| --- | --- | --- |
| 主體 | 本機構 ADMIN／AUD-LEAD | 外部機關或第三方（EXT-AUD） |
| 產出 | 受理紀錄、原件索引、準備清單 | 外部正式報告（外部主體製作） |
| 本機構角色 | 登錄、核對、準備、陪同 | 配合、提供證據、回應 |
| 是否可代製 | 不可 | 不可（原件僅能由外部主體出具） |

### 8.2 受理流程

1. 收件：收到外部通知或要求，由 ADMIN 登錄 F-072-08。
2. 核對：核對來文主體、範圍、準則、期程與所需證據。
3. **真實性查核**：核對原件簽章、發文主體、文號、日期與防偽特徵；無法核對者標 `UNKNOWN/HOLD`，不得引用。
4. 判定：能否依原件核對？不能者標 `UNKNOWN/HOLD`。
5. 指派：MGMT-REP 指派陪同與回應之角色（AUD-LEAD、ADMIN）。
6. 準備：彙整所需證據，維持來源可辨。
7. 陪同：外部稽核期間提供證據並記錄往來。
8. 回應：就外部正式報告要求之事項回覆，不代替外部製作其正式文件。
9. 結案：外部正式報告原件歸入原件索引。

### 8.3 原件與真實性查核規則

- 須取得外部機關出具之**原件（含簽章之通知或報告）**方可核對；未取得原件前，所有相關欄位維持 `UNKNOWN/HOLD`。
- 不得以任何方式製作、複製或推定第三方原件；不得由本機構代擬外部結論。
- 真實性查核至少涵蓋：發文主體一致性、文號、日期、簽章／電子簽章、格式與防偽特徵。
