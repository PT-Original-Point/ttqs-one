## 6. 可重算的出席/評量算法

本節所有公式均以一般文字式呈現，未使用未轉換的 LaTeX。

### 6.1 出席率算法（SYN-0021-FRM01）

公式：出席率（%） = 實際出席時數 / 應出席時數 × 100%

- MOD01：6 / 6 × 100% = 100.00%
- MOD02：4 / 4 × 100% = 100.00%
- MOD03：3 / 4 × 100% = 75.00%
- 全程：(6 + 4 + 3) / (6 + 4 + 4) × 100% = 13 / 14 × 100% = 92.86%

### 6.2 評量總分算法（SYN-0021-FRM02）

公式：總評分 = (MOD01 得分 + MOD02 得分 + MOD03 得分) / 3

= (85 + 78 + 70) / 3 = 233 / 3 = 77.67 分

### 6.3 達標判定算法（SYN-0021-FRM03）

門檻（本示例自訂值，非官方標準）：

- SYN-0021-THR01：單模組出席率 ≥ 80%
- SYN-0021-THR02：單模組評量 ≥ 75 分
- SYN-0021-THR03：總評分 ≥ 75 分

判定規則：

- 單模組達標 = (出席率 ≥ 80%) 且 (評量得分 ≥ 75 分)
- 整體達標 = (所有模組單模組達標) 且 (總評分 ≥ 75 分)

判定結果：

- MOD01：100.00% ≥ 80% 且 85 ≥ 75 → 達標
- MOD02：100.00% ≥ 80% 且 78 ≥ 75 → 達標
- MOD03：75.00% < 80% 且 70 < 75 → 未達標
- 整體：未達標（MOD03 未達標）
