## 二、R04 Blueprint 的具體衝突

R04 原始列 `BLUEPRINT_ROW_0010_I02-E01_R04.json` SHA-256 `47b3387d2f97aeed2b42efe602ffcc9070c664d2e9da4a119d50d378354d3236` 正確保留了官方要求、0010、學員評核標準及兩個負向近鄰；但下列欄位與官方來源及項目 008 不相容：

1. `required_fields_or_questions` 要求對外承諾、例外核准權及公開揭露版本，這些不是 I02-E01 學員成果評核的直接要求。
2. `required_calculations_or_analysis` 寫成「政策檢討完成率」，不能代表學員評核標準、評分示例或評估結果。
3. 文件正文以 `F-05 CONTROL_SCOPE_CONFLICT` 宣告不改 Blueprint，讓工程爭議文字出現在第一頁，降低協會可讀性。
4. R04 `SOURCE_BINDING_R04.json` 記錄的 Blueprint file SHA `406d0495…` 與 row SHA `3d818171…` 均未能和本次讀回的 R04 JSON 原始位元組 SHA 對上；未找到其對應原始檔，故此歷史綁定維持 UNKNOWN，不移植為 R05 證據。

## 三、R05 範圍決定

R05 以官方 PDF 與現行項目 008 為上位來源：0010 是「學員成果評核標準＋完整 SAMPLE 評分與分析示例」。保留標準文件所需題本、答案鍵、實作量規、權重、分母、門檻、評分示範、複評控制與替換清冊；補上真正由這些資料支持的評估報告內容，包括樣本納排、逐項結果、差距排序、限制、改善建議、責任角色及追蹤指標。

R05 明確排除組織年度績效目標（0009/I01-E06）、訓練政策／產品／市場定位、對外承諾與公開揭露、政策檢討完成率；不建立新文件，不更改 `0010` 或 `I02-E01`，不把未命名「其他」轉成新交付件。

## 五、數學核對基線（不是將不同 SHA 的 QA 合併）

R04c 既有示例數據可重算：知識 20 分、P 40 分、C 25 分、M 15 分，總計 100 分；通過條件為總分 ≥70、知識 ≥12、實作 ≥28、P3 ≥3。首次 SYN-003 為 17 + 17.50 + 22.50 + 12.50 = 69.50，未達總分、實作及 P3 條件；同版複評 17 + 27.50 + 22.50 + 12.50 = 79.50，仍因實作未達 28 而 NOT_PASS。首次 SYN-004 為 11 + 30 + 22.50 + 11.25 = 74.75，但知識與 P3 未達；複評 14 + 32.50 + 22.50 + 11.25 = 80.25，四個示範門檻達標。這些僅是合成示例，不代表實際協會成果；任何改動需由 R05 全量重新計算。
