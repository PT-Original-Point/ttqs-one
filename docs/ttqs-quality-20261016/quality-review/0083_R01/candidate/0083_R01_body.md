# DOCX 0083 學員行動計畫追蹤紀錄
## 目標、實際、阻礙、協助與結果判定的逐次紀錄

本紀錄供志工服務培訓承辦在學員完成課程、需要把學習成果轉為可觀察的訓後行動計畫時啟用，也在每一次追蹤日、協助需求出現、目標期限屆至，或日期與證據出現疑義時使用。它支持的核心決定是：依目前可定位且經授權的證據，這項行動計畫應繼續追蹤、提供協助、修正目標、暫時凍結、退回補正、重新查核，或如實結案為達成、部分達成、未開始、無機會。

請不要把它當成課程滿意度問卷、個人績效考核、課程結案報告、0082 訓後行為轉移問卷，或 17c 其他佐證的替代品。它的價值在於把每一次「目標與實際的差異」說清楚，並把阻礙、協助、證據、責任與下一步接起來。

## 2. 文類定位、適用界線與不建立的事項

### 2.1 本件在 17c 中的位置

17c 行為評估包含多種獨立佐證。本件只處理「個別學員行動計畫的設計與逐次追蹤」，不把其他文類合併進來。

| 17c 佐證類型 | 主要內容 | 與本件的關係 |
|---|---|---|
| 訓後動態問卷 | 反應、學習或行為轉移的問卷調查 | 另件，不併入 |
| 個人行動計畫與追蹤 | 個別目標、實際、阻礙、協助、成效 | 本件 DOCX 0083／089 |
| 派訓主管觀察量規 | 由派訓主管觀察行為 | 另件，非本件必備；090 亦獨立 |
| 知識社群記錄分析 | 社群互動與知識分享 | 另件 |
| 神秘客或外部稽核 | 外部查核方法 | 另件 |

### 2.2 適用與不適用

| 適用 | 不適用 |
|---|---|
| 一位學員、一個課程脈絡、一個可觀察行動目標 | 團體平均、課程滿意度、組織績效 |
| 志工服務或模擬服務情境中的訓後實作 | 未經授權的第三人個資或真實服務對象紀錄 |
| 需要逐次記錄目標與實際差異 | 主管考核、員工督導、績效排名 |
| 需要把協助、證據、責任與下一步連在一起 | 0082 訓後行為轉移問卷、090 主管評估、知識社群、神秘客 |
| 需要如實判定 HOLD、RETURN、REVISE、REVERIFY | 主張訓練因果或保證成效 |

同一學員有多個行動目標時，應使用多份 G1 或子案號，不得把多個目標塞進同一列。若涉及真實服務情境，只能記錄去識別後的行動與計數，不得寫入服務對象的姓名、聯絡方式、健康、家庭或其他可識別資訊。

### 2.3 本文件不建立以下事項

- 不證明課程造成行為改變，也不證明服務對象受益。
- 不建立正式接受、協會政策、期限變更或任何已生效的決定。
- 不建立協會設有服務站、門市、受僱員工、主管督導或實際服務場域。
- 不把學員自述轉成客觀成效，也不把協助提供轉成因果證明。
- 不把 SAMPLE/SYNTHETIC 值轉成真人紀錄。
- 不是 0082 的受訪者、轉介或個案，也不是 0082／088／090 的替代。
- 不以空白表單交差；沒有實質內容、示範或結果判定，就不能作為本項佐證。

### 3.2 角色與責任

| 角色代碼 | 主要工作 | 不可以做 |
|---|---|---|
| ROLE-LEARNER | 執行行動、提供自述、確認資料 | 不能代替追蹤角色填寫客觀結論 |
| ROLE-TRACKER | 建表、記錄、檢查日期與算術、安排追蹤 | 不能兼任考核者或正式接受者 |

### 3.3 日期與順序規則

- T1 必須晚於 T0，Tn 必須晚於前一次追蹤。
- 下次追蹤日期必須晚於本次追蹤日期；未定時填 PENDING。
- G1 的目標期限必須晚於 T0。
- 不得回溯填寫或事後改寫日期；發現倒置或矛盾時，標 REVERIFY，保留原值與更正註記。
- 期限調整需求以新的 AID 追加記錄，不得直接改寫原期限。

### 5.4 狀態碼與判讀

| 狀態 | 使用時機 | 不要用來表示 |
|---|---|---|
| ACHIEVED | 目標已達成，且有可定位、經授權的證據 | 只有數字過門檻，證據仍不足 |
| PARTIAL | 有進展，但仍有落差、協助未結或證據不足 | 學員失敗 |
| NOT_STARTED | 有執行機會，本期實際增量為 0，且沒有待處理協助 | 沒有機會 |
| NO_OPPORTUNITY | 客觀上沒有執行機會，且有紀錄可說明 | 0 次完成或學員不努力 |
| NEEDS_ASSIST | 已提出協助但尚未提供，進度因此停滯 | 學員未盡責 |
| HOLD | 資料、分母、授權或證據不足，暫不能判定 | 已達成 |
| RETURN | 表單或證據可補正，退回補件 | 拒絕學員 |
| REVISE | 目標、分母、期限或方法需要修正 | 事後改寫成績 |
| REVERIFY | 日期、算術、證據或跨文件事實有矛盾，需要重查 | 最終結論 |
| PASS-SAMPLE | 僅供示範對照的數值篩選（PROPOSED SAMPLE ONLY） | 協會政策或真實成效 |

### 5.5 分母為 0 與無機會的處理

本期計畫增量為 0 時，本期達成率一律填 N/A，不得寫成 0% 或 100%，也不得留白。累計分母（目標值）為 0 或不明時，不得輸出百分比，整份標 HOLD 並補明分母來源。

沒有執行機會不等於 0 次完成。應標 NO_OPPORTUNITY，寫明可佐證的原因，例如場地未安排、服務時段取消或對象臨時變更；不得把該期直接當成學員失敗，也不得為了讓數字好看而靜默修改分母。若因此需要變更目標或分母，應走 REVISE 或 REVERIFY，保留原值與修正理由。

## 6. 協助需求與責任紀錄（Form-A1）

### 6.1 追加規則

## 9. 量化規則與算例

### 9.1 同一單位與同一分母

基準值、目標值與實際值必須使用同一量尺、同一計數口徑與同一區段長度。本案例一致採「次／28 天」：基準期 28 天 4 次，目標期 84 天 12 次，每 28 天計畫增加 4 次。口徑不同時，先標 RETURN，不得直接比較。

### 9.2 公式

- 累計差 = 實際累計 − 計畫累計。
- 本期計畫增量 = 本次計畫累計 − 上次計畫累計。
- 本期實際增量 = 本次實際累計 − 上次實際累計。
- 本期達成率 = 本期實際增量 ÷ 本期計畫增量。
- 累計達成率 = 實際累計 ÷ 目標值。

### 9.3 本期與累計的差別

| 指標 | 分子 | 分母 | 回答什麼 | 不能回答什麼 |
|---|---|---|---|---|
| 本期達成率 | 本期實際增量 | 本期計畫增量 | 這一段期間的執行節奏 | 整體是否達成 |
| 累計達成率 | 實際累計 | 目標值 | 目前累計進度 | 是否成功、是否為因果成效 |

本期與累計必須分開寫。不能因為累計比率較高，就忽略本期落後；也不能因為某一期達到 100%，就宣稱整體達成。

### 9.4 SAMPLE/SYNTHETIC：算例

| 項目 | T1 | T2 | T3 |
|---|---|---|---|
| 日期 | 2026-04-03 | 2026-05-01 | 2026-05-29 |
| 計畫累計 | 4 | 8 | 12 |
| 實際累計 | 3 | 7 | 10 |
| 累計差 | -1 | -1 | -2 |
| 本期計畫增量 | 4 | 4 | 4 |
| 本期實際增量 | 3 | 4 | 3 |
| 本期達成率 | 3 ÷ 4 = 75.0% | 4 ÷ 4 = 100.0% | 3 ÷ 4 = 75.0% |
| 累計達成率 | 3 ÷ 12 = 25.0% | 7 ÷ 12 = 58.3% | 10 ÷ 12 = 83.3% |

### 9.5 分母為 0 與無機會

本期計畫增量為 0 時，本期達成率填 N/A，不得以 0% 或 100% 代替，也不得留白。累計目標值為 0 或不明時，不得計算累計百分比，整份標 HOLD。

沒有機會不是零完成。若客觀上沒有執行機會，標 NO_OPPORTUNITY 並寫明原因；不得把該期直接當成學員失敗。若因此要變更分母或目標，必須走 REVISE 或 REVERIFY，不得靜默修改。

### 9.6 日期驗證

- T1 必須晚於 T0。
- T2 必須晚於 T1，T3 必須晚於 T2。
- 下次追蹤日期必須晚於本次追蹤日期。
- 目標期限必須晚於 T0。
- 日期倒置、重複或與課程事實矛盾時，標 REVERIFY，保留原值並加註更正理由。
