## 2. 衡量口徑與公式

**主要單位**：一件完成並送最終檢驗的產品。若同一件有多個缺陷，主要「不良件數」只計一件；缺陷原因表採每件一個主要缺陷分類，另有缺陷事件數時必須分欄，不混算。

**同範圍分母**：同期間、同產品族、同檢驗版次、已完成最終檢驗的產品單位數。檢驗覆蓋不足、產品族或判準改變、未檢件未說明時不得直接比較。

- 不良件數 = 符合已凍結判準之「不同產品單位」數。
- 不良率(%) = 不良產品單位數 ÷ 同範圍受檢產品單位數 × 100。
- 每百件不良數 = 不良率(%)；報表均以百分比呈現，不把缺陷事件數當產品件數。
- 前後差（百分點）= 訓後不良率 − 訓前不良率；負值代表觀察到下降。
- 相對下降率(%) = (訓前不良率 − 訓後不良率) ÷ 訓前不良率 × 100。訓前為 0 時列 N/A，不除以零。
- 前後彙總採各期間分子、分母加總後重算，不以各期百分比的簡單平均取代加權彙總；同時保留各期資料以顯示趨勢。
- 數值四捨五入到小數 1 位顯示；差異計算先用未四捨五入值，最後顯示 2 位百分點／1 位百分比。

## 4. 其他影響及因果界線

合成案例設定：檢查表版次與缺陷判準保持不變；訓後期間另外引入紙型裁切導板且材料批號改變。這兩項變化均是 SYNTHETIC；它們可能影響缺陷率，因此結果只能寫「此合成資料呈下降趨勢」，不能稱下降由訓練造成、不能稱統計顯著，也不得上推為協會績效。還須檢查產品組合、檢驗者判定一致性、檢驗覆蓋率、返工／報廢是否漏列、季節與批次差異。

原因分類按「每個不良產品單位一個主要原因」填列，故訓前 6+4+3=13、訓後 3+3+2=8；若實務上允許一件多原因，另設缺陷事件表並明示事件數不得與不良件數相加。
