### 5.2 核心指標之數學公式庫（Explicit & Reproducible Formulae）

#### 1. 問卷回收率（Returned Rate, $R_{\text{ret}}$）
$$R_{\text{ret}} = \frac{\text{回收問卷總份數 } (N_{\text{returned}})}{\text{已送達／交付邀請數 } (N_{\text{invited}})} \times 100\%$$
*口徑說明：表示實際回收份數相對於邀請數的比例；不能單獨解讀為配合程度或代表性。*

#### 2. 回收有效率（Validity Rate among Returned, $R_{\text{val}}$）
$$R_{\text{val}} = \frac{\text{有效問卷總份數 } (N_{\text{valid}})}{\text{實際回收問卷總份數 } (N_{\text{returned}})} \times 100\%$$
*口徑說明：描述回收問卷中符合預先核定有效規則的比例；此比例本身不能證明題目或填答說明的品質。*

#### 3. 題項滿意度平均數（Mean Score, $\bar{X}_j$）
$$\bar{X}_j = \frac{\sum_{i=1}^{N_{\text{valid}, j}} X_{ij}}{N_{\text{valid}, j}}$$
*式中 $X_{ij}$ 代表第 $i$ 位有效填答者在第 $j$ 個題項之得分（1～5分）；$N_{\text{valid}, j}$ 為排除該題填寫 `N/A` 後之有效填答人數。四捨五入計算至小數點後第二位。*

#### 4. 滿意度正向率（Positive Response Rate, $P_j$）
$$P_j = \frac{N_{\text{positive}, j} \ (X_{ij} \in \{4, 5\})}{N_{\text{valid}, j}} \times 100\%$$
*式中分子為評等為 4 分或 5 分之有效人數。四捨五入計算至小數點後第一位。*

#### 5. 訓後成果達成率（Follow-up Outcome Rate, $R_{\text{outcome}}$）
$$R_{\text{outcome}} = \frac{\text{符合成果門檻之人數 } (N_{\text{pass}})}{\text{實際可評估之追蹤人數 } (N_{\text{evaluable}})} \times 100\%$$
*口徑說明：僅能以完成追蹤實作評量之有效配對樣本人數為分母。未受測者不得設為 0 分納入，亦不得假設其未達標。*

#### 6. 成效相對變化率（Relative Change Rate, $\Delta_{\text{rel}}$）與絕對差距（Absolute Difference, $\Delta_{\text{abs}}$）
$$\Delta_{\text{abs}} = \bar{Y}_{\text{post}} - \bar{Y}_{\text{pre}} = \frac{\sum Y_{\text{post}}}{N_{\text{paired}}} - \frac{\sum Y_{\text{pre}}}{N_{\text{paired}}}$$
$$\Delta_{\text{rel}} = \frac{\bar{Y}_{\text{post}} - \bar{Y}_{\text{pre}}}{\bar{Y}_{\text{pre}}} \times 100\% = \frac{\sum Y_{\text{post}} - \sum Y_{\text{pre}}}{\sum Y_{\text{pre}}} \times 100\%$$
*防護警示（N/A Guard）：若前測基準均分 $\bar{Y}_{\text{pre}} = 0$，相對變化率無數學意義，系統輸出為 `N/A`，嚴禁標註為無窮大或虛構百分比。*

**統一精度與四捨五入規則**：先保留完整原始分子、分母及未四捨五入中間值，再依下列位數呈現；採一般四捨五入，禁止以已四捨五入的中間值再計算。R_ret、R_val、R_outcome、正向率及 Δ_rel 以百分比表示時四捨五入至小數點後 1 位；題項平均數及 Δ_abs 四捨五入至小數點後 2 位。任何公式分母為 0 或資料不足時輸出 N/A，並明列可計算樣本數；不得以 0 代替缺值。
