## 1. 封面與 30 秒導讀

### 1.1 這份文件是什麼

本文件示範一份「訓後綜合檢討／管理審查會議紀錄」應該長什麼樣子，並同時示範**如何把一場訓後檢討會議從會前準備開到會後追蹤**。它不只是空白表單，也不只是流程說明，而是「可操作的會議流程」加上「一份填妥的 SAMPLE 會議紀錄」。

### 1.2 對應關係

| 項目 | 內容 |
| --- | --- |
| 官方具名需求 | I15-E01：訓後定期性綜合檢討或管理審查制度會議紀錄 |
| 官方 checkbox 流水號 | 071 |
| Word 文件編號 | 0065 |
| 上位要求 | I15 要求展現定期課後檢討及審查改善機制；課後檢討須呈現學員建議／回饋、訓練需求、訓練目標與訓練方法的檢討 |
| 本件負責範圍 | 「具有完整討論、決策、責任與追蹤欄位的訓後綜合檢討／管理審查會議紀錄」 |

### 1.3 實際應用情境

當一個訓練班次結束後，需在到期日前召開一次檢討／審查會議，把課程數據、學員與講師回饋、資源使用與異常風險放上桌，形成可追蹤的改善決議。本文件示範這個情境的完整紀錄樣貌。

### 1.4 資料性質（必讀）

- 本文件所有內容為 **SAMPLE / SYNTHETIC（合成示範）**。
- 訓練案例使用既有的 SAMPLE 案例 **SYN-0060-2026-A01**，其來源為 0060 R08 之 SAMPLE 資料，對應 I14-E01 / checkbox 065。
- 該來源之獨立審查結果為「候選通過、尚未取得正式人工接受」；其所有訓練資料均為**桌面演練、未生效的 SAMPLE**，不是協會真實辦訓。
- 0065 另外新增的會議、意見、角色與預算假設，**全部為 0065 專屬的合成演練假設**，不得說成來自 0060 或來自協會。

### 1.5 尚未核實的權限與真實會議缺口

- 會議的召集權、出席授權、法定人數皆為 **UNKNOWN**，本文件不得宣稱該會議為合法有效會議。
- 本會是否已設有委員會、部門、常設職稱或法定召集權，**尚待以有權威的協會原件核實**；因此本文件人員一律只用功能角色代碼，不預設既有職稱。
- 未發現可查核的 I15-E01 實際會議、簽到、通知、核准或決議原件。凡屬此類者一律標 **HOLD**。
