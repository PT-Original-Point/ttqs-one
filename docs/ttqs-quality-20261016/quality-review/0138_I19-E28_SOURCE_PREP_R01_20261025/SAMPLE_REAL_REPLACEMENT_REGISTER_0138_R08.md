# DOCX 0138 SAMPLE／REAL 替換清冊 R08

狀態：CANDIDATE ONLY。REAL 原件、授權與協會核定均未提供；正式接受 NOT_GRANTED。

| 編號 | SAMPLE 位置／內容 | REAL 或核定輸入 | 完成判準 |
|---|---|---|---|
| REG-01 | SYN-0126-01 | 有權建立的 REAL 個案碼與結訓來源 | 身分對照留在核定受限位置 |
| REG-02 | NT$32,000 → NT$33,000 | 兩期原件／可驗證來源及同口徑欄位 | 可逐欄回查重算；目前僅 SAMPLE |
| REG-03 | +NT$1,000；3.1250%；顯示 3.13% | 真案輸入後重新計算並由第二人複算 | 算式與分母一致 |
| REG-04 | SYN-SOURCE-NOT-PROVIDED | 發行者、文件識別、頁欄、日期及核定位置 | 不編造來源或存放位置 |
| REG-05 | 空白告知／選擇表 | 正式主體、用途、依據、範圍、收件人、期間、窗口及版本 | 協會核定後才可使用 |
| REG-06 | SYN-0138-EX-01 | 真案差異來源、處置及覆核 | 不把演練記成協會事件 |
| REG-07 | 空白第三方查證函稿 | 真實受文者、必要欄位、核定窗口及安全方式 | 有權核准後才可發送 |
| REG-08 | R-01 至 R-04 功能碼 | 協會實際角色、權限、代理及獨立覆核安排 | 無獨立覆核則 HOLD |
| REG-09 | 保存／安全未核定 | 期限依據、受限位置、權限、備份及到期處置 | 未確認實際制度前維持 HOLD |
| REG-10 | REAL UNKNOWN / HOLD | 原件、適用依據、獨立查驗及 exact-version 覆核 | 本候選不等於正式接受 |

計算樣本 SYN-0126-01 與 SYN-0138-EX-01 均為 SYNTHETIC；不得填入或推定真人薪資、雇主、升遷、獎勵、授權、第三方回覆或協會決議。
