## 1. 用途、使用者與名詞

### 1.1 用途

本文件用於建立一個可追溯、低負擔、尊重個資與安全的外部觀察程序：在機構權責層事先書面授權、完成獨立性與法遵／隱私審查，並核准「不預先告知第一線人員具體時點／情境」的延後揭露方案後，由具獨立性的外部人員，依核准的 8 項清單觀察訓後行為轉移與服務流程，形成發現、改善、追蹤與關閉；並界定真實外部稽核原件的索取、驗真、保管、退件與銷毀邊界。

本文件處理的是真正的神秘客方法，不是要求第一線人員事先知道觀察員身分、拜訪時間或情境的揭露式查核。神秘客僅得在已核准的一般服務使用者情境中互動；不得冒用真實他人身分、假造證照、政府權力或協會代表身分。若個別事前告知／同意是法定、契約或政策要求，或權責無法確認，則不得執行隱蔽情境，改採另行授權的揭露式外部稽核或 HOLD。

### 1.2 使用順序

30 秒讀懂 → §2 官方定位 → §4 Gate 0 與揭露模式 → §5 取樣 → §6 流程 → §7 清單與量尺 → §10 表單 → §11 原件 → §13 STOP／HOLD／REJECT。

## 4. 授權與獨立性前置閘門（Gate 0）

### 4.1 書面授權必要欄位

目的與決策用途、範圍起訖、場所與窗口、期間、母體與樣本、資料欄位與最小化、法律／契約／政策依據、告知與延後揭露方案、事後告知與申訴安排、記錄方式與禁止事項、存取權限、保存期限與銷毀、事件通報、核准角色與版本。

神秘客授權另須明定：核准的一般服務使用者情境、可互動對象與不可互動對象、觀察員不得冒用之身分或資格、不得蒐集之資料、不得錄音錄影、遇到詢問或要求停止時的處理方式、事後告知時點與對象。若上述任一項無法確認，或法規、契約、政策要求個別事前告知／同意，則不得核准隱蔽情境。

### 4.2 獨立性必要條件

- 與委託單位、受觀察單位無僱傭、顧問、財務、個人或過去兩年密切往來。
- 未參與被觀察流程之設計、執行或原案件處理。
- 報酬不與發現、分數或結論掛鉤。
- 無禮品、招待、競業或其他可能影響判斷之關係。
- 簽署獨立性與保密聲明；情況變更時立即更新。
- 有衝突就迴避、更換觀察員或交獨立覆核；無法處理即 HOLD。

### 4.4 禁止行為

不得冒用真實特定消費者或其他真實個人之身分、資料或關係；不得假造證照、資格、政府權力、協會代表身分或稽查權限；不得以虛假官方名義互動；不得偷拍、錄音、錄影；不得接觸未授權第三方；不得蒐集身分證號、病歷、電話、地址或其他未授權個資；不得在公開場合討論個案；不得以禮品或壓力影響服務；不得隱瞞利益衝突；不得把觀察結果用於人事處分。

神秘客情境下，第一線人員不預先獲知具體訪查時點／情境；但這必須建立在機構書面授權、法遵確認與核准延後揭露之上，不得以口頭默契、現場即興或「先觀察再說」代替。若受觀察者明確要求停止、出現安全或隱私疑慮，應依核准腳本停止，不得爭辯或繼續蒐集。

### 4.5 延後揭露、事後告知與申訴

1. 觀察前：確認法規、契約、政策與場域規則是否要求個別事前告知／同意；若要求或不明，停止神秘客方案。
2. 觀察前：核准神秘客情境、禁止事項、遇到詢問的應對、停止條件與通報鏈。
3. 觀察後：依核准時點向受觀察單位窗口及第一線人員辦理事後告知，說明目的、範圍、資料處理、觀察員角色邊界與申訴管道；不得洩漏其他個資。
4. 觀察員與服務窗口互動時，使用核准的一般服務使用者情境與腳本；不得自稱政府、認證機構、協會代表或具稽查權力。
5. 事後告知不得變成報復、人事處分或未經授權的個資揭露；申訴與更正依核准程序處理。

### 7.1 評分定義

| 分數 | 定義 | 必要條件 | 不能怎麼用 |

### 7.2 Gate 0 與四個硬閘門

### 7.4 百分比公式與四捨五入

- 計分項目數＝8－NA 數－NE 數。
- 得分合計＝各項 2／1／0 相加。
- 分母＝2×計分項目數。
- 百分比＝得分合計÷分母×100%，四捨五入至小數第一位（0.05 進位）。
- 分母為 0 時不得輸出百分比，狀態為 NOT_SCORABLE／HOLD。
- 不得加權；不得事後調權重；不得以總分抵銷硬閘門；不得把 NE 當 0、NA 當 2、0 當 NE。
- NE 未解決前不得結案；若已書面解決並說明，仍不得把 NE 計入分母。
