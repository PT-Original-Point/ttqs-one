## 第二章 追蹤目的、收案資格與觀察期規範

### 2.1 追蹤目的
本機制旨在建立小型產業協會於訓練結束後，客觀驗證學員將課堂所學技能（如流程規範、表單填寫、技術操作）轉移至其日常崗位職務之微觀證據鏈。本工具不評量組織巨觀營運成果，專注於「學員個人是否有機會、是否嘗試運用、產出是否符合驗收標準、未達標時如何採取補救措施」。

### 2.2 收案資格標準
符合下列全部條件之學員，始納入法定追蹤分母：
1. **結訓門檻合格**：出席率達 80% 以上，並通過課程隨堂測驗或技能實作考核取得結訓證明。
2. **在職且具對應職能職位**：結訓時處於就業狀態，且其職務內容直接包含或高度相關於該課程培訓主題。
3. **已簽署追蹤與個資利用同意書**：同意於訓後提供去識別化之工作樣本供學習轉移查核。

### 2.3 觀察期與追蹤時程窗口
* **靜置期（訓後第 1～30 天）**：學員返回工作崗位，進行工作適應與技能初次試行，不進行正式績效評定。
* **收集期（訓後第 31～60 天）**：專員發出追蹤通知，學員繳交具體工作產出或主管操作檢核紀錄。
* **檢核與行動期（訓後第 61～75 天）**：進行成果初審，若發現未運用或部分運用，開立改善行動。
* **覆核審查期（訓後第 76～90 天）**：驗收改善成效，召開結案審查會議，確定案件狀態。

### 2.4 狀態定義與分母口徑判定規則
為確保統計數值之真實性與嚴謹度，嚴格區分五類追蹤狀態，杜絕以「未回覆」直接灌水為「成功運用」或逕行判定為「培訓失敗」：

| 狀態代碼 | 狀態名稱 | 定義與判定標準 | 分母納入規則 |
| :--- | :--- | :--- | :--- |
| **`COMPLETE_USE`** | 完整運用 | 學員檢附具體工作物，經核對驗收檢核標準（Rubric），關鍵項目完全符合要求。 | 納入運用率計算（分子 +1） |
| **`PARTIAL_USE`** | 部分運用 | 已在職務中實際操作，但產出格式不全、部分非核心項目未依規範填寫，或使用頻率未達標準。 | 納入整體運用率（分子 +1），與完整運用分開列示 |
| **`VERIFIED_NO_USE`**| 確認未運用 | 學員明確回報且查證屬實，在具有該項任務之職位上，完全未使用任何訓練所學技能。 | 納入分母（計算為未運用 / 失敗） |
| **`HOLD_UNKNOWN`** | 待核實／未知 | 佐證檔案損毀、關鍵欄位模糊、或仍在補件流程中，現階段無法客觀判定者。 | 納入分母（保守原則，不視為成功運用） |
| **`NO_OPPORTUNITY`** | 無職務發揮機會 | 因組織調動、留職停薪、產假或不可抗力之業務停擺，致觀察期內客觀無該項任務可供執行。 | **獨立剔除於運用機會分母外**，不列入培訓失敗計分 |

## 第三章 角色職責與權限邊界（小型協會情境）

小型協會通常無獨立人資部門（HR），追蹤職責由秘書處現有同仁兼任。為防範球員兼裁判與推論失真，訂定明確權限矩陣：

### 3.1 角色分工矩陣

| 權責角色 | 組織對應人員 | 核心職責 | 權限限制與禁區 |
| :--- | :--- | :--- | :--- |
| **培訓專員** | 秘書處專案執行人員 | 建立學員名冊、發放追蹤通知、收集工作樣本、初審欄位完整性、登錄替代簿。 | 不得單獨決定結案；不得竄改學員原始繳交內容。 |
| **業務輔導員** | 外聘產業顧問／資深幹部 | 執行工作產出之專業 Rubric 評分、提供缺失診斷、指導學員填寫改善行動。 | 不得干預協會行政決策；不作法律或僱傭爭議判定。 |
| **秘書長／督導主管**| 秘書處主管／理事會指派者 | 審核追蹤報告、核准逾期展延申請、裁定升級案件、簽發最終結案認可。 | 未取得完整驗證紀錄前，嚴禁核准結案。 |

## 第四章 學員職務運用追蹤標準作業程序（SOP）

### 4.1 作業程序圖與節點管制

```
[節點 1：名冊匯入] 結訓後第 30 天，專員由學員名冊匯入應追蹤學員 (檢查合格證號)
       ↓
[節點 2：機會查核] 核實學員現職是否有對應工作機會？
       ├─ (無機會) ──> 判定為 NO_OPPORTUNITY -> 填報原因並獨立存檔 -> 排除於運用分母
       └─ (具機會) ──> 進入標準追蹤名冊
              ↓
[節點 3：佐證提報] 學員於第 60 天前繳交工作樣本 (附去識別化標籤)
       ↓
[節點 4：規準檢驗] 依 Rubric 進行雙人核對 (專員初審 + 輔導員複審)
       ├─ (完全合規) ──> 判定 COMPLETE_USE -> 歸檔備查
       ├─ (部分合規) ──> 判定 PARTIAL_USE ─┐
       ├─ (完全未用) ──> 判定 VERIFIED_NO_USE ──┼─> [節點 5：開立改善行動表]
       └─ (資料缺漏) ──> 判定 HOLD_UNKNOWN ──┘          (指派責任人、資源與期限)
                                                               ↓
                                                    [節點 6：第 85 天行動驗收]
                                                               ├─ (全數完成驗收) ──> 提報主管准予結案 (CLOSED)
                                                               └─ (逾期或未通過) ──> 維持列管 (HOLD/REVISE) -> 啟動升級機制
```

### 4.2 輸入、控制點、輸出與異常分支處理表

| 階段步驟 | 輸入要件 (Inputs) | 關鍵控制點 (Control Points) | 產出成果 (Outputs) | 異常處理分支 (Exception Branches) |
| :--- | :--- | :--- | :--- | :--- |
| **S1. 資格與機會過濾** | 結訓總表、學員現職說明 | 必須由學員或其主管確認現任職掌是否有實際運用空間。 | 追蹤母體清冊（標記機會狀態） | 若因轉調內勤無機會，轉為 `NO_OPPORTUNITY`，留存人事令影本備查。 |
| **S2. 佐證收集與編碼** | 去識別化工作樣張、系統截圖 | 檢視是否包含完整「時間、工作項目、技能要素」，去除機密資訊。 | 編碼後之佐證檔案與登錄清單 | 佐證缺漏或逾期未繳者，標記 `HOLD_UNKNOWN`，限期 7 日內補正。 |
| **S3. 規準檢驗判定** | 評分規準 (Rubric)、工作樣張 | 依四大維度（格式、完整度、精確度、結案時限）嚴格比對。 | 檢核評定表、評分紀錄 | 出現爭議樣張時，由督導主管召開個案覆審會議判定。 |
| **S4. 改善行動開立** | 未達標樣張、缺失分析表 | 改善措施必須符合 SMART 原則，具體指定協會輔導資源與對應期限。 | 改善行動追蹤卡（填妥責任人與到期日） | 若學員拒絕配合改善，專員呈報主管進行職務訪談或判定為確認未運用。 |
| **S5. 覆查與結案判定** | 改善成果報告、抽查覆檢表 | 檢查點：四項改善行動是否全數「完成驗收」。缺一即不可結案。 | 結案審查決議書（准予結案 / 維持列管） | 若有一項行動逾期未結，一律判定為 `HOLD/REVISE`，提報理事會備查。 |

### 9.2 無效佐證鑑定標準與排除處置

出現下列任一情事者，判定為「無效佐證」，一律作廢發回，不得列入合規分子：
1. **非觀察期內產出**：佐證物之產出日期在訓練結訓前，或晚於結訓後第 90 天者。
2. **非學員職能範圍產出**：經查證該單據為同組同仁代筆或由主管直接操作，非學員本人親簽承辦。
3. **竄改或變造痕跡**：文件具有明顯塗改未認證、數位修圖或拼接痕跡者。
4. **純主觀自評宣告**：未附任何客觀業務單據，僅提供學員自行填寫之「我認為我已充分發揮」心得報告。
5. **不相干之業務雜件**：繳交無關本課程核心技能之打卡單、請假單或無具體顧客紀錄之通用發票。
