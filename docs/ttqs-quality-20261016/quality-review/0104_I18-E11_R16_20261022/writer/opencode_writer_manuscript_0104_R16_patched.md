# 證照獲取率_分析報告

本報告協助承辦人與主管確認：符合資格的學員中，有多少人完成報名、實際到考、通過考試，以及取得並完成證書查驗。請先確認同一課程期別、名冊和共同截止日，再沿著每一段人數核對差額；缺少來源時標示 UNKNOWN，分母為零時標示 N/A。

## 1. 摘要與使用方式

**一句話**：本報告回答「一批完成訓練的人，有多少人真的去報考、真的到考、考過，而且證書簽發已被獨立查證」，並把每個數字的分母、來源、缺口與後續動作寫清楚。

| 項目 | 內容 |
|---|---|
| 目的 | 用可重算的方式呈現證照取得情形，供主管判斷「缺口在哪一段」並決定下一步動作。 |
| 讀者 | 協會主管與決策者為主；訓練承辦與品保人員用於自我檢查與覆核。 |
| 使用時點 | 每期結訓、考試成績與簽發查證都完成後；對外提供佐證前先讀本頁。 |
| 母體（分母起點） | 「符合該期課程資格且完成結訓認定」的學員，逐期定義，不跨期合併。 |
| 截止點（cutoff） | 共同規則：**考試日後 90 個日曆日**為簽發查證截止；未到截止日者不計入「已驗證」。 |
| 主要輸出 | 5 個人口數；5 個固定比率：申請率（P2/P1）、到考率（P3/P2）、通過率（P4/P3）、已驗證證照獲取率（P5/P1）、簽發查證完成率（P5/P4）；另列選用之通過產出率（P4/P1，非前述 5 個固定比率）；例外清單、決策與期限、真實替換清單。 |
| 資料狀態 | **SAMPLE／SYNTHETIC**：第 11–14 節全部數字為示範；**REAL 現況為 UNKNOWN**（第 9 節），不得以 0 代替。 |
| 不可以做什麼 | 不得把本文當成協會實績、不得當成 TTQS 評核證據、不得推論訓練因果、技能提升、就業或組織績效。 |

## 2. 官方要求、範圍與來源階層

### 2.1 官方要求原文與頁面定位

- 官方查核佐證表**列印頁 7**，精確原文：**「證照獲取率。」**
- 頁面所屬評核內涵為 4 分指標「目標客戶及學員認為訓練有顯著具體績效。」；「證照獲取率。」出現在該指標「常見參考佐證資料（並註明資料來源及頁碼）」的**例示清單**中，同清單另有「指導學員參加技能競賽獲獎。」「感謝函。」等。
- **例示清單不等於達成證明**：出現在清單中，只表示「這是可以拿來佐證的一種資料」，不表示協會已做到、也不表示本件已成立。
- 同頁另有兩處與本件口徑直接相關，必須分開讀：
  - 3 分例示：「**高證照通過率之證明資料。**」
  - 1 分例示（文字層於頁面末截斷，僅引用可見片段）：「**學員考照通過率有增加，但未有**…」
  - 這兩處講的是**通過率**；本件的核心指標是**已驗證的證照獲取率**。兩者分母不同，不得互換（見第 10 節）。
- 官方依據：TTQS 評核指標與常見參考佐證資料表第 7 頁「證照獲取率。」；這是可採用的佐證類型，不代表協會已取得證書或完成查驗。

### 2.2 本報告的適用範圍

- 本報告只計算「合格學員中，證書已簽發且查驗成功的人數比例」。感謝函真偽查核、滿意度與學習需求、能力落差，應分別使用各自的紀錄與分析表，不可代替本報告的證書查驗分子。

## 3. 五個分離人口與排除關係

證照獲取率出錯，九成來自「把不同人口混成一個分母」。本件強制分離五層：

| 層 | 人口 | 定義 | 本文代號 |
|---|---|---|---|
| P1 | 合格學員 | 符合該期課程資格、完成結訓認定、且未被排除者 | 母體起點 |
| P2 | 申請／報名者 | 在報名截止前完成報考程序（含繳費或機構登錄）者 | 申請率分母為 P1 |
| P3 | 實際到考者 | 考試當日完成報到並全程應考者 | 到考率分母為 P2 |
| P4 | 通過者 | 成績達該考試公告及格標準者 | 通過率分母為 P3 |
| P5 | 簽發且已驗證者 | 已取得證書，且**簽發事實經指定來源查驗成功**者 | 取證率分母為 P1 |

**恆等式（必須成立，否則不得計算）**

1. P1 = P2 + 未申請
2. P2 = P3 + 未到考
3. P3 = P4 + 未通過
4. P4 = P5 + 待簽發 + 查證未通過（＋其他已定義例外）
5. 失聯為**旗標**，不是獨立人口；已含於未申請或未到考之中，不重複計入分母。

**排除（不得進 P1）**：重複身分未釐清、世代資格爭議未決、無授權或同意、資料版本不一致且未對帳、非屬該期課程學員。排除必須逐筆留理由與決定人，且不得為了讓比率好看而排除。

## 4. 納入／排除與共同截止規則

| 規則 | 內容 |
|---|---|
| 世代界定 | 以「課程代碼＋結訓日」界定世代；不同課程不混算。 |
| 納入 | 完成結訓認定、具備報考資格、資料版本一致、授權狀態有效。 |
| 排除 | 重複身分、資格爭議、無授權、版本不一致、非本期學員（逐筆留痕）。 |
| 共同截止點 | 考試日 + 90 個日曆日，之後不變更；截止後才簽發者另立「逾期簽發」註記，不回頭修改已發布數字。 |
| 截止後才補到資料 | 下一版以「修訂」處理，保留舊版與差異說明，不靜默覆寫。 |
| 計算單位 | 人；比率計算至小數第二位；百分點差以未四捨五入前值相減後再四捨五入（可能與顯示值直接相減差 ±0.01）。 |
| 不得合併 | 不同課程、不同截止點、不同考試主辦的數字不得合成單一「協會取證率」。 |

## 6. 隱私、個資與對帳控制

1. **最小化**：本文只呈現彙總，明細僅保留去識別 `SYN-A-001` 形式；姓名、身分證號、聯絡方式不進入分析檔。
2. **證書編號**：只保留「查驗結果＋查驗日＋查驗來源」，不重製證書影像、不抄錄完整編號。
3. **三向對帳**：名冊 ↔ 報考 ↔ 到考 ↔ 成績 ↔ 簽發查驗，逐層差額必須為 0；差額一律進例外紀錄簿，不就地修正。
4. **雙人覆核**：分母重建由承辦建立、品保獨立重算；兩人結果不一致時，以「較保守（較小分子、較大分母）」版本暫列，並開啟閘門。
5. **版本控制**：每次發布留存來源版本、匯出時間、截止日、覆核人角色、差異說明。
6. **不得推測補值**：缺漏就是缺漏，不以平均、比例回推、口頭確認補成數字。
7. **本文不製發任何證書、不代簽、不補作、不仿製第三方文件。**

## 8. 指標定義、公式、四捨五入與 N/A 規則

| 指標 | 公式 | 分母 | 分子 | 零分母 | 常見誤用 |
|---|---|---|---|---|---|
| 申請率 | P2 ÷ P1 | 合格學員 | 完成報考者 | N/A | 用「有意願」代替「完成報名」 |
| 到考率 | P3 ÷ P2 | 報名者 | 實際到考者 | N/A（P2=0） | 用「准考證寄發」代替到考 |
| 通過率 | P4 ÷ P3 | 到考者 | 通過者 | N/A（P3=0） | 用「報名者」當分母 |
| **已驗證證照獲取率** | **P5 ÷ P1** | **合格學員** | **簽發且查驗成功者** | N/A（P1=0） | 用「通過率」或「已送件」代替 |
| 簽發查證完成率 | P5 ÷ P4 | 通過者 | 已驗證簽發者 | N/A（P4=0） | 把「待簽發」算成已取得 |
| 通過產出率（選用，須另標名） | P4 ÷ P1 | 合格學員 | 通過者 | N/A | 改名為「取證率」 |

**名詞邊界**：本報告不以籠統「成果率」取代具體指標；若提及證照成果率，僅指「已驗證證照獲取率（P5/P1）」。相對變化率定義為 `(B−A)÷A×100%`，基準 A=0 時標 `N/A`；百分點差是 `B−A`，不得與相對變化率混用。通過率固定為 `P4÷P3`，分母僅為實際到考者。

**硬規則**

- 分母為 0 → 顯示 `N/A`，**不得顯示 0%**。
- 分子缺漏 → 顯示 `UNKNOWN`，不得以 0 代入計算。
- 未申請、未到考、未通過、待簽發、查證未通過、失聯、缺件，**一律並列呈現**，不得只在註腳提及。
- 「通過率」與「取證率」是兩個標籤、兩個分母、兩個結論，永不互換。
- 「通過產出率」若使用，必須寫全名 `通過產出率（P4/P1）`，不得簡稱取證率。
- 四捨五入至小數第二位；差異以未四捨五入值計算。

## 9. 四段乘法鏈（本件的核心機制）

已驗證取證率可完全分解為四段，任何一段缺口都會被定位：

```
P5/P1 = (P2/P1) × (P3/P2) × (P4/P3) × (P5/P4)
        申請率      到考率      通過率      簽發查證完成率
```

此式的用途是**定位**，不是**歸因**：它只說「數字在哪一段流失」，不說「為什麼流失」，更不說「訓練造成」。

```
合格 40 ─未申請 8→ 申請 32 ─未到考 3→ 到考 29 ─未通過 7→ 通過 22 ─待簽發 2／查證未過 1→ 已驗證 19
```

## 25. 結論、發布條件與限制

### 25.1 結論

1. **真實面**：目前協會的合格學員數、報考數、到考數、通過數、簽發且已驗證數**全部 UNKNOWN**，因此**現階段無法計算證照獲取率**，證據強度為 **E0**。本報告不能作為協會實績，也不能作為 TTQS 評核證據。
2. **方法面**：取證率必須以「合格學員」為分母、以「簽發且查驗成功」為分子；通過率與取證率是兩個不同標籤，不得互換；零分母一律 `N/A`。
3. **示範面**：在完整填入的合成資料中，A 期已驗證取證率 47.50%、B 期 66.67%，差距 19.17 個百分點；拆解後以申請率與通過率兩段占比最高。此結果**僅示範流程可執行**，不是任何真實課程的成效，也不構成訓練因果證據。
4. **決策面**：示範情境下最該先做的是「把已通過但未完成簽發查證的 3 件逐件結案」（此 3 件僅指 A 期：2 件待簽發＋1 件查證未通過；B 期另有 2 件，為 1 件待簽發＋1 件查證未通過），其次是「記錄未申請原因」；這些事都不需要新增經費，只需要紀律與留痕。
5. **邊界面**：本件拒絕與 0103（感謝函）、0105（問卷／成效感知）混用；在五項證據未全同前，也拒絕與 0102（能力落差）建立跨件人口對應。
