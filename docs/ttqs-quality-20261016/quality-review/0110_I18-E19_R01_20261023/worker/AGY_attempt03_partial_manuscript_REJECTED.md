### 1.1 工具定位與適用對象

## 第三章 評估構念與量表編碼規範

### 3.1 核心評估構念定義
本工具將「訓練對組織績效之改善與提升」拆解為五個明確構念，以避免流於抽象感覺：
- **構念一：學習應用信心（L-A）**：學員對於課程所傳授之標準作業流程、規範與工具之認知清晰度及獨立操作自信。
- **構念二：步驟執行能力（L-B）**：學員在現場實務操作中，落實標準作業要點、排除突發異常狀況之純熟度。
- **構念三：服務品質與完整度感受（L-C / C-B）**：現場交付成果（如報到手續、物資發放、資料登記）之精確性、無遺漏性與齊全度。
- **構念四：組織協作與流程效能（L-D / C-C）**：志工交接換班之順暢度、跨人員溝通成本降低程度及等待時間縮短之可觀察狀態。
- **構念五：外生變數與替代解釋**：檢驗績效變化是否可能由培訓以外之客觀環境條件（如活動場地變大、參與人流減少、軟硬體升級等）所引起。

### 3.2 量表編碼與分母處理規則
問卷主體採用五點李克特量表，輔以專用無效標記代碼，定義如下：
- **`5`（非常同意 / 明顯改善）**：受測者極為認同，且觀察到顯著的具體正面轉變。
- **`4`（同意 / 有所改善）**：受測者認同該項敘述，並觀察到多數時候有正面進步。
- **`3`（普通 / 無明確變化）**：感受持平，未見明顯差異或變化不大。
- **`2`（不同意 / 稍有退步）**：受測者不認同，或觀察到執行品質稍有下降。
- **`1`（非常不同意 / 明顯退步）**：受測者極度不認同，或現場發生嚴重作業缺失與混亂。
- **`0`（未觀察／不適用）**：受測者在此期間未接觸該作業環節，或該項目不適用於受測者之角色。
- **空白（Missing）**：受測者遺漏未填答之題項。

> [!CAUTION]
> **統計分母計算嚴格警語**：
> 1. 代碼 `0`（未觀察／不適用）與「空白未填」**絕對不可**被編碼為分數，亦**不得**納入 1 至 5 分之平均值或有利比例的分母中。
> 2. 題項之「有效分母」，僅計算實質填答 `1` 至 `5` 分之有效樣本總數。
> 3. 「有利比例（Favorable Proportion）」計算公式：$\text{有利比例} = \frac{\text{填答 4 分與 5 分的總次數}}{\text{有效分母（填答 1 至 5 分總次數）}} \times 100\%$。
> 4. 嚴禁將學員評分與客戶評分進行加權混合計算為「綜合單一分數」。兩者群體性質完全不同，必須分開獨立呈報。

## 第七章 編碼指引、分母計算規則與統計處理

為確保評核數據之嚴謹度與真實性，協會行政人員處理問卷數據時，必須嚴格遵守下列算術規則：

### 7.1 問卷回收率計算
- **學員問卷回收率**：
  $$\text{學員回收率} = \frac{\text{有效回覆問卷份數}}{\text{發出邀請總人數}} \times 100\% = \frac{8}{10} \times 100\% = 80.0\%$$
- **目標客戶問卷回收率**：
  $$\text{客戶回收率} = \frac{\text{有效回覆問卷份數}}{\text{發出邀請總人數}} \times 100\% = \frac{6}{8} \times 100\% = 75.0\%$$

### 7.2 構面有效分母與平均分計算規範
1. **有效題項分母（Valid Denominator, $N_v$）**：
   - 僅計算實質給予 `1, 2, 3, 4, 5` 分之有效填答題數。
   - 勾選 `0`（未觀察／不適用）、空白缺答、填答矛盾或重複作答者，**必須全數剔除於分母之外**。
2. **有利評價比例（Favorable Proportion, %）**：
   - 定義為給予正面評價（`4` 分同意／改善 與 `5` 分非常同意／明顯改善）之人次比例。
   - 計算公式：
     $$\text{有利比例} = \frac{\text{Count}(\text{Score} \in \{4, 5\})}{N_v} \times 100\%$$
3. **構面平均值（Mean Score）**：
   - 計算公式：
     $$\text{平均值} = \frac{\sum_{i=1}^{N_v} \text{Score}_i}{N_v}$$
   - 計算結果一律以四捨五入計算至小數點後第二位。

### 7.3 客觀業務紀錄抽樣與百分點變化
- **基線完整率（$P_{\text{base}}$）**：訓前抽樣完整筆數 / 訓前總抽樣筆數 $\times 100\%$。
- **訓後完整率（$P_{\text{post}}$）**：訓後追蹤抽樣完整筆數 / 訓後總抽樣筆數 $\times 100\%$。
- **實質成效差異（百分點, %p）**：
  $$\Delta P = P_{\text{post}} - P_{\text{base}}$$
  *重要原則：此處計算出之差異僅代表描述性對比（Descriptive Comparison），不得擅自宣稱為訓練具備統計上之顯著因果必然性。*

```
      ▼ (真實開課、取得合規問卷調查)
[PERCEPTION_ONLY] (僅有主觀知覺評分，無客觀紀錄佐證)
      │
      ▼ (取得獨立客觀業務抽樣且比對完成)
[CORROBORATED_DESCRIPTIVE] (雙軌問卷與客觀數據相互呼應，具描述性成效)
      │
      ▼ (經過權責主管審核、抽樣核實且無爭議)
[REAL] (正式有效評核佐證)
      │
      └─> [INCONCLUSIVE / HOLD] (任一檢核不合格時之暫緩狀態)
```

- **`SAMPLE_ONLY`（示範樣本）**：文內所有填答、數據均為合成虛構，僅供行政作業培訓示範。
- **`PERCEPTION_ONLY`（純知覺評價）**：已取得真實學員或客戶之合法問卷，但缺乏客觀現場業務抽樣紀錄佐證。
- **`CORROBORATED_DESCRIPTIVE`（描述性佐證完備）**：學員滿意度、客戶觀察與客觀業務抽樣數據相互對照且呈現改善趨勢，惟受限於小樣本無法證明單一絕對因果。
- **`INCONCLUSIVE / HOLD`（存疑／暫緩核定）**：數據矛盾、樣本不足、缺乏授權或遭遇退件條件時之管制狀態。
- **`REAL`（正式真實文件）**：嚴格遵循真實資料替換指引，經專責主管簽署並通過合規查核之正式佐證。

### 9.2 退件、補件與暫停（REJECT / HOLD）之觸發條件
當評估報告或送審文件出現下列情事之一者，審查人員應即刻判定退件或暫緩核定：
1. **【退件 REJECT】重大造假與合規缺失**：
   - 將本手冊示範之虛構案例、虛構代碼（如 `SYN-0110-CASE-01`, `L01`）直接冒充為協會真實辦訓實績。
   - 於問卷中擅自蒐集受測者之身分證字號、真實姓名、私人電話等敏感個資，違反個人資料保護法。
   - 目標客戶未簽署「去識別化使用授權確認」，或已勾選「不同意」卻仍擅自納入外部報告。
   - 實際抽樣數據未達預期目標值（如 87.5% < 90.0%），審查紀錄卻擅自勾選「CLOSE 達標結案」。
2. **【暫緩／補正 HOLD】程序與計算瑕疵**：
   - 僅施測學員問卷，未對目標客戶／外部夥伴進行施測，卻在報告中宣稱「客戶均認為有顯著效果」。
   - 將代碼 `0`（未觀察／不適用）或空白漏填項計入 1 至 5 分之分母計算，導致分數被蓄意拉高或壓低。
   - 將學員評分與客戶評分混編為單一平均分數，遮蔽群體差異。
   - 課後行動計畫缺乏 30 天具體追蹤數據佐證，或佐證檔案卷夾代碼無法在資料室調閱核實。
