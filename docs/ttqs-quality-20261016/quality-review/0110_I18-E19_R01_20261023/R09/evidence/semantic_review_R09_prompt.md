真實資料替換清單（操作步驟）
每份真實來源先確認合法來源、資料權限及使用目的；必要的同意／授權與核定政策缺一即 HOLD。
以獨立匿名代碼替換示範填答碼；不得建立姓名對照清冊。刪除自由文字中的姓名、聯絡方式、內部代號及可辨識事件。
逐格將示範題目值替換成原始匿名答覆；保留0、空白、無效、重複的不同狀態與原因，不用示範答案補值。
學員、客戶／夥伴分開匯總；依實際送達的合格邀請計回覆率，按有效1–5重算逐題結果。
將示範操作數6/8、7/8及90%目標全部換成有來源可追溯的實際分子、分母與核定目標；若前後定義不一致，不得計算差值。
將示範角色代碼、相對日期、行動內容、追蹤結果、核可狀態及稽核軌跡逐項替換；不得保留任何示範核可勾選或假造來源。
替換後再由有權人員核對原始來源、匿名處理、計算及處置；未完成獨立核對前，狀態保持 UNKNOWN／HOLD。
本工具無固定保存期限；真實資料的保存、存取與銷毀依協會另行核定的規則執行。
