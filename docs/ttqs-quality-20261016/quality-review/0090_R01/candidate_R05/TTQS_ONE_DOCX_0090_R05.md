# 一、開場使用說明（先讀這一段再填表）

**1. 這份文件是什麼。** 這是「派訓單位主管對參訓學員的學習成效評估表」，用來判斷**一位具體受訓者是否學會那一項指名的學習目標，並在工作中實際用出來**。**一張表只評一項學習目標**；第五節的五題量規**不是五個目標**，而是同一項目標的五個可觀察構面（對應表見 2.3）。它是一份可直接填寫的表單，加一份完整合成示範個案，不是制度說明、不是滿意度問卷、也不是空白格式而已。

**2. 這份文件不是什麼（不得混用）。**
- 它**不是** DOCX 0084（I17C-E03）的工作場域行為觀察紀錄；17c 的行為觀察證據不可挪來當本表的成效判定。
- 它**不是** DOCX 0089（I17D-E03）的品質不良率變化表；不得挪用其 8/40、2/40 等數字，也不得宣稱與本件共用案例。
- 它**不是**官方方框序號 090（I17C 行為勾選項）；本件對應**官方方框序號 097**，請勿與 DOCX 文件編號 0090 或序號 090 混淆。

**3. 何時填。** 分三個時點填寫，各時點都要留下紀錄定位：
- **訓前（示範相對期間 D-7）**：記錄能力基準。
- **訓後立即（D+0）**：記錄**首測（first attempt）**結果；首測定義見 7.1。
- **工作應用觀察時窗（D+1 至 D+30，於 D+30 彙整）**：由主管在受訓者實際執行合格任務時觀察並評分。
- **補救複測（如有啟動，例如 D+3）**：**另立紀錄**，只記該受訓者的複測結果，**不得回頭改寫 D+0 首測統計**（見 6.2 第 12 項、7.5）。

**4. 誰填。** 由**依實際授權**的派訓單位主管或觀察者填寫。小型志工協會若無專職 HR、無固定部門、無全職員工，則由實際承辦訓練的志工行政人員與實際帶領該受訓者的主管依現行授權填寫；本文件**不預設**協會已設置人力資源部門、已聘任專職人員或已有既定核准制度。合成示範中的「主管」只是**假設角色**，不代表已聘任或已核定任何人。

**5. 附什麼紀錄。** 每個分數都要能追溯到一份可指認的紀錄（檔名／頁次／列次或表單編號）。沒有對應紀錄不得填分：期間無合格任務才記 N/O；任務已存在但來源未核驗／定位待補時，按 6.2.3 不計該題並列 HOLD 或退件，不以 N/O 代替來源缺失。

**6. 缺項怎麼辦。** 僅在本次期間**沒有合格任務**時記 **N/O**（不是 0，也不是結論），並記原因與下次觀察方式；若無合格任務，勾「**不適用：期間內無合格任務**」，改填觸發條件與狀態覆核期限。若合格任務已存在但來源未核驗或定位缺漏，**不得改記 N/O，也不得先計分**：來源已存在且可補定位時列 **HOLD**，補齊後重判；來源不存在或不可核驗時依 6.2.3 退件，並依剩餘有效證據判定；有效證據不足則為 **INSUFFICIENT_EVIDENCE**。

**7. 四類資訊不可互相代替。** 本表**主要**評估**兩件事**：**訓後立即展現的學習成效**，以及**主管親見的工作行為**；這兩項是本表的計分主體，且二者評的是**同一項學習目標**。個人工作結果指標僅為**選填背景**（不計分、不作因果歸因），組織整體結果不納入判定。

| 證據類型 | 說明 | 本表角色 |
|---|---|---|
| 學習／滿意度 | 知道了、喜歡這門課 | 滿意度**不可**代替成效判定；訓後立即的學習成效另以即時檢核計分 |
| 工作行為觀察 | 主管親見的操作行為 | **主要評估對象（計分）** |
| 個人工作結果指標 | 缺件率、完成率等 | **選填背景**：有合法來源才附記，**不計分、不作因果歸因**；無來源一律填「尚無可判讀結果」 |
| 組織整體結果 | 全會計的彙總數字 | **不納入判定、不歸因**；本表不作因果主張 |

# 二、文件目的與證據鏈（兩者分開表述）

## 2.1 目的（Purpose）

本文件的目的**只有一件事**：就**一項**具體指名、可觀察的學習目標（**一表一目標**；填寫欄位見第四節「學習目標」欄，目標敘述模式與示範見 2.3），判斷指定受訓者是否（a）在訓後立即展現該目標應有的知識／技能，（b）在指定期間內的合格工作任務中穩定運用，並（c）在有合法來源時，附記對應的工作結果觀察——（c）**僅供背景參考，不計分、不作因果歸因**，無合法來源即寫「尚無可判讀結果」。最後由主管作出 PASS／HOLD／INSUFFICIENT_EVIDENCE 的判定與後續行動。

第五節的五題量規**不是五個不同學習目標**，而是**同一項目標的五個可觀察構面**；一對五的對應表見 2.3。若需評估第二項目標，**另立一份評估表**，不得在同一張表內混列兩項目標。

本文件**不**用來計算單位績效、**不**用來取代 I17C 工作場域行為觀察紀錄、**不**用來取代 I17D 不良率統計表、**不**用來取代滿意度調查，也**不**對協會整體成效作出因果結論。

## 2.2 證據鏈（Evidence chain，逐環必須可回溯）

依序如下，前一環的產出是後一環的輸入：

1. 學習目標（**一項**可觀察行為描述；由第五節五題對應，見 2.3）
2. 訓前基準（來源定位 ＋ 分母 ＋ 排除條件）
3. 訓後立即檢核（工具名稱 ＋ 原始紀錄定位 ＋ 同分母 ＋ **首測定義**，見 7.1）
4. 工作應用觀察（合格任務定義 ＋ 觀察時窗 ＋ 主管親見事實）
5. 工作結果指標（**選填背景**：有合法來源才附，**不計分、不作因果歸因**；無來源＝「尚無可判讀結果」）
6. 逐題評分（1–4 錨點 ＋ 證據定位 ＋ 觀察事實；無任務＝N/O）
7. 判定（N/O 優先順序 ＋ 平均門檻 ＋ 關鍵項門檻 ＋ 分母完整性，見 6.1）→ 後續行動與複評（不得預填結果）
8. 替換清冊（每一個合成值都有 SYN-0090 系列 fact_id 與替換指引）

**證據鏈斷裂時的處理**：「工作結果指標」一環為選填背景，缺來源時僅記「尚無可判讀結果」，**不構成斷裂**；其餘任一環節缺來源定位、分母不明或觀察者無法確認，判定只能停在 INSUFFICIENT_EVIDENCE，不得以上一環或下一環的數字補推。

## 2.3 單一學習目標 ↔ 五題量規的對應（一項目標、五個可觀察構面）

**目標敘述模式（規範，非合成值）**：「受訓者在＿＿（合格任務）中，能獨立完成＿＿（可觀察行為），並留下＿＿（可追溯產出）。」**一表只填一項**。

**合成示範目標（SYN-0090-37；用於第七節與 7.4）**：「受訓者能在指派的行政服務紀錄任務中，獨立依序完成：核對資料來源與必要同意、補齊必要欄位且不臆測、對照來源並留下更正軌跡、以最小必要方式安全保管、遇例外即停止並升級，全程留下可追溯的紀錄定位。」

| 量規題 | 對應同一項目標中的可觀察構面 | 所屬證據面向（第三節 A–D） |
|---|---|---|
| 1. 資料來源與必要同意／授權（關鍵） | 核對資料來源與必要同意 | A（知識／技能）→ B（轉移應用） |
| 2. 必要欄位完整且不臆測（非關鍵） | 補齊必要欄位且不臆測 | A → B |
| 3. 對照來源與更正差異（關鍵） | 對照來源並留下更正軌跡 | A → B |
| 4. 最小必要與安全保管（關鍵） | 以最小必要方式安全保管 | A → B |
| 5. 例外辨識、停止與升級（關鍵） | 遇例外即停止並升級 | A → B |

> **第三節 A～D 不是四個學習目標。** A、B 是**同一項目標**的兩個證據層次（知能、實際轉移），C 是選填結果背景（不計分、不歸因），D 是限制記錄（不計分）。**分數只由 A、B 兩面向經由上述五題產生**；C、D 不進任何分母。

## 5.3 N/O 處理規則

- **N/O 永遠不是 0 分，也永遠不是結論。** N/O 僅表示「本次期間沒有可觀察的合格任務」，屬**未觀察**，不是**未達成**；結論仍須落於 PASS／HOLD／INSUFFICIENT_EVIDENCE 三者之一（路由見 6.1）。合格任務已存在但來源缺失／未核驗時不得記 N/O；依 6.2.3 暫停計分、補來源或退件。
- N/O 不納入該題與該人的平均分母；須寫明「無合格任務」理由、是否存在下次任務及觸發／覆核時點。若任務已存在但來源未核驗，改走來源缺漏欄，不以 N/O 隱去資料缺失。
- 期間內**沒有**合格任務時，勾第四節「**不適用：本次期間無合格任務**」，改填**觸發條件**（首個合格任務分派當日）與**狀態覆核期限**（相對日期）。
- **關鍵題 N/O**：若同時沒有任何關鍵題分數 <3 → 結論 **INSUFFICIENT_EVIDENCE**（6.1 第二步）；若另有關鍵題分數 <3 → 結論 **HOLD**（6.1 第一步優先）。
- **五題全 N/O 或期間無合格任務** → 結論 **INSUFFICIENT_EVIDENCE**（6.1 第三步）；**不是 0、不是 PASS、也不是「N/O」這一種判定**。
- **非關鍵題（第 2 題）N/O** → 自平均分母剔除（分母 5→4），其餘已評分題照常計算；門檻不因少一題而放寬或加嚴。
- N/O 既不得計為失敗，也不得計為成功；不得用其他題的分數推估 N/O 題。

# 六、判定規則與拒收條件

## 6.1 三種結論與 N/O 優先順序（**依序判定，先看關鍵項**）

> **N/O 是觀察狀態，不是第四種結論。** 依下列優先順序先處理固定關鍵項與證據狀態，再查判定表；全程只可得 PASS、HOLD、INSUFFICIENT_EVIDENCE 三種結論。

**第一步（關鍵項分數 <3）**：任一**預先指定**關鍵項（第 1、3、4、5 題）**已評分且 < 3** → 結論＝**HOLD**。無論平均多高都成立；平均不得抵銷、不得四捨五入、不得移除該題。（此時若另有關鍵題 N/O，仍記 HOLD，並在後續行動中一併補齊該 N/O 觀察。）

**第二步（關鍵項 N/O）**：第一步不成立（**沒有任何已評分關鍵項 <3**），但仍有任一預先指定關鍵項為 **N/O** → 結論＝**INSUFFICIENT_EVIDENCE**。須記錄：缺哪一題、N/O 原因、**下次觀察觸發條件**（例：主管分派第一個合格任務當日）與**狀態覆核期限**。

**第三步（全題 N/O／無合格任務）**：五題全為 N/O，或期間內無合格任務 → 結論＝**INSUFFICIENT_EVIDENCE**，理由＝「期間內無合格任務，無可觀察行為」；**不得記 0、不得記 PASS、不得以 N/O 作為結論**。納入題數為 0 時，平均欄填「不計算」。

**第四步（其餘可判讀情況）**：依下表判定；若固定關鍵項均已評分且 ≥3、無固定關鍵項 N/O，但有效平均 <3.0，必列 **HOLD**，不得留下未分類狀態。

| 結論 | 成立條件（須同時滿足） | 應記動作 |
|---|---|---|
| **PASS** | 全部**預先指定**關鍵項（第 1、3、4、5 題）**均已觀察且 ≥ 3**；**且**平均 ≥ **3.0**（分母＝已評分題數，N/O 不進分母）；**且**分母有效（四個關鍵題全數在分母內；非關鍵題 N/O 可自分母剔除，故分母＝5 或 4）；**且**每題均有證據定位；**且**分母與排除條件完整可查 | 記錄判定與證據定位，指定下次例行複核時點 |
| **HOLD** | 任一固定關鍵項已評分且 < 3（第一步優先）；或沒有固定關鍵項分數 <3／N/O 但有效平均 <3.0；或發現重大流程錯誤；或原始來源已存在、定位缺漏可於期限內補齊（未補齊前該題不得計分） | 列明補強或補件內容、責任角色、期限及下次觀察時窗；複評或來源覆核前不得改判 |
| **INSUFFICIENT_EVIDENCE** | 任一固定關鍵項為 N/O 而無固定關鍵項 <3（第二步）；或五題全 N/O／無合格任務（第三步）；或分母不明；N/O 過多致固定關鍵題不足；或來源退件後有效證據不足；或無法確認觀察者 | 記錄缺什麼、原因、下次觀察觸發條件、狀態覆核期限及責任角色；不得以推測、平均值或外部數字補值 |

**平均算法須寫明**：平均＝有效已評分題總分÷有效已評分題數，N/O 不進分母。固定關鍵項 <3 優先 HOLD；固定關鍵項 N/O 且無已評分固定關鍵項 <3 時為 INSUFFICIENT_EVIDENCE；若固定關鍵項均 ≥3 且無關鍵 N/O、但有效平均 <3.0，為 HOLD；符合全部 PASS 條件才為 PASS。平均不得抵銷固定關鍵項缺失或低分，N/O 不會成為第四種結論。

## 6.2 拒收（Reject）條件——出現任一項，該份評估不得採計

1. 以滿意度、課後反應或出勤率代替學習成效判定。
2. 題目沒有 1–4 行為錨點，或以「優／可／待改進」等籠統形容詞計分。
3. 將無來源紀錄的分數採計，或在來源無法核驗時保留該分數。若原始紀錄確實存在但定位待補，該題先不採計、整份列 HOLD；期限內補齊後重算。若找不到來源或來源不可核驗，該題及其支撐結論退件；依剩餘有效證據重判，不足時列 INSUFFICIENT_EVIDENCE。
4. 把 N/O 記為 0 分、把 N/O 計入分母，或**以 N/O 直接作為結論**（N/O 只是觀察狀態，須依 6.1 優先順序路由至 HOLD 或 INSUFFICIENT_EVIDENCE）。
5. 訓前與訓後分母不一致卻未說明原因與排除條件。
6. 公式錯誤：把百分點差寫成相對百分比、或把相對百分比寫成百分點。
7. 樣本數、百分點、相對變化三者混寫或互換。
8. 關鍵項未於**評分前**指定，或評分後才變更門檻。
9. 將合成（SYNTHETIC）個案敘述為協會真實紀錄、真實成效或已核准結果。
10. 未經來源即填入工作結果指標，或以推算值代替「尚無可判讀結果」。
11. 對協會整體或課程作出因果歸因（例如「因參訓而使缺陷率下降」）而無對照設計與來源。
12. 以複測結果（如 D+3）改寫、覆蓋或併入 D+0 **首測**統計，或把複測計入首測分母（首測只記第一次結果；複測須另行記錄並標示時點）。
