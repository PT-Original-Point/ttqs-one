## 0101 報告的計算與判讀規則

1. 只納入同一匿名配對碼、相同題目版本、相同六個維度且前後皆有效的資料。
2. 每一維度平均數 = 該維度有效配對分數總和 ÷ 該維度有效配對 n；差異 = 課後平均 − 課前平均。
3. 每題均須為 1 至 5 分。漏答、重複碼、題目版本不一致、日期順序錯誤或來源無法回查者，先隔離並查證，不用零值或推估值填補。
4. 完整配對以同一分母計算；若不同維度有效 n 不同，必須逐項揭露分母，禁止呈現一個看似共同樣本的雷達圖。
5. n=1 僅代表一個合成示範配對。不得計算或宣稱顯著性、群體效果、協會績效或客觀能力證明。

## SAMPLE／REAL 分界與替換

本階段所有學員、單位、課程、日期、分數、角色敘述及分析結論均為 SYNTHETIC。沒有真實問卷、名冊、核定課程、機構核准、簽名或外部查證。文件不得放入協會標誌、真實個資、真實核定語句或第三方證據。

改作真實紀錄前，須由授權人員以實際受控原件替換每筆合成值，核對課程與題目版本、填答時間、匿名配對碼、原始資料位置與資料權限，再由另一位實際覆核人員重算。任何 REAL 狀態都須由原件和授權資料支援；本包本身不提升正式接受狀態。
