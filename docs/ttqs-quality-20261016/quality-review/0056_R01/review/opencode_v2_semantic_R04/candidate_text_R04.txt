這一頁要你做什麼找出本次課程將使用的場域與器材，確認是否有「安全檢查」或「場地投保證明」義務；依決策樹做一次「有來源依據」的適用性判定；向第三方索取正本；驗證後登記到期日與檢索方式。官方要求（逐字）「設備安檢或是場地投保證明。」（勞動力發展署「訓練機構 TTQS 證據表」，第 4 頁，官方指標 I12-E04）合成／真實界線本文件目前只含一份合成示範案例（非真實）。任何真實保單、檢查證明、機構、保單號或簽名在本文件中都不存在；相關欄位一律為 未知 或 待取得真實來源。紅線適用性「未知」或「沒有來源依據」時，一律 暫停，不得自行當成「不適用（N/A）」。

五、官方「或」語意與適用性決策
官方要求為「設備安檢『或是』場地投保證明」：任一路徑成立即可，但必須依「已記錄、有來源依據」的判定，不能憑感覺決定。
設備安檢路徑獨立成立 → 走「設備安檢」。
場地保險路徑獨立成立 → 走「場地保險」。
兩者各自獨立成立 → 兩者皆辦（both）。
判為不適用 → 必須有來源依據，才算 有來源佐證的不適用。
適用性未知或缺依據 → 暫停，永不靜默當成 N/A。
不得臆造法規、承保限額或「協會政策」。

[起點] 本次將使用的場域／設備？  ├─ 場域／設備清單未知 → 適用性未明，暫停判定  └─ 已知（先填表 T2）       ├─ 是否有「要求檢查」的來源依據（真實手冊／契約／法規）？       │    ├─ 有且已驗證 → 已依來源確認適用（走設備安檢）       │    ├─ 有但未驗證 → 可能適用，待核實來源（暫時 暫停）       │    └─ 無／未知 → 不得判 N/A → 適用性未明，暫停判定       ├─ 是否有「要求投保」的來源依據（真實租約／契約／規範）？       │    ├─ 有且已驗證 → 已依來源確認適用（走場地保險）       │    ├─ 有但未驗證 → 可能適用，待核實來源（暫時 暫停）       │    └─ 無／未知 → 不得判 N/A → 適用性未明，暫停判定       └─ 合併判定：            ├─ 僅檢查成立 → 僅走設備安檢路徑            ├─ 僅保險成立 → 僅走場地投保證明路徑            ├─ 兩者皆成立 → 設備安檢與場地投保證明兩路皆適用            ├─ 兩者皆有依據地不適用 → 兩路均有來源依據並判定不適用（須引用來源）            └─ 任一未知 → 適用性未明，暫停判定

設備安檢流程（對應表 T3）
1. 由表 T2 取出本次要使用的設備義務。
2. 檢查前先確認「允收基準來源」（真實手冊／契約）；沒有基準就不得自訂門檻，一律記為 未知 / obtain and verify。
3. 執行檢查（目視／功能測試），並記錄檢查發現。
4. 發現異常 → 立即隔離並掛牌停用（掛牌停用，即隔離並掛牌禁止使用），記錄負責角色與更正措施。
5. 更正後由「獨立複核者」複核，並依「真實允收基準」判定是否放行；沒有基準就 暫停。
6. 全程以證據編號回填表 T5，並在表 T6 留下決策軌跡。
7. 除非有真實驗證正本，否則不得聲稱由合格第三方完成檢測。
