## D. 官方「或」語意與適用性決策樹

### D.1 語意鎖定
官方為「設備安檢**或是**場地投保證明」——**任一路徑成立即可**，但須依**已記錄、有來源依據**的判定：
- 設備安檢路徑獨立成立 → 走「設備安檢」。
- 場地保險路徑獨立成立 → 走「場地保險」。
- 兩者**各自獨立**成立 → 兩者皆辦（"both"）。
- 判為不適用 → **必須有來源依據**才成立 `NOT_APPLICABLE_SUPPORTED`。
- 適用性未知、或缺少依據 → `HOLD`，永不靜默 N/A。
- 不得臆造法規、承保限額、或「協會政策」。

### D.2 決策樹（每個節點輸出一個決策代號）

```
[起點] 本次將使用的場域／設備？
  ├─ 場域／設備清單未知 → D5 HOLD_UNKNOWN
  └─ 已知（填 T2）
       ├─ 是否有「要求檢查」的來源依據（真實手冊/契約/法規）？
       │    ├─ 有且已驗證 → 記 APPLICABLE_CONFIRMED，走設備安檢
       │    ├─ 有但未驗證 → APPLICABLE_CANDIDATE → 暫時 HOLD
       │    └─ 無/未知 → 不得判 N/A → D5 HOLD_UNKNOWN
       ├─ 是否有「要求投保」的來源依據（真實租約/契約/規範）？
       │    ├─ 有且已驗證 → 記 APPLICABLE_CONFIRMED，走場地保險
       │    ├─ 有但未驗證 → APPLICABLE_CANDIDATE → 暫時 HOLD
       │    └─ 無/未知 → 不得判 N/A → D5 HOLD_UNKNOWN
       └─ 合併：
            ├─ 僅檢查成立 → D1 APPLY_INSPECTION_ONLY
            ├─ 僅保險成立 → D2 APPLY_INSURANCE_ONLY
            ├─ 兩者皆成立 → D3 APPLY_BOTH
            ├─ 兩者皆有依據地不適用 → D4 NOT_APPLICABLE_WITH_BASIS（需引用來源；否則無效）
            └─ 任一未知 → D5 HOLD_UNKNOWN
```

### D.3 狀態字典（每個決策／狀態的代號、語意、可離開條件）

| 代號 | 類別 | 語意 | 允許的下一步 |
|---|---|---|---|
| `APPLICABLE_CONFIRMED` | 適用性 | 有**已驗證**真實來源要求 | 進入證據索取 |
| `APPLICABLE_CANDIDATE` | 適用性 | 有來源但未驗證 | 補驗證；仍 `HOLD` |
| `NOT_APPLICABLE_SUPPORTED` | 適用性 | 有**已驗證**真實來源支持不適用 | 可移出分母 |
| `UNKNOWN_APPLICABILITY` | 適用性 | 未知 | `HOLD`，禁 N/A |
| `EVIDENCE_MISSING` | 證據 | 尚無任何原本文檔 | 建立索取 |
| `REQUEST_DRAFTED_NOT_SENT` | 證據 | 索取函已草擬、**未寄出** | 授權後寄出 |
| `REQUESTED_PENDING_RESPONSE` | 證據 | 已寄出待回 | 追蹤 |
| `RECEIVED_UNVERIFIED` | 證據 | 收到但未驗證 | 進驗證步驟 |
| `RECEIVED_VERIFIED_REAL` | 證據 | 已驗證為真實正本 | 進索引與到期 |
| `EXPIRED_OR_OUT_OF_PERIOD` | 證據 | 已過期或不涵蓋課程期間 | `HOLD` 或補件 |
| `MISMATCH_OR_UNVERIFIABLE` | 證據 | 內容不符或無法驗證 | `HOLD` |
| `CANDIDATE` | 整體 | 僅範本完整、正本未到 | **不得**視為 PASS |
| `PENDING_REAL_SOURCE` | 整體 | 等真實正本 | 續辦 |
| `HOLD` | 整體 | 阻擋 | 解決後解除 |

`N/A` 只允許出現在 `NOT_APPLICABLE_SUPPORTED` 生效後；且**僅有已支持之適用性複核**才能把該義務移出分母。

## G. 設備安檢流程（文字＋表 T3）

1. 由 T2 取出「本次使用設備」義務。
2. 檢查前先確認**允收基準來源**（真實手冊/契約）；無則不得自訂門檻，記 `UNKNOWN / obtain and verify`。
3. 執行檢查（目視／功能）；記錄發現。
4. 異常 → **立即隔離與掛牌停用（tag-out）**，記錄 owner 與更正措施。
5. 更正後由**獨立複核者**複核，依**真實允收基準**判定放行；無基準 → `HOLD`。
6. 全程以 evidence_id 回填 T5、並在 T6 留決策軌跡。
7. **禁止**聲稱由合格第三方完成檢測，除非有真實驗證正本。
