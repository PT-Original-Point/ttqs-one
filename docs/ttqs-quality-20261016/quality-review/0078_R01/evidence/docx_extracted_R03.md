第 5 節　真實照片收件流程（可實際操作）
本節為真實使用時的收件程序。示範版無任何原件，故各步驟之欄位以「待填／受限」標示；真實使用時，未完成者維持 HOLD。
5.1 收件步驟（逐步）
1. 暫存與隔離：原件先置於受控暫存，不得放入公開儲存庫、雲端共享連結或個人未授權裝置。
2. 唯讀保存原檔：以唯讀方式保存原始檔（不覆寫、不重新編碼、不裁切原始檔）；衍生版另存。
3. 指派唯一 ID：對每張照片指派唯一 photo_id（格式見第 6.1 節）；ID 不得重複，且必須唯一指向一張原圖。
4. 登錄影像後設資料：原始檔名、格式、檔案大小、可得之拍攝時間與時區（若 EXIF 可取得則登錄；不確定時標 UNKNOWN）。
5. 計算 SHA-256：對原始檔計算 SHA-256（逐位元組一致），登錄計算時間（UTC）與計算角色。
6. 登錄來源路徑：記錄受限來源路徑（可驗證位置）；公開版僅顯示遮蔽後之識別碼，不揭露路徑。
7. 活動核對：將照片對應至具體活動 ID（如 SYN-078-Axx）；核對日期／時段／課程／活動紀錄，不符者 HOLD。
8. 授權／同意核對：檢核適用之同意／授權文本、使用範圍與有效期間；無適用授權者 HOLD／拒收。
9. 拒拍替代：若無法取得同意或場景不宜拍攝，改採替代素材或文字紀錄（須標示「非照片」，見第 7.4 節）。
10. 識別風險判斷：檢查姓名、名牌、螢幕、紙本、背景、未成年人、服務對象或第三人個資；有風險者去識別或 HOLD。
11. 建立遮罩／衍生版本鏈：記錄每一衍生版（遮罩、模糊、裁切）之版本號、衍生自哪個原圖、處理角色、時間與理由。
12. 權限／保存／刪除核准登錄：記錄存取權限、保存與刪除之核准角色（規則依本會核定，REAL=UNKNOWN/HOLD；不代填期限）。

7.2 選片原則

3. 不美化、不生成：不得修圖美化或生成補位。
4. 一致可查：入選照片須有唯一 ID 與雜湊，未入選者亦登錄狀態。
7.3 不要求拍攝可識別學員
本程序不要求、亦不鼓勵拍攝可識別學員；可以教材、場地、道具與去識別布置達成佐證目的。
若場合不宜拍攝（含服務對象保護），採拒拍替代（見 7.4）。
7.4 文字替代規則（必標示「非照片」）
任何以文字、圖示或去識別示意圖取代照片者，必須明確標示「非照片／文字替代」。
