## 第 5 節　真實照片收件流程（可實際操作）

> 本節為**真實使用**時的收件程序。示範版無任何原件，故各步驟之欄位以「待填／受限」標示；真實使用時，未完成者維持 HOLD。

### 5.1 收件步驟（逐步）

1. **暫存與隔離**：原件先置於**受控暫存**，不得放入公開儲存庫、雲端共享連結或個人未授權裝置。
2. **唯讀保存原檔**：以**唯讀**方式保存原始檔（不覆寫、不重新編碼、不裁切原始檔）；衍生版另存。
3. **指派唯一 ID**：對每張照片指派唯一 `photo_id`（格式見第 6.1 節）；ID 不得重複，且必須唯一指向一張原圖。
4. **登錄影像後設資料**：原始檔名、格式、檔案大小、**可得之拍攝時間與時區**（若 EXIF 可取得則登錄；不確定時標 `UNKNOWN`）。
5. **計算 SHA-256**：對**原始檔**計算 SHA-256（逐位元組一致），登錄計算時間（UTC）與計算角色。
6. **登錄來源路徑**：記錄**受限來源路徑**（可驗證位置）；公開版僅顯示遮蔽後之識別碼，不揭露路徑。
7. **活動核對**：將照片對應至**具體活動 ID**（如 `SYN-078-Axx`）；核對日期／時段／課程／活動紀錄，**不符者 HOLD**。
8. **授權／同意核對**：檢核適用之同意／授權文本、使用範圍與有效期間；**無適用授權者 HOLD／拒收**。
9. **拒拍替代**：若無法取得同意或場景不宜拍攝，改採**替代素材或文字紀錄**（須標示「**非照片**」，見第 7.4 節）。
10. **識別風險判斷**：檢查姓名、名牌、螢幕、紙本、背景、未成年人、服務對象或第三人個資；有風險者去識別或 HOLD。
11. **建立遮罩／衍生版本鏈**：記錄每一衍生版（遮罩、模糊、裁切）之版本號、衍生自哪個原圖、處理角色、時間與理由。
12. **權限／保存／刪除核准登錄**：記錄存取權限、保存與刪除之**核准角色**（規則依本會核定，`REAL=UNKNOWN/HOLD`；**不代填期限**）。

## 第 7 節　拍攝覆蓋與選片程序（可執行）

### 7.1 拍攝覆蓋清單（以活動段為單位）

| 活動段 | 建議覆蓋內容 | 不拍（禁止） |
| --- | --- | --- |
| 開場目標 | 課程目標、日程、安全提醒之教材畫面 | 名冊、桌牌、含個資螢幕 |
| 教材示範 | 示範步驟、教具、去識別教材 | 學員正面特寫、姓名標籤 |
| 練習／角色扮演 | 道具、情境卡、去識別布置 | 可辨識學員、服務對象資料 |
| 評量安排 | 評量場地設置或教材 | 答題紙、分數、姓名 |
| 反思收束 | 反思工具、空白表單樣式 | 學員填寫內容、個人反思文本 |

### 7.2 選片原則

1. **以資訊價值優先**：優先選能呈現活動設置與教材的畫面。
2. **去識別優先**：若含可辨識個人，先確認同意；否則改選或去識別。
3. **不美化、不生成**：**不得**修圖美化或生成補位。
4. **一致可查**：入選照片須有唯一 ID 與雜湊，未入選者亦登錄狀態。

### 7.3 不要求拍攝可識別學員

- 本程序**不要求**、亦**不鼓勵**拍攝可識別學員；可以教材、場地、道具與去識別布置達成佐證目的。
- 若場合不宜拍攝（含服務對象保護），採**拒拍替代**（見 7.4）。

### 7.4 文字替代規則（必標示「非照片」）

- 任何以文字、圖示或去識別示意圖取代照片者，**必須**明確標示「**非照片／文字替代**」。
- 替代素材**不得**被索引為 `photo_id` 之影像；應以獨立 `substitute_id` 登錄，並說明替代原因。
