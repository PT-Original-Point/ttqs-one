## 3. 課後追蹤調查機制設計

### 3.1 追蹤期程與目標對象界定

本機制設立雙波次追蹤時程，以平衡技能短期應用驗收與中長期行為定型之評估需求：
1. **結訓基準日（Day 0）：** [SAMPLE-DATE-D0] 2026-05-15（示範日期）。
2. **第一波次（30-Day Wave）：**
   - 啟動窗口：結訓後第 25 天寄發預告，第 30 天正式啟動，追蹤收案至第 40 天截止。
   - 核心目標：評估核心技能記憶維持、初步工作實務應用機會、流程依循度與初期證照備考狀態。
3. **第二波次（90-Day Wave）：**
   - 啟動窗口：結訓後第 85 天發出通知，第 90 天正式啟動，收案至第 100 天截止。
   - 核心目標：評估行為轉化持續性、長期工作產出改善效益、具體遭遇障礙與最終證照測驗結果。

### 3.2 接觸管道與催收標準作業程序（SOP）

為防範無效調查與樣本人為偏誤，制定標準接觸階梯：
- **第 1 次接觸（Day 30/90）：** 寄發個人專屬加密數位調查問卷連結（Email/簡訊）。
- **第 2 次接觸（第 3 工作天）：** 對未填答者發送通訊軟體或簡訊提醒。
- **第 3 次接觸（第 5 工作天）：** 由訓練小組執行專責電話訪談與核對。
- **狀態判定分流：**
  - **成功接觸（Reached）：** 學員親自接聽電話、確認收到問卷或回覆訊息。
  - **無法接觸（Unreachable）：** 號碼失效、信箱退信且透過次要緊急聯絡人連續 3 次均無法聯繫。
  - **接觸後未回覆（Reached Nonrespondent）：** 確認學員收到調查，但明確拒絕填答或逾收案截止日未完成送出。
  - **有效回卷（Valid Return）：** 完成問卷核心題目且通過邏輯檢核，無明顯亂填或系統性矛盾。

### 3.3 隱私保護與受試者自主權宣告

- 本調查遵循個人資料保護精神，全數樣本賦予虛擬代碼（`[SAMPLE-P01]` 至 `[SAMPLE-P10]`）。
- 學員可自由決定是否填答，並享有隨時退出之權利。
- 針對工會、協會或志願型受訓學員，**嚴格禁止強制要求其提供雇主或主管聯絡資訊**；主管/外部第三方觀察紀錄列為「選用（Optional）且須經學員明示同意（Consented）」之項目。

| :---: | :--- | :--- | :--- | :--- |
| **Q01** | 工作關聯性 (Job Relevance) | 課程技能與實務工作/志願任務相關度 | 5點李克特量表 (1=完全不相關 ~ 5=高度相關) | 檢驗課前需求分析與選員配對適切性 |

| **Q03** | 應用機會與情境 (Opportunity to Apply) | 課後任務中具備實際應用技能之機會 | 分類與程度 (1=無任何機會 ~ 5=每日持續應用) | 建立「具應用機會分母」，排除環境限制偏誤 |

| **Q08** | 實務應用障礙 (Application Barriers) | 落實應用技能時所面臨之最大瓶頸 | 類別選項 (1=無機會, 2=負荷重, 3=缺設備, 4=支持不足, 5=熟練度不足, 6=無障礙) | 識別組織或個人瓶頸，作為訓練行政支援依據 |
| **Q09** | 後續支援需求 (Support Needed) | 期待培訓單位提供之課後協助措施 | 類別單選 (1=工作坊, 2=手冊範本, 3=導師諮詢, 4=系統權限, 5=無需求) | 規劃課後輔導資源配置與回訓機制 |
| **Q10** | 整體行為轉化 (Behavioral Transfer) | 相較課前在工作習慣與專業行為之整體改變 | 5點李克特量表 (1=完全無轉變 ~ 5=建立穩定新習慣) | 綜合評定學員學習遷移整體成熟度 |
| **Q11** | 關鍵案例反思 (Qualitative Case Reflection) | 具體描述成功應用之實例或遭遇之困境 | 開放式文字問答 (文字長度 50~200 字) | 收集非辨識性質性佐證，深入還原應用現場 |
| **Q12** | 證照報考與結果 (Credential Status) | 對應專業認證之報名、應考及通過狀態 | 狀態選項 (1=通過, 2=未通過, 3=報名待考, 4=延期未考, 5=無資格/不報考) | 建立證照檢定母數，計算嘗試率與通過率 |

### 10.3 技能落實應用率：全體分母 vs. 機會分母對照驗算

技能在實務現場之應用，極常受到客觀工作派工與環境條件限制。本報告特別展示兩種分母定義之嚴謹計算：
1. **情境定義：**
   - 有效回卷人數 = $8$ 人（`P01-P08`）。
   - 具備應用機會人數（Q03 得分 $\ge 2$） = $7$ 人（`P01-P07`；`P08` 勾選 1 分代表無任何機會）。
   - 實際有落實應用人數（Q04 得分 $\ge 2$） = $6$ 人（`P01-P06`；`P07` 具機會但未應用；`P08` 因無機會未應用）。

2. **算式與數據代入：**
   - **全體有效學員技能應用率（All-Valid Skill-Use Rate）：**
     $$\text{Rate}_{\text{All-Valid}} = \frac{\text{實際應用人數}}{\text{全體有效回卷人數}} = \frac{6}{8} = 75.0\%$$
   - **機會調整後技能應用率（Opportunity-Adjusted Skill-Use Rate）：**
     $$\text{Rate}_{\text{Opportunity-Adjusted}} = \frac{\text{實際應用人數}}{\text{具備實質應用機會人數}} = \frac{6}{7} = 85.7\%$$
   - **分析意涵：** 75.0% 呈現整體培育對象之絕對轉化效益，而 85.7% 則排除了「單位完全無派工」之外在不可抗力因素，更能真實反映學員在「有機會情境下」的主動實踐意願。

### 10.4 證照報考與通過率獨立計算

針對示範專業證照 [SAMPLE-CRED-01]，嚴格區分「應考嘗試者」與「全體符合資格學員」之雙重分母計算，嚴禁將小樣本數據指稱為機構通過率：

1. **基本計數統計：**
   - 具報考資格母數（Eligible Cohort） = $10$ 人。
   - 完成檢定應試人數（Completed Attempts） = $8$ 人（`P01-P08`）。
   - 檢定測驗通過人數（Passed） = $6$ 人（`P01-P06`）。

2. **率值計算與公式驗算：**
   - **檢定應試涵蓋率（Attempt Coverage Rate）：**
     $$\text{Attempt Rate} = \frac{\text{完成檢定應試人數}}{\text{具報考資格人數}} = \frac{8}{10} = 80.0\%$$
   - **實考通過率（Pass Rate among Completed Attempts）：**
     $$\text{Pass Rate}_{\text{Attempts}} = \frac{\text{檢定測驗通過人數}}{\text{完成檢定應試人數}} = \frac{6}{8} = 75.0\%$$
