## 1. 目的

1.1 本程序明訂訓練結果評估之標準化作業流程，使每次訓練之結果評估具有一致的步驟、責任、判斷門檻、控制點與紀錄。

1.2 本程序明訂訓練實施前必須完成之「實施依據」確認事項，確保訓練非任意開辦，而是有需求、有目標、有資源、有評估計畫之依據。

1.3 本程序之所有操作、判斷、紀錄與例外處理，均以可檢查、可追溯、可重算為原則，以支援 TTQS 查核佐證。

1.4 本程序僅擁有 I04-E04 之直接紀錄／分析口徑；不得吞併 0024 或 0026 之專屬事實。

---

## 2. 適用範圍

2.1 適用於本機構（SAMPLE）所有對外或對內之訓練課程／班次之「實施前依據確認」與「結訓後結果評估」。

2.2 適用對象：承辦人、課程負責人、講師、訓練品質主管、稽核人員、高階主管。

2.3 不適用：訓練提供方式之選擇與管道（見 0024）、TTQS 管理系統之核准公告更新保存之治理機制（見 0026）。

2.4 本程序以文件化方式運作；若某訓練不適用本程序之任一步驟，必須依第 7 節登錄例外，不得逕行省略。

## 3. 名詞定義

| 名詞 | 定義 |
|---|---|
| **訓練實施依據（Implementation Basis）** | 訓練開辦前，必須具備並經確認之需求、目標、資源、評估計畫等證據集合；本程序以 F-0025-01 確認。 |
| **訓練結果評估（Training Result Evaluation）** | 結訓後，對反應、學習、行為、成果四層次之系統化評估與分析，以 F-0025-02 記錄。 |
| **控制點（Control Point, CP）** | 流程中必須由指定角色獨立覆核之節點；未通過不得進入下步。 |
| **決策門檻（Decision Threshold）** | 觸發分支判斷之數值或條件；本程序門檻均為 SAMPLE 示範值，正式使用前須由有權角色確認。 |
| **例外（Exception）** | 無法依標準步驟完成之情形，必須登錄 F-0025-03 並升級。 |
| **SAMPLE／SYNTHETIC** | 本文件所有情境與數值均為合成示範，不代表機構實績。 |
| **REAL** | 具可核實原件支撑之事實；本文件目前不包含 REAL 資料。 |

## 8. 判斷規則與控制點

### 8.1 決策門檻（SAMPLE 示範參數）

| 代碼 | 評估層次 | 門檻定義（SAMPLE） | 計算方式 |
|---|---|---|---|
| T-REACT | 反應評估 | 平均滿意度 ≥ 80%（4.0/5.0） | 所有有效作答題目分數總和 ÷（有效問卷數 × 題目數） |
| T-LEARN | 學習評估 | 通過率 ≥ 70% | 通過人數 ÷ 參評人數 |
| T-BEHAV | 行為評估 | 行動計畫完成率 ≥ 60% | 完成人數 ÷ 追蹤人數 |
| T-RESULT | 成果評估 | KPI 達成率 ≥ 50% | 達成人數 ÷ 追蹤人數 |

### 8.2 判斷樹（可檢查）

**起點：** 取得完整評估數據。

- 反應達到 T-REACT：記錄通過。未達門檻：登錄 E-05 並升級 R03。
- 學習達到 T-LEARN：記錄通過。未達門檻：登錄 E-06，擬定重訓或修課計畫。
- 行為達到 T-BEHAV：記錄通過。未達門檻：登錄 E-07，擬定輔導計畫。
- 成果達到 T-RESULT：記錄通過。未達門檻：登錄 E-08 並升級 R05。

**綜合判定：**

- 四項全通過：評估結論為「符合」，建議延續。
- 1 至 2 項未通過：評估結論為「部分符合」，擬定改善計畫。
- 3 至 4 項未通過：評估結論為「不符合」，升級 R05 並啟動矯正。

### 8.3 實施依據確認判定（F-0025-01）

| 項目 | 判定規則 |
|---|---|
| IB-01 需求分析已完成 | 必須為「是」；否則不得進入 S02 核准 |
| IB-02 訓練目標明確 | 必須為「是」 |
| IB-03 資源（講師／教材／環境）備妥 | 必須為「是」 |
| IB-04 評估計畫已擬定（四層次） | 必須為「是」 |
| IB-05 與年度計畫連結 | 必須為「是」 |
| IB-06 利益關係人已參與（引用 0024 範疇，本程序僅確認有紀錄） | 必須為「是」或附 N/A 理由 |

判定：IB-01~IB-05 全為「是」→ 准予實施；任一為「否」→ 不得實施，登錄 E-01。

### 8.4 N/A 與缺漏處理

| 情形 | 處理 |
|---|---|
| 資料尚未蒐集完成 | 延後評估，登錄 E-02／E-03，不得以空白充當完成 |
| 某層次評估不適用（如短期課程無行為追蹤） | 須於 F-0025-02 填寫 N/A 理由並經 R03 核准 |
| 數值無法計算（分母為 0） | 記錄「不適用：分母為 0」，不得以 0% 或 100% 填入 |
