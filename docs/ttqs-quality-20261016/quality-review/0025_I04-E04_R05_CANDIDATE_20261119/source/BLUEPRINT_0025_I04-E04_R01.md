## 2. 目的、讀者與操作邊界

### 目的
建立一份訓練執行者可按步驟操作、主管可依權責處置、評核者可抽查來源與計算的 SOP。流程須串起「核定課程依據 → 課前確認 → 實際實施紀錄 → 評估資料 → 判讀 → 補救／改善 → 結案及紀錄定位」。

### 預定讀者
訓練承辦／協調、講師或執行者、評估與資料覆核者、決策主管、紀錄保管者及外部評核者。這些是功能角色，不是該機構實際職稱、組織、人員或授權的事實；實際名稱、代理權及核准者均為 UNKNOWN，須以機構授權來源替換。

### 邊界
- 核心是訓練如何依據核定內容實施、如何評估結果，以及結果如何導致處置。
- 需求分析、課程設計、教學方式選擇及 TTQS 文件管制屬相鄰需求；只引用必要事實，不複製其專屬正文。
- 不把簽到、滿意度或單次測驗等同長期工作績效、訓練移轉或組織成果。
- 本來源未指定機構的門檻、工具、頻率、保存期限、核准層級、個資權限及補救時限。取得正式來源前標 UNKNOWN；範例值只能標 SAMPLE/SYNTHETIC。
- 沒有 REAL 訓練紀錄時，未來 DOCX 仍須用完整一致的 SAMPLE/SYNTHETIC 案例展示流程，不得把範例寫成實際課程、實績或已核准制度。

## 4. 操作步驟與決策控制

以下是未來文件的設計要求，不表示該機構已採用：

1. **受理及核對依據：**建立唯一訓練期程識別碼；核對課程計畫、目標、對象、時間、教材及評估方式的版本與來源。缺少核定證據時標 UNKNOWN，不稱為正式核定。
2. **課前就緒：**確認執行角色、場地／工具、教材、名冊、評量及資料保護措施。逐項記錄符合／不符合／UNKNOWN 與證據位置。關鍵資源不符合時，依核定權責暫停或升級。
3. **依計畫實施：**記錄實際日期、起訖、模組、出席、講師、教材版次及偏差。計畫值與實際值分欄保存；偏差記原因、影響、決策與證據。
4. **收集及驗證：**記錄評量工具版本、母體、有效樣本數、缺漏／無效值及來源。檢查分子分母、可回溯性及資料權限；不能驗證時標 UNKNOWN，不估算補值。
5. **計算及覆核：**按明定公式重算，記錄執行者、覆核者、時間、結果及資料位置。實際人名只可來自授權來源。
6. **形成判定：**依機構核定目標及門檻判讀。若門檻不存在或版本不明，標「無法判定／UNKNOWN」，撰稿者不得自行設定 REAL 門檻。
7. **改善及補救：**未達條件或出現偏差時，記錄措施、責任角色、期限來源、驗證方式及結果。未回收的補救證據維持 OPEN。
8. **結案及可追溯：**核對紀錄完整、計算可重現、偏差及改善有狀態；記受控位置／識別碼／版次／SHA（可得時）。保存期限、權限、公告流程引用 I04-E05 或機構來源，不在 0025 發明。

決策至少分為：資料不足則暫不判定並補取來源；實施與核定依據不一致則記偏差並依核定權責處置；資料完整且達標則記錄公式及證據；未達或個別未達則補救並追蹤；安全、個資或重大外部效果依機構核定程序升級。未結事項不得標成完成。
