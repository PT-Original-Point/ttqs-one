# Automated Quality Gates

## Hard gates
A. Blueprint binding — exactly one requirement/Blueprint row per deliverable.
B. Genre mechanics —
- Questionnaire: questions/options/scales/instructions/scoring-analysis.
- SOP: roles/inputs/ordered steps/decisions/exceptions/controls/outputs/records.
- Meeting: time/participants/agenda/opinions/decisions/owner/due date/follow-up.
- Assessment: criteria/scoring/threshold/result interpretation.
- Outcome/analysis: metric/numerator-denominator/period/source link/interpretation/limitations.

C. SAMPLE completeness —
If REAL is unavailable and the genre needs operational data, complete coherent SAMPLE/SYNTHETIC facts are mandatory.
Any 待填/待核/空白表/保持空白/會後填寫 outside an explicit REAL_REPLACEMENT_AREA = FAIL.
Sample-required document with zero registered synthetic facts = FAIL.

D. Truth boundary — no SAMPLE may imply real signing, approval, third-party issuance, attendance, government/financial original, certification, or real outcome.

E. Readability — body >=10.5pt; table >=9.5pt; first page answers purpose/user/time/action/output/SAMPLE-vs-REAL.

F. Anti-template — fresh title-blind reviewer must identify correct requirement/genre; negative-choice against nearest semantic neighbors must reject wrong assignments with body locators. Substantive repeated body/table schemas across unrelated families trigger impact scan. Standard front matter is exempt.

G. Arithmetic/source consistency — formulas, denominators, units, periods, totals and linked sample facts recompute.

H. DOCX integrity — DOCX opens / ZIP CRC passes. PDF/PNG is not required unless a layout anomaly is detected.
